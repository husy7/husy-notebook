# 图像处理基础：张量表示、归一化与增广

## 一、核心思想

计算机视觉模型的输入是**数字矩阵**。把图片变成模型能吃的数据，通常经历三步：

1. **表示**：图片 → 张量（C, H, W），并做 RGB/灰度、尺寸统一。
2. **归一化**：把 0~255 像素缩放/标准化到合适分布，帮助收敛。
3. **增广（Augmentation）**：训练时对图像做随机变换制造更多样本，增强泛化、抗过拟合。

## 二、图像的张量表示

- 灰度图：形状 `(H, W)`，每像素一个 0~255 的亮度值。
- RGB 彩色图：形状 `(H, W, 3)` 或按通道优先为 `(3, H, W)`（PyTorch 用 **CHW**，`torchvision` 输出即此）。
- 神经网络 batch 通常为 `(N, C, H, W)`。

```python
from torchvision.io import read_image
img = read_image("image.jpg")      # shape: (C, H, W), uint8, 范围 0~255
img = img.float() / 255.0          # 归一化到 [0,1]
print(img.shape)                   # e.g. torch.Size([3, 224, 224])
```

> ⚠️ PyTorch 是 **CHW**；OpenCV 是 **HWC 且 BGR** 通道序。互转要 `.permute` 和通道翻转，极易踩坑。

## 三、归一化

### 3.1 两种层次

| 方式 | 操作 | 目的 |
|------|------|------|
| **线性缩放到 [0,1]** | 除以 255 | 让输入量级适中 |
| **标准化（均值-方差）** | $(x-\mu)/\sigma$ | 让每通道接近 0 均值、单位方差，配合预训练模型 |

### 3.2 ImageNet 标准（与预训练模型搭配）

```python
from torchvision import transforms

normalize = transforms.Normalize(
    mean=[0.485, 0.456, 0.406],   # RGB 通道均值
    std=[0.229, 0.224, 0.225]     # RGB 通道标准差
)
```

> 💡 加载预训练 CNN（torchvision 模型）时，**必须用对应的 ImageNet 均值/方差**，否则结果大幅退化。

## 四、数据增广（Augmentation）

训练中对每张图随机施加变换（翻转、旋转、裁剪、色彩抖动等），本质引入了**更强的先验与正则**。

- 目的：抑制过拟合、提升对平移/旋转/光照/裁剪的鲁棒性。
- 代价：每 batch 多一步计算；过度增广会损害真实分布（augmentation 太狠反而伤训练）。

```python
augment = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.8, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.2, contrast=0.2),
    transforms.ToTensor(),           # → [0,1] 并转 CHW
    normalize,
])
```

## 五、卷积与池化（处理的基础算子）

- **卷积**：小卷积核（如 3×3）滑过图像，做加权求和提取局部特征。
- **池化（Pooling）**：下采样降低尺寸、保留局部最强响应（MaxPool 最常用），增强平移不变性并减小计算。

```python
import torch.nn as nn
conv = nn.Conv2d(3, 16, kernel_size=3, stride=1, padding=1)   # RGB → 16 通道
pool = nn.MaxPool2d(2)
out = pool(conv(torch.randn(1, 3, 224, 224)))   # 输出 (1,16,112,112)
```

## 六、边界与坑

- ❌ 用 OpenCV 载图直接喂 PyTorch 模型 → BGR & HWC 通道错乱、颜色反转。✅ 转 RGB + `permute(2,0,1)`。
- ❌ 没按 ImageNet 均值/方差归一化就用预训练模型 → 精度暴跌。✅ 用官方 `transforms` 预处理一致。
- ❌ 增广**作用到验证集** → 指标失真（评估应保持原始/仅基本 resize）。✅ 增广只用于训练。
- ❌ `ToTensor` 与 `Normalize` 顺序颠倒 → 归一化错。✅ ToTensor 后再 Normalize。
- ❌ 尺寸不统一的 batch → `stack` 失败。✅ 先 resize/ResizedCrop 到统一尺寸再 batch。
- 边界：归一化依赖训练分布，跨域（医学图 vs 自然图）迁移时可能需重算统计量。
