# 图像处理基础：张量表示、归一化与增广

## 定义

本知识点覆盖计算机视觉数据管线的"输入侧"三件事：**图像的张量表示（Representation）**、**归一化（Normalization）** 与 **数据增广（Augmentation）**，即"把一张图片变成模型能吃的数据"的完整三步流程。

它解决的问题：CNN 等深度学习模型的输入必须是**数字矩阵**，无法直接消费 JPEG/像素文件——需要先把图片统一成数值张量，再把数值调整到合适的分布帮助收敛，最后在训练阶段人为制造更多样本以增强泛化、抑制过拟合。

核心特征有三点：

- **张量表示**：灰度图为 `(H, W)`（每像素一个 0~255 亮度值），RGB 彩色图为 `(H, W, 3)` 或按通道优先的 `(3, H, W)`（PyTorch/torchvision 采用 **CHW**），神经网络 batch 通常为 `(N, C, H, W)`。
- **归一化**：把 0~255 像素缩放到合适分布——除以 255 的线性缩放到 [0,1]，或 `(x-μ)/σ` 的标准化让每通道接近 0 均值、单位方差。
- **数据增广（Augmentation）**：训练时对每张图随机施加翻转、旋转、裁剪、色彩抖动等变换，本质引入更强的先验与正则，提升对平移/旋转/光照/裁剪的鲁棒性。

适用范畴：PyTorch/torchvision 生态下基于预训练 CNN 的图像分类、检测、分割训练与迁移学习；任何需要统一图像输入格式、配合预训练权重使用的数据流水线。

## 原理

**张量表示环节**：`read_image` 一次调用把 JPEG 解码成 uint8 的 CHW 张量（值域 0~255），channel-first 布局方便 PyTorch 按通道做向量化统计与卷积（`Conv2d` 期望输入 `(N, C, H, W)`）。陷阱根源在于：OpenCV 默认是 **HWC 且 BGR** 通道序，喂给 PyTorch 前必须 `COLOR_BGR2RGB` 转通道 + `permute(2,0,1)` 换布局，互转极易踩坑。

**归一化两种层次**：

| 方式 | 操作 | 目的 |
|------|------|------|
| 线性缩放到 [0,1] | 除以 255 | 让输入量级适中 |
| 标准化（均值-方差） | $(x-\mu)/\sigma$ | 让每通道接近 0 均值、单位方差，配合预训练模型 |

为什么必须与预训练模型搭配同一套统计量：加载预训练 CNN（torchvision 模型）时，权重是在 ImageNet 均值 μ=[0.485,0.456,0.406]、标准差 σ=[0.229,0.224,0.225] 的输入分布上训练的；喂不同分布的输入会导致特征统计漂移、**结果大幅退化**。先除以 255 把量级压到 [0,1] 避免梯度震荡，再做 `(x-μ)/σ` 标准化。

**数据增广原理**：每个训练样本在每个 epoch 被随机变换一次，等价于在训练分布上叠加更强的先验（平移/翻转/光照不变性）与正则化（减少对特定像素布局的过拟合）。`RandomResizedCrop` 同时承担随机裁剪与尺寸统一两个职责，保证 batch 内尺寸一致、`stack` 不失败。代价：每 batch 多一步计算；增广过狠会损害真实分布、反而伤训练。

**顺序约束**：`ToTensor`（PIL → [0,1] 并转 CHW）必须先于 `Normalize`（标准化）执行，顺序颠倒会让标准化作用在错误量纲上。

**基础算子**：卷积（小卷积核如 3×3 滑过图像做加权求和，提取局部特征）与池化（下采样降低尺寸、保留局部最强响应，MaxPool 最常用）是图像进入网络后的第一步处理，池化增强平移不变性并减小计算量。

## 应用

典型使用场景：用 torchvision 预训练 CNN 做图像分类与迁移学习；训练数据不足或类别不均衡时靠增广扩充样本；任何以统一 `(N,C,H,W)` 张量喂模型的 PyTorch 训练/评估管线。

快速上手步骤：

1. 读图并统一通道序与尺寸——`read_image` 或 PIL 直接得 CHW+RGB；若用 OpenCV 需先 `cvtColor` 转 RGB。
2. 训练管线：`transforms.Compose([RandomResizedCrop, RandomHorizontalFlip, ColorJitter, ToTensor, Normalize(ImageNet 均值/方差)])`。
3. 验证/测试管线只做 `Resize + ToTensor + Normalize`，**绝不做随机增广**，否则评估指标失真。
4. batch 前先统一尺寸（resize/ResizedCrop），否则 `stack` 失败。

注意事项/常见坑：

- ❌ OpenCV 载图直接喂 PyTorch 模型 → BGR & HWC 通道错乱、颜色反转。✅ 转 RGB + `permute(2,0,1)`。
- ❌ 用预训练模型却不用 ImageNet 均值/方差归一化 → 精度暴跌。✅ 用官方 `transforms` 一致预处理。
- ❌ 增广作用到验证集 → 指标失真（评估应保持原始/仅基本 resize）。✅ 增广只用于训练。
- ❌ `ToTensor` 与 `Normalize` 顺序颠倒 → 归一化错误。✅ ToTensor 后再 Normalize。
- ❌ 尺寸不统一的 batch → `stack` 失败。✅ 先 resize/ResizedCrop 到统一尺寸再 batch。
- 边界：归一化统计量依赖训练分布，跨域迁移（医学图 vs 自然图）时可能需重算统计量。

```python
# 案例：一张 JPEG → 可直接喂预训练 CNN 的 (N,C,H,W) batch，含张量表示、归一化、增广与基础算子
import torch
import torch.nn as nn
from torchvision.io import read_image
from torchvision import transforms

# ---- 1. 张量表示：图片 → (C, H, W)，uint8，范围 0~255 ----
img = read_image("image.jpg")   # torchvision 直接读出 CHW + RGB
print(img.shape)                # e.g. torch.Size([3, 224, 224])
# ⚠️ 若用 OpenCV 读图：默认 HWC 且 BGR，需先
#    img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
#    img = torch.from_numpy(img).permute(2, 0, 1)   # 才能得到 CHW + RGB

# ---- 2. 归一化：先线性缩放，再标准化 ----
img01 = img.float() / 255.0        # 线性缩放到 [0,1]：让输入量级适中

normalize = transforms.Normalize(  # 标准化 (x-μ)/σ：配合预训练模型必用
    mean=[0.485, 0.456, 0.406],    # ImageNet RGB 通道均值
    std=[0.229, 0.224, 0.225]      # ImageNet RGB 通道标准差
)

# ---- 3. 数据增广（只用于训练集；验证/测试集仅 Resize + ToTensor + Normalize）----
augment = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.8, 1.0)),  # 随机裁剪并统一尺寸 → batch 可 stack
    transforms.RandomHorizontalFlip(),                     # 随机水平翻转
    transforms.ColorJitter(brightness=0.2, contrast=0.2),  # 色彩抖动：亮度/对比度 ±20%
    transforms.ToTensor(),        # PIL → [0,1] 并转 CHW；必须先于 Normalize 执行
    normalize,                    # ImageNet 标准化
])
# 注：若输入已是用 read_image 得到的 uint8 张量，用 img.float()/255.0 替代 ToTensor

# ---- 4. 处理基础算子：卷积 + 池化 ----
conv = nn.Conv2d(3, 16, kernel_size=3, stride=1, padding=1)  # RGB(3) → 16 通道
pool = nn.MaxPool2d(2)                                       # 2×2 最大池化下采样
x = torch.randn(1, 3, 224, 224)    # batch 张量 (N=1, C=3, H=224, W=224)
out = pool(conv(x))                # 输出形状 (1, 16, 112, 112)

# ---- 案例详解 ----
# 输入一张 224×224 的 JPEG：read_image 得到 (3,224,224) 的 uint8 张量。
# 训练时经 augment，每个 epoch 都会得到不同的随机裁剪/翻转/色彩抖动结果，再做
# ImageNet 标准化——相当于给模型施加平移/旋转/光照不变性先验，抑制过拟合；
# 同一批数据验证时只用 resize + 标准化，保证评估指标不失真。
# 进入网络后：3×3 卷积滑窗加权求和提取 16 通道局部特征 → 2×2 池化把空间尺寸减半
# 到 112×112、保留局部最强响应并增强平移不变性，构成 CNN 主干的基础构建块。
```

## 对比选型
| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| 本文方案：torchvision.transforms 一体化管线 | ToTensor→Normalize→增广与 PyTorch 张量/预训练权重深度耦合，变换顺序即数据流顺序 | 微调/训练 torchvision 预训练 CNN、PyTorch 生态内的分类与检测管线 |
| 替代方案：OpenCV + NumPy 手工预处理 | 底层 HWC/BGR 原生读写，手动 `permute`/通道翻转完成转换，控制粒度最细 | 图像读写与调试、非 torch 框架、需要逐中间结果把控的场景 |
| 替代方案：Albumentations | 与 OpenCV 对齐的高性能随机增广库，增广种类更全、速度与效果俱佳 | 大数据量训练、分割/检测等需要复杂空间增广的场景 |
