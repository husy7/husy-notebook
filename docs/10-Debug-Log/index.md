# 踩坑记录（10-Debug-Log）

> **板块定位**：真实踩坑记录与解决方案。**AI 方向尤其重要**——每次踩坑都是最贵的教训，写下来就变成了资产。

## 记录规范

1. **一条坑一个文件**：按 `YYYY-MM-DD-<简短描述>.md` 命名。
2. **固定结构**：现象 → 原因 → 排查过程 → 解决 → 预防。
3. **关联回笔记**：与某篇笔记相关的坑，在笔记「第五部分 踩坑关联」中同步登记。
4. **AI 辅助生成**的记录同样在文末注明。
