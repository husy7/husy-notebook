# 机器学习算法（02）

> **板块定位**：传统机器学习（非深度学习）核心算法与评估方法论，作为深度学习（03）、NLP/LLM（04）、CV（05）的理论基础。

## 覆盖主题

| 子目录 | 覆盖内容 |
| :--- | :--- |
| `Linear-Models` | 线性回归、逻辑回归、正则化（L1/L2/Ridge/Lasso） |
| `Tree-Based` | 决策树、随机森林、GBDT/XGBoost/LightGBM |
| `Clustering` | K-Means、层次聚类、DBSCAN、高斯混合模型 |
| `Evaluation` | 指标（准确率/精确率/召回率/F1/AUC）、交叉验证、过拟合 |

## 前置知识

- 线性代数：矩阵、向量、范数
- 概率论：条件概率、极大似然估计
- 微积分：偏导、梯度
