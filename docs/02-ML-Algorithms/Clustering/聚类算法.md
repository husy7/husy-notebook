# 聚类：无监督学习与常用算法

## 一、核心思想

聚类用于**没有标签**的数据：把相似的样本自动分到同一组（簇），使**簇内相似度高、簇间相似度低**。它是无监督学习的代表任务，常用于数据探索、画像分群、图像分割、异常检测。

聚类本质是求解一个"怎么定义相似、怎么划分"的问题，因此不同算法对数据形态的假设差异很大。

## 二、K-Means（最经典）

### 2.1 原理

1. 指定簇数 K，随机初始化 K 个质心。
2. 迭代：把每个样本分给最近的质心 → 用簇内均值更新质心 → 重复直到质心不再变化。

本质是优化目标：
$$ \min \sum_{k=1}^{K} \sum_{x \in C_k} \| x - \mu_k \|^2 $$

### 2.2 特点与局限

- ⚡ 简单、快、可扩展，适合大规模数据。
- ⚠️ **K 必须预先指定**；对**初始质心敏感**；对**异常值敏感**；只能找到**凸/球形簇**（用欧氏距离、基于均值=球状假设）。

```python
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

X, _ = make_blobs(n_samples=300, centers=4, random_state=0)
km = KMeans(n_clusters=4, n_init=10, random_state=0).fit(X)
print(km.labels_)          # 每个样本的簇标签
print(km.cluster_centers_) # 4 个质心
```

> 💡 工程建议：对特征做标准化，用肘部法或硅系数（Silhouette）选 K，多次运行取最优（`n_init>1`）。

## 三、DBSCAN（基于密度）

### 3.1 原理

- 参数 `eps`（半径）与 `min_samples`（最少邻居数）。
- 核心点：半径内邻居 ≥ min_samples 的点；边界点：非核心但落在核心点半径内；噪声点：其余。
- 从任一核心点贪心地"密度相连"地扩展成簇。

### 3.2 优势

- 不需要指定 K。
- 能发现**任意形状**的簇。
- 天然识别**异常点/噪声**。

```python
from sklearn.cluster import DBSCAN
db = DBSCAN(eps=0.3, min_samples=5).fit(X)
print(set(db.labels_))     # -1 表示噪声点
```

## 四、其他算法

| 算法 | 思路 | 适用 |
|------|------|------|
| **层次聚类** | 不断合并最近的两簇（凝聚式），生成层次树（树状图） | 需要树状结构、小数据 |
| **高斯混合模型 GMM** | 假设数据是多高斯分布加权混合，用 EM 估计 | 软分配（带概率）、椭球形簇 |
| **谱聚类** | 基于图拉普拉斯特征向量聚类 | 非凸簇、图结构数据 |

## 五、怎样评估"聚得好不好"？

无标签下无"标准答案"，用内部指标：

| 指标 | 思想 |
|------|------|
| **轮廓系数（Silhouette）** | 综合簇内紧密度与簇间分离度，[-1,1] 越大越好 |
| **内/外 WSS**（肘部法） | 簇内平方和随 K 的下降拐点选 K |

```python
from sklearn.metrics import silhouette_score
print(silhouette_score(X, km.labels_))   # 越大越好
```

## 六、边界与坑

- ❌ K-Means 在**各簇大小分布极度不均**或**长条形/环状簇**下失效。✅ 换 DBSCAN/GMM。
- ❌ **量纲不同的特征**直接用欧氏距离会扭曲聚类。✅ 必须标准化。
- ❌ K-Means 用**均值**做质心 → 对**异常值/离群点**极敏感。✅ 可先剔除异常或换 K-medoids。
- ❌ 类别不平衡脚本中，密度类参数（eps）对稀疏簇效果差。
- 边界：聚类结果高度依赖距离度量与缩放，属于无监督"探索性"而非"验证性"工具。

## 七、关联

- 前置知识：欧氏距离、KNN（相似度思想）。
- 类似概念：K-Means vs KNN（有监督）；硬聚类 vs GMM 软聚类。
- 应用：图像分割、客户画像、异常检测、知识库文本话题分组。
