# 聚类：无监督学习与常用算法

## 定义

聚类（Clustering）是**无监督学习**（Unsupervised Learning）的代表任务，专门处理**没有标签**的数据：不依赖任何人工标注，仅凭样本自身的特征分布，把相似样本自动归入同一组（簇，Cluster）。

其核心目标可概括为——**簇内相似度高、簇间相似度低**：让同一簇内的样本尽量"抱团"，不同簇之间的样本尽量"分开"。

聚类本质上是求解两个问题：①如何定义"相似"（即距离/相似度度量，如欧氏距离、余弦相似度）；②如何划分（硬聚类给出确定归属 vs 软聚类给出概率归属，如 GMM）。

由于不同算法对数据形态（球形/任意形状、密度均匀/不均、有无噪声、是否需要预设簇数）的假设差异很大，**没有任何一种聚类算法能通吃所有场景**，选型必须先分析数据形态与业务需求。

典型产出形式包括：簇标签（K-Means、DBSCAN）、概率归属（GMM）、层次树状图（层次聚类）等，既可用于探索性数据分析（EDA），也可作为后续监督学习/特征工程的输入。

## 原理

### 1. K-Means（最经典，基于质心的划分式聚类）

- **为什么这样设计**：把聚类转化为"找 K 个质心，使样本到所属质心距离平方和最小"的优化问题，再用"分配—更新"交替迭代逼近（局部）最优解，思路直观、计算高效。
- **步骤**：
  1. 指定簇数 \( K \)，随机初始化 \( K \) 个质心（centroid）；
  2. 迭代：将每个样本分配给距离最近的质心 → 用簇内所有样本的均值更新质心 → 重复直到质心不再变化（收敛）。
- **优化目标**（最小化簇内平方和 WCSS/SSE）：
  \[
  \min \sum_{k=1}^{K} \sum_{x \in C_k} \| x - \mu_k \|^2
  \]
  其中 \( C_k \) 为第 \( k \) 个簇，\( \mu_k \) 为该簇质心。该目标函数非凸，结果依赖初始质心，因此实践中需 `n_init` 次随机初始化并取最优。
- **特点**：简单、快速、可扩展，适合大规模数据；但对 **K 值需预先指定**敏感，对**初始质心**和**异常值**敏感；因使用欧氏距离与均值更新，只能发现凸/球形簇。

### 2. DBSCAN（基于密度）

- **参数**：`eps`（邻域半径）与 `min_samples`（成为核心点所需的最少邻居数）。
- **点的分类**：
  - **核心点**：半径 `eps` 内邻居数 ≥ `min_samples`；
  - **边界点**：非核心点，但落在某核心点的 `eps` 半径内；
  - **噪声点**：其余点（既非核心也非边界，标记为噪声）。
- **聚类过程**：从任一核心点出发，贪心地扩展所有密度相连（density-connected）的点，连通成簇。
- **优势**：无需指定 K；能发现任意形状的簇；天然识别噪声/异常点。代价是 `eps` 与 `min_samples` 需要根据数据密度调参，密度不均匀时效果会变差。

### 3. 其他常用算法

| 算法 | 思路 | 适用场景 |
|------|------|----------|
| **层次聚类** | 不断合并最近的两簇（凝聚式/自底向上），生成层次树（树状图 dendrogram） | 需要树状结构、小数据集 |
| **高斯混合模型 GMM** | 假设数据由多个高斯分布加权混合，用 EM 算法迭代估计参数 | 软分配（带概率）、椭球形簇 |
| **谱聚类** | 基于图拉普拉斯矩阵的特征向量进行聚类（图切割视角） | 非凸簇、图结构数据 |

## 应用

**典型使用场景**：
- 数据探索与画像分群：如客户细分（CRM 分群）、用户行为画像；
- 图像分割：按像素特征聚成不同区域；
- 异常检测：DBSCAN 天然适用（噪声点即异常）；
- 知识库文本话题分组：文档向量化后聚类出话题簇；
- 推荐系统：对用户/物品做聚类，缩小候选集或辅助冷启动分组。

**快速上手步骤（流程）**：
1. **特征预处理**：缺失值处理后做标准化/归一化——量纲不同会扭曲距离计算结果；
2. **选算法**：数据呈球状且 K 可预估 → K-Means；形状任意/含噪声/不知 K → DBSCAN；需要层次关系 → 层次聚类；
3. **定参**：K-Means 用肘部法（elbow）或轮廓系数选 K，并设 `n_init>1` 多次运行；DBSCAN 调 `eps` 与 `min_samples`；
4. **评估**：用轮廓系数（silhouette score，越大越好）等内部指标衡量分簇质量；
5. **解释落地**：给每个簇打上业务标签，用于下游分析或特征工程。

**易错点/坑**：
- **特征必须标准化**——量纲不同会扭曲距离计算，这是最常见的坑；
- K-Means 只跑一次容易陷入局部最优，务必 `n_init>1`，并固定 `random_state` 保证结果可复现；
- K 值不能盲目拍脑袋，需结合肘部法/轮廓系数等辅助判断；
- DBSCAN 的 `eps` 与 `min_samples` 需根据数据密度调参，密度不均时效果差（可考虑 OPTICS）；
- 聚类只是"数据视角的分组"，是否对应真实业务含义需人工验证——它是探索工具而非最终结论。

## 代码示例

```python
# ============ 生成模拟数据：300 个样本、4 个球状簇 ============
from sklearn.datasets import make_blobs

X, _ = make_blobs(n_samples=300, centers=4, random_state=0)
# X 为特征矩阵 (300, 2)；第二返回值是"真实标签"，仅供生成模拟数据用，
# 聚类时只用 X 不用标签 —— 这正是"无监督"的体现

# ============ K-Means 示例 ============
from sklearn.cluster import KMeans

km = KMeans(n_clusters=4, n_init=10, random_state=0).fit(X)
# n_clusters=4: 预先指定簇数 K；n_init=10: 随机初始化 10 次取最优，规避局部最优
print(km.labels_)          # 每个样本的簇标签
print(km.cluster_centers_) # 4 个质心

# ============ DBSCAN 示例（同一份数据上做对比） ============
from sklearn.cluster import DBSCAN
db = DBSCAN(eps=0.3, min_samples=5).fit(X)
print(set(db.labels_))     # -1 表示噪声点

# ============ 轮廓系数评估 ============
from sklearn.metrics import silhouette_score
print(silhouette_score(X, km.labels_))   # 越大越好，范围 [-1, 1]
```

**案例详解**：先用 `make_blobs` 生成 300 个样本、真实中心为 4 的二维数据（聚类只用 X，丢弃标签以模拟无监督场景）。K-Means 设 `n_clusters=4` 与真实簇数一致、`n_init=10` 做多次初始化防局部最优，拟合后输出每个样本的簇标签（0~3）与 4 个质心坐标。DBSCAN 用 `eps=0.3, min_samples=5` 在同一份数据上聚类，`labels_` 中 -1 即为噪声点，可与 K-Means 对比"自动发现簇数 vs 需预设 K"。最后用轮廓系数对 K-Means 结果打分（越大越好）；若用轮廓系数横向评估含噪声点的 DBSCAN 结果，通常应先剔除 `-1` 样本，否则会拉低分数、口径不一致。

## 对比选型

| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| **本文方案：K-Means** | 基于质心迭代，最小化簇内平方和 | 数据呈球状、各簇大小相近、无严重异常值，且 K 可预估 |
| **替代方案：DBSCAN** | 基于密度连通性 | 簇形状任意、存在噪声、不需预设簇数，但数据密度需较均匀 |
| **替代方案：层次聚类** | 自底向上合并或自顶向下分裂 | 需要层次关系、小样本（< 数千） |
| **替代方案：GMM** | 概率生成模型，软分配 | 簇为椭球状、需要归属概率、可处理重叠簇 |
| **替代方案：谱聚类** | 图切割，利用特征向量降维 | 非凸簇、图结构数据（如社交网络） |
