# 聚类：无监督学习与常用算法

## 定义

聚类（Clustering）是**无监督学习**的代表任务，用于处理**没有标签**的数据。其核心目标是将相似的样本自动归入同一组（簇），使得**簇内相似度高、簇间相似度低**。聚类本质上是求解“如何定义相似”以及“如何划分”的问题，不同算法对数据形态的假设差异很大，因此没有一种算法能通用所有场景。

## 原理

### 1. K-Means（最经典）

- **步骤**：
  1. 指定簇数 \( K \)，随机初始化 \( K \) 个质心；
  2. 迭代：将每个样本分配给最近的质心 → 用簇内所有样本的均值更新质心 → 重复直到质心不再变化。
- **优化目标**：
  \[
  \min \sum_{k=1}^{K} \sum_{x \in C_k} \| x - \mu_k \|^2
  \]
- **特点**：简单、快速、可扩展，适合大规模数据；但对 **K 值预先指定**敏感，对**初始质心**和**异常值**敏感，且只能发现凸/球形簇（因使用欧氏距离和均值）。

### 2. DBSCAN（基于密度）

- **参数**：`eps`（半径）与 `min_samples`（最少邻居数）。
- **点的分类**：
  - **核心点**：半径内邻居数 ≥ `min_samples`；
  - **边界点**：非核心但落在某核心点的半径内；
  - **噪声点**：其余点。
- **聚类过程**：从任一核心点出发，贪心地扩展所有密度相连的点，形成簇。
- **优势**：无需指定 K，能发现任意形状的簇，天然识别噪声/异常点。

### 3. 其他算法

| 算法 | 思路 | 适用场景 |
|------|------|----------|
| **层次聚类** | 不断合并最近的两簇（凝聚式），生成层次树（树状图） | 需要树状结构、小数据集 |
| **高斯混合模型 GMM** | 假设数据由多个高斯分布加权混合，用 EM 算法估计参数 | 软分配（带概率）、椭球形簇 |
| **谱聚类** | 基于图拉普拉斯矩阵的特征向量进行聚类 | 非凸簇、图结构数据 |

## 应用

- 数据探索与画像分群（如客户细分）
- 图像分割
- 异常检测（DBSCAN 天然适用）
- 知识库文本话题分组
- 推荐系统中的用户/物品聚类

## 代码示例

```python
# K-Means 示例
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

X, _ = make_blobs(n_samples=300, centers=4, random_state=0)
km = KMeans(n_clusters=4, n_init=10, random_state=0).fit(X)
print(km.labels_)          # 每个样本的簇标签
print(km.cluster_centers_) # 4 个质心

# DBSCAN 示例
from sklearn.cluster import DBSCAN
db = DBSCAN(eps=0.3, min_samples=5).fit(X)
print(set(db.labels_))     # -1 表示噪声点

# 轮廓系数评估
from sklearn.metrics import silhouette_score
print(silhouette_score(X, km.labels_))   # 越大越好
```

> **工程建议**：
> - 特征必须标准化（量纲不同会扭曲距离）；
> - K-Means 可用肘部法或轮廓系数选择 K，并多次运行（`n_init>1`）避免局部最优；
> - DBSCAN 的 `eps` 和 `min_samples` 需根据数据密度调参。

## 对比与选型

| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| **K-Means** | 基于质心迭代，最小化簇内平方和 | 数据呈球状、各簇大小相近、无严重异常值，且 K 可预估 |
| **DBSCAN** | 基于密度连通性 | 簇形状任意、存在噪声、不需要预设簇数，但数据密度需较均匀 |
| **层次聚类** | 自底向上合并或自顶向下分裂 | 需要层次关系、小样本（< 数千） |
| **GMM** | 概率生成模型，软分配 | 簇为椭球状、需要归属概率、可处理重叠簇 |
| **谱聚类** | 图切割，利用特征向量降维 | 非凸簇、图结构数据（如社交网络） |
