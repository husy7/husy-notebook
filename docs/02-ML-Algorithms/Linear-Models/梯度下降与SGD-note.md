# 梯度下降与 SGD

## 定义
- 梯度下降（Gradient Descent, GD）是一种**迭代式**的一阶优化算法：对可微损失 $J(\theta)$，从某个初始参数出发，反复沿 **负梯度方向** 走一小步，直到损失收敛到（局部）最小值。SGD（Stochastic Gradient Descent）是它"每次只用少量样本估计梯度"的随机变体。
- 它要解决的问题是：直接求解析解（如线性回归的正规方程）需要求 $X^\top X$ 的逆，复杂度约 $O(d^3)$ 且要一次性装下全部数据，在**特征多 / 数据量大**时不可行；梯度下降只需每次算梯度，成本低、可在线更新。
- 核心特征：只依赖梯度（一阶信息）+ 学习率 $\eta$；更新式 $\theta \leftarrow \theta - \eta \nabla_\theta J(\theta)$，实现简单、通用，几乎可用于任意可微损失。
- 按"每次用多少数据算梯度"分为三档：**BGD**（全量，梯度真但慢）、**SGD**（1 个样本，快且有噪声）、**Mini-batch GD**（32/64 一小批，实践中默认）。
- 适用范畴：线性回归 MSE、逻辑回归交叉熵，以及深度学习等一切以梯度训练的模型；对凸问题（线性回归/MSE）保证收敛到全局最小，对非凸问题只保证局部最优。
- 注意语境：深度学习里说的 "SGD" 常泛指"小批量梯度下降 + 动量/Adam"，与严格意义的单样本 SGD 不同。

## 原理
- 出发点：损失 $J(w)$ 是参数空间上的一个曲面，梯度 $\nabla J$ 指向**上升最快的方向**，因此 $-\nabla J$ 就是局部下降最快的方向；沿它迈步长为 $\eta$ 的步，即 $w \leftarrow w - \eta \nabla_w J(w)$，反复迭代即可滚向谷底。
- 为什么用负梯度：把 $J$ 在 $w$ 处一阶 Taylor 展开 $J(w+\Delta)\approx J(w)+\nabla J^\top \Delta$，要让 $J$ 下降需 $\nabla J^\top \Delta<0$；在步长约束下取 $\Delta=-\eta\nabla J$ 使内积 $=-\eta\|\nabla J\|^2<0$，是局部最优的下降方向——这是"为什么这样设计"的数学依据。
- 学习率 $\eta$ 决定步长：太大越过谷底来回震荡甚至发散，太小收敛极慢；实践中看 loss 曲线调，或用学习率调度 / 自适应算法（Adam）。
- 落到线性回归：损失 $J(w)=\frac{1}{n}\sum_{i}(w^\top x_i-y_i)^2$；把所有样本排成设计矩阵 $X$（每行一个样本）并在左侧补一列全 1 当截距项后，梯度可写成矩阵形式：
$$\nabla_w J = \frac{2}{n}X^\top (Xw-y)$$
即"误差向量 $Xw-y$ 与特征的内积再乘 $2/n$"，写成代码就是最简 SGD 循环：`w = w - lr * (2/n * X.T @ (X@w - y))`。
- 三个版本的本质差异是**梯度的估计量**：BGD 用全部 $n$ 个样本得真实梯度，方向稳但每步 $O(n)$；SGD 只用 1 个样本，是无偏但有噪声的估计，快、噪声还能帮跳出局部极小，但曲线抖；Mini-batch 取折中，且向量化后吞吐最高，是深度学习实践默认。
- 两个容易忽略的机制细节：① 随机梯度要求数据先 **shuffle**，否则按原始顺序遍历会引入偏置；② 损失用 **均值（mean）** 而非求和（sum），否则梯度被 batch 大小放大、步长失真。

## 应用
- 典型场景：线性回归 / 逻辑回归的参数训练，以及神经网络、深度学习的反向传播训练；凡是"损失可微、解析解不可行"的优化问题都能用。
- 快速上手步骤：① 特征标准化（StandardScaler），消除量纲差异；② 写出损失与梯度（手推或自动微分）；③ 初始化参数（如全 0 或小随机）；④ 外层 epoch 循环：先 shuffle 数据，再按 mini-batch（32/64）切分；⑤ 每批执行 $w \leftarrow w - \eta \cdot \text{grad}$；⑥ 记录 loss 曲线，据其调学习率或换调度 / Adam。
- 学习率怎么选（核心坑）：$\eta$ **太大** → 发散震荡不收敛；$\eta$ **太小** → 收敛极慢；实践从 0.01~0.1 小值试起，观察 loss 是否单调下降，再配合学习率调度或 Adam 自适应。
- 特征量纲差很大 → 梯度在某些方向被迫走极小步、收敛慢：**先标准化**（StandardScaler）。
- 数据不打散就 SGD → 收敛受样本顺序偏置：每次 epoch **先 shuffle**。
- 随机梯度噪声大、单步 loss 不降甚至上升 → 别误判模型坏了：看一段窗口的**平均 loss**，或换 mini-batch / 加动量。
- 梯度没除 $n$（用了 sum 不用 mean）→ 步长被 batch 放大、训练不稳：**一律用均值损失**。
- 边界认知：凸问题（线性回归 + MSE）梯度下降保证收敛到全局最小；非凸（深度学习）只保证局部最优，需靠初始化与调度改善。

```python
# 梯度下降与 SGD 实现线性回归（含注释的代码示例 + 案例详解）
import numpy as np

# ---------- 1. 造数据：y ≈ 2*x1 - 1*x2 + 3（真实参数 [2, -1, 3]） ----------
rng = np.random.default_rng(42)
n, d = 1000, 2
X = rng.standard_normal((n, d))          # 两列特征（量纲相近，无需标准化演示）
true_w = np.array([2.0, -1.0, 3.0])      # [w1, w2, b]
Xb = np.hstack([X, np.ones((n, 1))])     # 左侧补全 1 列当截距 -> (n, 3)
y = Xb @ true_w + rng.normal(0, 0.1, n)  # 加高斯噪声

def batch_grad(w, Xb, y):
    """BGD 全量梯度：(2/n) * X^T (Xw - y)。注意除以 n —— 用均值损失"""
    return 2.0 / len(y) * Xb.T @ (Xb @ w - y)

# ---------- 2. BGD：每个 epoch 用全部样本算真实梯度，稳但慢 ----------
w = np.zeros(3)
lr = 0.05
for _ in range(200):                      # 每步都在全量数据上更新一次
    w = w - lr * batch_grad(w, Xb, y)
print("BGD 结果:", np.round(w, 3))        # 期望约 [2.0, -1.0, 3.0]

# ---------- 3. Mini-batch SGD：一次一小批，实践默认；顺带演示坑 ----------
w = np.zeros(3)
lr = 0.05
epochs, batch_size = 30, 32
for epoch in range(epochs):
    idx = rng.permutation(n)              # 坑①：每轮先 shuffle，避免顺序偏置
    for i in range(0, n, batch_size):
        j = idx[i:i + batch_size]         # 取一批样本下标
        # 坑②：梯度要除以批大小 len(j)，而不是样本总数 n —— 保持均值损失
        grad = 2.0 / len(j) * Xb[j].T @ (Xb[j] @ w - y[j])
        w = w - lr * grad
print("Mini-batch SGD 结果:", np.round(w, 3))

# ---------- 4. 案例详解 ----------
# ① 两种方法都收敛到 [2, -1, 3] 附近（误差来自噪声项 0.1），说明梯度公式正确；
# ② BGD 每轮只更新 1 次但用全量梯度，Mini-batch 每轮更新 n/batch_size≈31 次，
#    后者大数据下每步成本低、总吞吐更高 —— 这正是深度学习中默认 mini-batch 的原因；
# ③ 若把上面除以 len(j) 改成除以 n，梯度被 batch 放大 ~30 倍，loss 会发散 ——
#    验证"必须用均值损失"这条坑；
# ④ 若把 lr 调到 0.5，可看到 loss 震荡不收敛 —— 对应"学习率太大会发散"的坑。
```

## 对比选型
| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| 本文方案：梯度下降（BGD / Mini-batch / SGD） | 沿负梯度方向按学习率迭代更新参数，逐步逼近（局部）最小 | 数据大 / 特征多、无解析解：线性回归、逻辑回归与深度学习训练 |
| 正规方程（解析解） | 解 $\nabla_w J=0$ 得闭式解 $w=(X^\top X)^{-1}X^\top y$，不迭代 | 小规模线性回归：样本与特征都少（如 <1 万样本、<100 特征） |
| 纯 SGD（batch=1） | 每步只用 1 个样本估计梯度，更新极快、有噪声可跳出局部极小 | 流式 / 在线学习；对训练抖动不敏感的小模型 |
