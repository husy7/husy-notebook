# 线性模型：线性回归与逻辑回归

## 一、核心思想

线性模型假设**输出是输入特征的线性组合**。它是最简单、最可解释的一类模型，也是深度学习全连接层的基础。

$$ \hat{y} = w^\top x + b $$

- **线性回归**：输出为连续实数，解决回归问题。
- **逻辑回归**：在线性回归基础上套上 Sigmoid 函数，输出落在 (0,1)，用于分类（二分类）与概率预测。

## 二、线性回归（Linear Regression）

### 2.1 模型与损失

模型输出 $\hat{y} = w^\top x + b$。用**均方误差（MSE）**衡量预测与真实的差距：

$$ \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2 $$

目标是通过梯度下降（或正规方程）最小化 MSE。

### 2.2 求解方式

| 方法 | 原理 | 适用场景 |
|------|------|----------|
| **正规方程** | 直接求闭式解 $\theta = (X^\top X)^{-1}X^\top y$ | 维度低、样本适中 |
| **梯度下降** | 迭代沿负梯度方向更新参数 | 高维、大数据 |

### 2.3 sklearn 示例

```python
import numpy as np
from sklearn.linear_model import LinearRegression

X = np.array([[1], [2], [3], [4], [5]])
y = np.array([3, 5, 7, 9, 11])            # y = 2x + 1

model = LinearRegression().fit(X, y)
print(model.coef_, model.intercept_)      # [2.0] 1.0
print(model.predict([[6]]))               # [13.0]
```

## 三、逻辑回归（Logistic Regression）

### 3.1 从线性到概率

对线性输出做 Sigmoid 变换，映射到 (0,1) 作为概率：

$$ \hat{p} = \sigma(w^\top x + b) = \frac{1}{1 + e^{-(w^\top x + b)}} $$

预测类别：$\hat{p} \ge 0.5$ 判为类别 1，否则为类别 0。

### 3.2 为什么用交叉熵而非 MSE

逻辑回归用**二元交叉熵（log-loss）**作为损失：

$$ L = -\frac{1}{n} \sum_{i} \left[ y_i \log \hat{p}_i + (1-y_i) \log(1-\hat{p}_i) \right] $$

因为 Sigmoid + MSE 会带来**非凸、梯度饱和**问题（预测错得很远时梯度反而很小），导致收敛慢；交叉熵是凸的且梯度合理。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)
y_bin = (y == 0).astype(int)              # 二分类演示

clf = LogisticRegression(max_iter=1000).fit(X, y_bin)
print(clf.predict_proba([[5.1, 3.5, 1.4, 0.2]]))  # [P(class=0), P(class=1)]
```

## 四、正则化：防止过拟合

当特征多、样本少时，模型易记住噪声（过拟合）。正则化在损失函数上加入对参数大小的惩罚：

| 正则化 | 惩罚项 | 效果 | 对应方法 |
|--------|--------|------|----------|
| **L2（Ridge）** | $\lambda \lVert w \rVert_2^2$ | 参数整体缩小，趋于均匀的小值 | Ridge 回归 |
| **L1（Lasso）** | $\lambda \lVert w \rVert_1$ | 参数退化为 0，实现**特征选择** | Lasso |
| **弹性网** | L1 + L2 混合 | 兼顾二者 | ElasticNet |

> 💡 L1 为何能产生稀疏解？L1 约束在参数空间形成"菱形"边界，最优解更容易落在坐标轴上（某维度为 0）。

## 五、边界与坑

- ❌ **特征未标准化**时，逻辑回归/梯度下降收敛慢，且 L1/L2 正则化会偏向量纲大的特征。✅ 先做 StandardScaler 标准化。
- ❌ **线性不可分问题**（如 XOR）线性模型永远无法拟合。✅ 改用核方法、引入多项式特征，或换非线性模型。
- ❌ **共线性**导致正规方程解不稳定、系数方差大。✅ 用正则化（Ridge）或 PCA 降维。
- ❌ **类别不平衡**时用准确率评估会失真。✅ 结合 F1、AUC，或设置 `class_weight`。
- 边界：逻辑回归是线性**决策边界**模型，适合低维高信噪比数据；对高维稀疏文本数据易退化为简单线性可分假设。

## 六、关联

- 前置知识：梯度下降、极大似然估计（MLE → 交叉熵）。
- 进阶知识：Softmax 回归（多分类）→ 深度学习的输出层；GLM（广义线性模型）。
- 类似概念：感知机（无概率输出、硬阈值）vs 逻辑回归（软概率输出）。
