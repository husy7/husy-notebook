# 线性模型：线性回归与逻辑回归

## 定义

线性模型（Linear Model）是机器学习中最基础的一类模型，核心假设是**输出是输入特征的线性组合** $\hat{y} = w^\top x + b$。它解决的是一大类"从特征到目标"的预测问题，并且是理解深度学习全连接层（FC Layer）的起点——全连接层本质就是一个带激活函数的线性变换。本笔记聚焦其两大支柱：

- **线性回归（Linear Regression）**：输出为连续实数，解决**回归（Regression）**问题，例如房价、销量、温度预测。
- **逻辑回归（Logistic Regression）**：在线性组合上套一层 Sigmoid 函数，把输出压缩到 (0,1)，用于**二分类（Binary Classification）与概率预测**，是工业界最常用的分类基线模型。

核心特征可概括为三点：**简单**（训练快、推理快）、**可解释**（系数 $w$ 直接反映每个特征的贡献方向与大小）、**可扩展**（是 Softmax 多分类、深度学习输出层的构建基石）。适用范畴上，它擅长"特征与目标近似线性、信噪比高"的数据；当数据非线性、特征高度相关或维度极高时，则需要正则化、特征工程乃至非线性模型辅助。

## 原理

**统一框架**：线性回归与逻辑回归共享线性假设 $\hat{y} = w^\top x + b$，区别只在最后的"输出映射 + 损失函数"设计。

**1. 线性回归（最小化均方误差 MSE）**。模型输出 $\hat{y} = w^\top x + b$，用 MSE 衡量预测与真实的差距：

$$ \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2 $$

最小化 MSE 有两种主流求解方式，两者本质等价（梯度为零时收敛到同一目标）：

| 方法 | 原理 | 适用场景 |
|------|------|----------|
| **正规方程（Normal Equation）** | 直接求闭式解 $\theta = (X^\top X)^{-1}X^\top y$ | 维度低、样本适中 |
| **梯度下降（Gradient Descent）** | 沿损失负梯度迭代更新参数 $w \leftarrow w - \eta \nabla_w \text{MSE}$ | 高维、大数据（无法一次性求逆） |

**2. 逻辑回归（Sigmoid 映射 + 交叉熵）**。对线性输出做 Sigmoid 变换映射到 (0,1)，作为正类概率：

$$ \hat{p} = \sigma(w^\top x + b) = \frac{1}{1 + e^{-(w^\top x + b)}} $$

预测规则：$\hat{p} \ge 0.5$ 判为类别 1，否则为类别 0；因此**决策边界是超平面** $w^\top x + b = 0$——这正是"逻辑回归是线性边界模型"的由来。损失使用**二元交叉熵（log-loss）**：

$$ L = -\frac{1}{n} \sum_{i} \left[ y_i \log \hat{p}_i + (1-y_i) \log(1-\hat{p}_i) \right] $$

**为什么用交叉熵而不用 MSE？** 关键推导：Sigmoid 的导数 $\sigma'(z) = \sigma(z)(1-\sigma(z))$，当 $|z|$ 很大（预测错得离谱）时 $\sigma' \to 0$。若用 MSE，梯度中会乘上这一项，导致**预测错得越远、梯度反而越小（梯度饱和）**，收敛极慢；且 Sigmoid + MSE 的损失曲面**非凸**。而交叉熵由极大似然估计（MLE）推导而来，损失是凸的，其梯度正比于残差 $\hat{p}_i - y_i$，预测越错梯度越大、更新越快。

**3. 正则化（防止过拟合）**。当特征多、样本少时，模型易记住噪声。正则化在损失函数上加入对参数大小的惩罚：

| 正则化 | 惩罚项 | 效果 | 对应方法 |
|--------|--------|------|----------|
| **L2（Ridge）** | $\lambda \lVert w \rVert_2^2$ | 参数整体缩小，趋于均匀的小值 | Ridge 回归 |
| **L1（Lasso）** | $\lambda \lVert w \rVert_1$ | 参数退化为 0，实现**特征选择** | Lasso |
| **弹性网（ElasticNet）** | L1 + L2 混合 | 兼顾二者（特征选择 + 稳定收缩） | ElasticNet |

> 💡 **L1 为何能产生稀疏解？** L1 约束在参数空间形成"菱形（L1 ball）"边界，其顶点在坐标轴上，因此最优解更容易落在坐标轴上（部分维度恰好为 0）；而 L2 是圆形边界，切点几乎不可能落在坐标轴，只会整体缩小参数。

## 应用

**典型使用场景**：① 任何二分类任务的第一个 baseline（工业界默认起点，如风控违约预测、医疗筛查、CTR 预估早期方案）；② 需要概率输出的场景（`predict_proba` 可对接阈值调优与业务决策）；③ 需要解释特征影响力的场景（直接读系数 $w$，可配合 L1 做特征选择）；④ 连续值回归与趋势预测。

**快速上手步骤**：1) 加载数据并划分 train/test；2) 特征标准化 `StandardScaler`；3) 训练 `LinearRegression().fit(X, y)` 或 `LogisticRegression(max_iter=1000).fit(X, y)`；4) 回归看 MSE/R²，分类看 F1/AUC（类别不平衡时勿只看准确率）；5) 必要时加正则化或 `class_weight`。

**易错点与坑（务必注意）**：
- ❌ **特征未标准化**：梯度下降收敛慢，且 L1/L2 正则化会偏向量纲大的特征。✅ 先做 StandardScaler 标准化。
- ❌ **线性不可分问题**（如 XOR）：线性模型永远无法拟合。✅ 改用核方法、引入多项式特征（PolynomialFeatures），或换非线性模型。
- ❌ **共线性**：导致 $X^\top X$ 接近奇异，正规方程解不稳定、系数方差大。✅ 用正则化（Ridge）或 PCA 降维。
- ❌ **类别不平衡**：用准确率评估会严重失真。✅ 结合 F1、AUC 评估，或设置 `class_weight='balanced'`。
- **边界认知**：逻辑回归是线性**决策边界**模型，适合低维高信噪比数据；对高维稀疏文本数据容易退化为简单线性可分假设。

**自我检验（原笔记复习题，供自测）**：1) 逻辑回归为什么用交叉熵而不是 MSE？2) 写出逻辑回归的决策边界方程。3) L1 与 L2 正则化的本质区别是什么？4) 线性回归与逻辑回归的损失函数各自是什么？

```python
# ============ 示例一：线性回归（连续值预测）============
import numpy as np
from sklearn.linear_model import LinearRegression

X = np.array([[1], [2], [3], [4], [5]])
y = np.array([3, 5, 7, 9, 11])            # 真值服从 y = 2x + 1

model = LinearRegression().fit(X, y)
print(model.coef_, model.intercept_)      # [2.0] 1.0 —— 学习到的斜率 2、截距 1
print(model.predict([[6]]))               # [13.0]  —— 外推预测 x=6 时 y=13

# ============ 示例二：逻辑回归（二分类 + 概率输出）============
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)
y_bin = (y == 0).astype(int)              # 把 iris 改成二分类：是否为 setosa

clf = LogisticRegression(max_iter=1000).fit(X, y_bin)
print(clf.predict_proba([[5.1, 3.5, 1.4, 0.2]]))
# 输出形如 [[P(class=0), P(class=1)]]，两列和为 1；取 argmax 即得类别

# ============ 案例详解 ============
# 1) 示例一演示了"最小二乘拟合"：模型在训练集上直接求闭式解（sklearn 内部
#    默认使用基于 SVD 的求解器，数值更稳定），coef_=2、intercept_=1 与数据
#    生成规则 y=2x+1 完全一致，体现线性回归的可解释性。
# 2) 示例二演示逻辑回归的标准用法：先构造二分类标签，再 fit + predict_proba。
#    predict_proba 输出的是"属于各类的概率"（Sigmoid 概率值），而不是硬类别，
#    这正是逻辑回归相对感知机的核心优势——可输出置信度供业务决策。
# 3) 实操提醒：真实任务中请务必先对特征做 StandardScaler（本示例特征量纲
#    相近所以影响不大）；若 max_iter 不足导致未收敛告警，应调大 max_iter，
#    而不是盲目增加迭代容忍——未标准化才是收敛慢的常见根因。
```

## 对比选型
| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| 线性回归（本文方案） | 输出 = 特征线性组合，最小化 MSE（正规方程/梯度下降求解） | 连续值回归、低维高信噪比、需要系数可解释 |
| 逻辑回归（本文方案） | 线性组合 + Sigmoid 映射概率，最小化交叉熵 | 二分类、概率预测、分类任务的工业基线 |
| 感知机（替代方案） | 线性组合 + 硬阈值 0/1，误分类样本驱动更新 | 无概率需求的教学/简单在线二分类 |
| 核方法/非线性模型（替代方案） | 核技巧把特征映射到高维空间，或直接建模非线性结构 | XOR 等线性不可分、复杂非线性模式 |

> 补充说明：当任务是"多分类"时，把逻辑回归升级为 Softmax 回归即可；当任务是回归但线性拟合欠佳时，可先做特征工程/多项式扩展，仍不行再换决策树类或神经网络模型。
