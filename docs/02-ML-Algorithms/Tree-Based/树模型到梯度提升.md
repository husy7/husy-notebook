# 树模型：决策树到梯度提升

## 一、核心思想

树模型通过**递归地按特征划分样本**，最终形成一棵"决策树"。每个叶子节点给出一类预测。它天然处理非线性和特征交互，且不需要特征标准化。

单棵树的表达能力有限、易过拟合，因此现代实践中核心是用**集成学习**组合多棵树：

- **Bagging**（并行）：随机森林 —— 降低方差。
- **Boosting**（串行）：GBDT/XGBoost/LightGBM —— 降低偏差。

## 二、决策树：树的构建核心

### 2.1 划分准则

划分目标：让分裂后子节点的**纯度**最大化。常用三种准则：

| 准则 | 公式思想 | 特点 |
|------|----------|------|
| **信息增益**（ID3） | 熵减少量 | 偏向取值多的特征 |
| **增益率**（C4.5） | 信息增益 / 固有值 | 校正 ID3 偏置 |
| **基尼指数**（CART） | 基尼不纯度 | 分类常用，二叉树 |

**熵**定义：$H = -\sum_{k} p_k \log_2 p_k$，熵越小纯度越高。

### 2.2 决策树 sklearn 示例

```python
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)

dt = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_tr, y_tr)
print(dt.score(X_te, y_te))   # 0.977...
```

## 三、随机森林（Random Forest）

- **并行**训练多棵独立树。
- 每棵树的训练集用 **Bootstrap 有放回抽样**，且每棵树的每个分裂只在**随机选取的特征子集**中找最优切分点。
- 预测时多数投票 / 取平均。
- **效果**：降低单棵树的方差，显著抑制过拟合，抗噪强，几乎不需要精细调参。

```python
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=100, random_state=0).fit(X_tr, y_tr)
print(rf.score(X_te, y_te))
```

## 四、梯度提升树（GBDT / XGBoost / LightGBM）

### 4.1 核心思想：串行拟合负梯度

Boosting 逐棵学习一棵树来**拟合上一轮的残差（负梯度）**，不断降低偏差：

1. 初始化一个常数模型 $F_0$。
2. 每轮计算当前模型在样本上的残差 $r_i = y_i - F_{m-1}(x_i)$。
3. 用一棵回归树去拟合 $r_i$。
4. $F_m = F_{m-1} + \eta \cdot \text{tree}_m$（$\eta$ 为学习率）。
5. 重复，生成一个强模型。

### 4.2 经典实现对比

| 工具 | 关键改进 | 适合场景 |
|------|----------|----------|
| **GBDT** | 原始梯度提升框架 | 学习原理 |
| **XGBoost** | 二阶泰勒展开、正则化、列抽样、自动缺失值处理 | 通用强 baseline |
| **LightGBM** | 直方图算法（Histogram）、GOSS 采样、**Leaf-wise** 生长 | 大数据、快 |
| **CatBoost** | 目标编码处理类别特征、对称树 | 类别特征多 |

### 4.3 XGBoost 示例

```python
import xgboost as xgb

model = xgb.XGBClassifier(
    n_estimators=100, learning_rate=0.1,
    max_depth=5, use_label_encoder=False, eval_metric="logloss"
).fit(X_tr, y_tr)
print(model.score(X_te, y_te))
```

## 五、Bagging vs Boosting

| 维度 | Bagging（随机森林） | Boosting（GBDT 系） |
|------|--------------------|--------------------|
| 训练方式 | 并行 | 串行 |
| 优化目标 | 降方差 | 降偏差 |
| 对噪声 | 鲁棒 | 易过拟合噪声 |
| 参数意义 | 树多、特征采样 | 且模型更强 |

## 六、边界与坑

- ❌ 单棵 **不剪枝的决策树**严重过拟合。✅ 限制 `max_depth` / 用集成。
- ❌ Boosting 在**噪声大、离群点多**的数据上易过拟合。✅ 减小 `learning_rate`、增大正则。
- ❌ 树模型对**高维稀疏**（如 one-hot 文本）学习较差。✅ 用适合稀疏的方案或换模型。
- ❌ 分类误差 + 正负样本极端不平衡时，Boosting 偏向多数类。✅ 加 `scale_pos_weight` / 阈值调整。
- 边界：树模型无隐式特征缩放，但对完全无规律的高维空间、以及需要外推预测场景表现有限。
