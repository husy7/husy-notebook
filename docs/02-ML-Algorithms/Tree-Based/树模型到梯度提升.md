# 树模型：决策树到梯度提升

## 定义

树模型是一类通过**递归地按特征划分样本**来逼近目标函数的监督学习方法：从根节点开始，每次选择一个特征及其切分点把当前样本集分裂成更"纯"的子集，重复直到满足停止条件，最终形成一棵"决策树"，每个叶子节点给出一类预测值。

它解决的核心问题是：线性模型难以表达的**非线性关系**与**特征间交互**。树模型不需要任何特征标准化/归一化，对特征量纲不敏感，天然能处理数值与类别混合的表格型数据。

单棵树的表达能力有限且极易过拟合，因此现代实践中真正的主角是**集成学习（Ensemble Learning）**——把多棵树组合成强模型：

- **Bagging（并行）**：以随机森林为代表，多棵树独立并行训练，靠降低方差抑制过拟合。
- **Boosting（串行）**：以 GBDT / XGBoost / LightGBM / CatBoost 为代表，逐棵串行拟合残差，靠降低偏差逼近强模型。

适用范畴：绝大多数**结构化表格数据**上的分类、回归、排序任务，是 Kaggle 竞赛中的最强 baseline 之一；同时树的特征重要性输出也常被用于特征筛选与模型可解释性分析（如 SHAP）。其边界在于：对高维稀疏数据（如 one-hot 文本）与需要外推预测的场景表现有限。

## 原理

### 树的构建核心：划分准则

划分目标是在每个节点选出"使分裂后子节点纯度最大"的特征与阈值。常用三种准则：

| 准则 | 公式思想 | 特点 |
|------|----------|------|
| **信息增益**（ID3） | 熵减少量 | 偏向取值多的特征 |
| **增益率**（C4.5） | 信息增益 / 固有值 | 校正 ID3 偏置 |
| **基尼指数**（CART） | 基尼不纯度 | 分类常用，二叉树 |

**熵**定义：$H = -\sum_{k} p_k \log_2 p_k$，熵越小纯度越高。ID3 每次选信息增益最大的特征分裂，C4.5 用增益率消除对多取值特征的偏好，CART 用基尼指数并强制生成二叉树。

### 为什么单棵树不行：方差 vs 偏差

不剪枝的深树能零误差拟合训练集，但在新样本上泛化差——方差过大。集成思想把"多个有差异的弱模型"合并成强模型：

- **Bagging（随机森林）**：对训练集做 **Bootstrap 有放回抽样**生成每棵树的样本，且每个分裂点只在**随机选取的特征子集**中找最优切分，最后多数投票/取平均。树与树之间的随机差异让误差相互抵消，**降低方差**、抑制过拟合、抗噪强。
- **Boosting（GBDT 系）**：每棵新树都去**拟合上一轮模型的残差（负梯度）**，残差 = 模型还没学会的部分，逐轮补上，**降低偏差**。

### GBDT 串行拟合负梯度流程

1. 初始化一个常数模型 $F_0$（如预测均值/众数）。
2. 每轮计算当前模型在样本上的残差 $r_i = y_i - F_{m-1}(x_i)$。
3. 用一棵回归树去拟合 $r_i$。
4. $F_m = F_{m-1} + \eta \cdot \text{tree}_m$（$\eta$ 为学习率，起缩步作用）。
5. 重复以上步骤，串行累加出强模型。

XGBoost 在其上做了工程与理论双重增强：损失函数**二阶泰勒展开**、对叶子权重与树结构加正则项、列抽样、自动缺失值处理；LightGBM 引入**直方图算法（Histogram）**、GOSS 采样与 **Leaf-wise** 生长，训练更快；CatBoost 用目标编码处理类别特征、构建对称树。

### Bagging vs Boosting

| 维度 | Bagging（随机森林） | Boosting（GBDT 系） |
|------|--------------------|--------------------|
| 训练方式 | 并行 | 串行 |
| 优化目标 | 降方差 | 降偏差 |
| 对噪声 | 鲁棒 | 易过拟合噪声 |
| 参数意义 | 树多、特征采样 | 学习率小则模型更强 |

## 应用

典型使用场景：结构化表格数据的分类/回归/排序，特征重要性分析与可解释性（SHAP），以及数据量中等的通用强 baseline。

快速上手步骤：

1. 数据准备：补缺失值（XGBoost/LightGBM 原生支持缺失值可省略）、类别特征编码、划分训练/测试集；**无需特征缩放**。
2. 先用默认参数的随机森林或 XGBoost 跑通 baseline，确认数据管线无误。
3. 再按工具选型升级并调参：优先调 `n_estimators`（树的数量）、`learning_rate`（学习率）、`max_depth`（深度）与正则项。

工具选型（经典实现对比）：

| 工具 | 关键改进 | 适合场景 |
|------|----------|----------|
| **GBDT** | 原始梯度提升框架 | 学习原理 |
| **XGBoost** | 二阶泰勒展开、正则化、列抽样、自动缺失值处理 | 通用强 baseline |
| **LightGBM** | 直方图算法、GOSS 采样、**Leaf-wise** 生长 | 大数据、追求速度 |
| **CatBoost** | 目标编码处理类别特征、对称树 | 类别特征多 |

常见坑与对策：

- ❌ 单棵**不剪枝的决策树**严重过拟合 → ✅ 限制 `max_depth` / 改用集成模型。
- ❌ Boosting 在**噪声大、离群点多**的数据上易过拟合 → ✅ 减小 `learning_rate`、增大正则（`reg_lambda` 等）。
- ❌ 树模型对**高维稀疏**（如 one-hot 文本）学习较差 → ✅ 改用适合稀疏的方案或换线性模型。
- ❌ 分类任务 + 正负样本极端不平衡时，Boosting 偏向多数类 → ✅ 加 `scale_pos_weight` / 调整决策阈值。
- ⚠️ 边界：树模型无隐式特征缩放，但对完全无规律的高维空间、以及需要**外推预测**（超出训练数据范围）的场景表现有限。

```python
# ========== 1. 决策树（sklearn）==========
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)  # 鸢尾花：4 个数值特征、3 类
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)

# max_depth=3 限制深度，防止不剪枝导致的严重过拟合
dt = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_tr, y_tr)
print(dt.score(X_te, y_te))   # 0.977...，可 dt.tree_ 查看分裂结构

# ========== 2. 随机森林（Bagging，降方差）==========
from sklearn.ensemble import RandomForestClassifier

# 100 棵并行训练的树；每棵用 Bootstrap 抽样 + 随机特征子集分裂
rf = RandomForestClassifier(n_estimators=100, random_state=0).fit(X_tr, y_tr)
print(rf.score(X_te, y_te))   # 通常高于单棵决策树，且更抗过拟合

# ========== 3. XGBoost（Boosting，降偏差）==========
import xgboost as xgb

# learning_rate 即上文的 η：越小模型越强但需更多树（n_estimators 相应加大）
# 注：新版本 xgboost 已移除 use_label_encoder，且多分类 eval_metric 建议用 "mlogloss"
model = xgb.XGBClassifier(
    n_estimators=100, learning_rate=0.1,
    max_depth=5, use_label_encoder=False, eval_metric="logloss"
).fit(X_tr, y_tr)
print(model.score(X_te, y_te))

# 案例详解：同一份鸢尾花数据，单棵浅树 → 随机森林 → GBDT 系逐级增强。
# 泛化实践：先用 RF 默认参数建立 baseline，再换 XGBoost/LightGBM 精调
# learning_rate 与正则项；对比验证集分数而非训练集分数。
```

## 对比选型

| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| 本文方案（梯度提升树 GBDT/XGBoost/LightGBM） | 串行逐棵拟合负梯度（残差），用学习率 η 缩步，降低偏差 | 结构化表格数据的分类/回归/排序，追求精度的通用强 baseline |
| 替代方案 1（随机森林，Bagging） | 并行 Bootstrap + 随机特征子集建多棵树，投票/平均降方差 | 噪声大、离群点多、需鲁棒与少调参的场景 |
| 替代方案 2（线性模型） | 特征加权求和，假设线性关系，显式可解释 | 高维稀疏文本、需要外推预测或强业务解释性的场景 |
