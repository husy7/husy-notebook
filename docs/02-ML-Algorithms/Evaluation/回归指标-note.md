# 回归指标：MSE / RMSE / MAE / R²

## 定义

回归评估要回答的核心问题是两件事：**预测误差有多大**、**模型解释了数据中多少变化**。围绕这两个问题形成两族指标：

- **误差量纲族**（MSE / RMSE / MAE）：误差的绝对大小，只有单位与 y 一致时数值才有业务意义（"平均偏差 3.2 万元"）。
- **归一化解释族**（R²）：模型解释的变异占比，无量纲、可与不同任务粗略比较。

两族指标最大的分歧在于**怎么对待离群点**——MSE 系通过平方把离群误差非线性放大（一个错 10 的样本顶一百个错 1 的样本），MAE 对每个样本一视同仁，R² 通过"与猜均值对比"给出模型相对解释力。因此指标选择本质上是**对离群误差的立场选择**，而非纯粹的数学偏好。

适用范畴：所有回归任务的模型评估、训练损失函数的设计参考（MSE/MAE 同时是最常用的损失）、以及跨模型/跨任务的横向比较（此时必须用无量纲形式，如 R² 或归一化误差）。实践中通常在**同一测试集**上同时报告多个指标：量纲指标给业务可读性，R² 给解释力度，指标之间的落差本身又是新的诊断信息。

## 原理

指标为什么这样设计、彼此之间是什么关系：

- **MSE = mean((ŷ−y)²)**：平方让**大误差的代价非线性放大**——一个错 10 的样本顶一百个错 1 的样本。优点是可导且处处光滑，梯度好算，所以是训练损失的首选；代价是对离群点过度敏感。
- **RMSE = √MSE**：开方把单位拉回 y 的量纲，方便和业务口径直接对比（"平均偏差 3.2 万元"）；但对离群值的放大与 MSE 完全相同。
- **MAE = mean|ŷ−y|**：对异常值**鲁棒**（不放大），对应的是"预测中位数"为最优解（median regression 的天然目标）；但零点不可导让梯度优化不便，通常只当评估指标。
- **为什么同时报 RMSE 和 MAE**：两者之差本身就是诊断信息——RMSE ≫ MAE 说明**存在少数大离群误差**在拉扯平方和，此时应查残差、考虑清洗数据或换鲁棒目标（Huber / 分位数回归）。
- **R² = 1 − SS_res/SS_tot**：把模型残差平方和与"猜均值"（SS_tot）作比。R²=1 完美；R²=0 等价于常数预测均值；**R²<0 表示比直接猜均值还差**（模型被离群点带偏或结构选错，这不是 bug）。注意 R² 不是"相关系数的平方"的简单直觉——样本量、是否含截距都会影响其取值，跨数据集直接比较 R² 也要小心。
- **MAPE = mean(|ŷ−y|/|y|)**：直观（百分比口径），但 **y→0 时爆炸**、对低估惩罚不对称（同样偏差在 y 小时相对误差被夸大），很多场合应改用 SMAPE（对称化）或 WAPE（按总量加权）代替。
- **与损失函数家族的对应关系**：L2（MSE）⇄ L1（MAE）⇄ Huber（折中、带 δ 阈值）⇄ 分位数损失（预测区间）——每个评估指标的数学性质都直接来自对应损失的构造动机，选评估指标与选训练损失必须配套考虑。

## 应用

典型使用场景：

- 在**同一测试集**上评估回归模型：RMSE/MAE 给业务方量纲可读的误差，R² 给模型解释力度；
- 训练用 MSE 而业务更在乎离群容忍时，把训练损失换成 Huber/MAE，保证**优化目标与业务目标一致**；
- 跨模型/跨任务比较时用无量纲的 R² 或归一化误差（如除以 y 均值）；同任务内直接比较量纲指标即可。

快速上手（核心流程）：

1. 先在**同一测试集**上算 RMSE + MAE + R² 三件套，量纲指标给业务可读性，R² 给解释力度；
2. RMSE ≫ MAE → 查残差直方图/残差图找离群样本，决定是清洗、换 Huber 损失还是分位数回归；
3. 跨模型/跨任务比较时用 R²（或归一化后的 RMSE/MAE）；同任务内比较量纲指标。

注意事项 / 常见坑：

- ❌ 只报一个数（尤其只报 R²）→ R² 高也可能有系统性偏差；✅ 配残差图看模式（漏斗形=异方差、弯月形=漏非线性项）。
- ❌ 拿 RMSE/MAE 跨"不同量纲的数据集"直接比大小 → 量纲不同不可比；先归一化再比。
- ❌ 用 MAPE 且 y 存在接近 0 的值 → 除零/爆炸；换 SMAPE 或用 WAPE。
- ❌ 训练损失用 MSE、评估却在意离群值容忍 → 优化目标与业务目标不一致；评估要鲁棒就换 Huber/MAE 做训练损失。
- ❌ 把 R²<0 当 bug → 它真实地告诉你"比猜均值更差"，常见于强离群或模型对测试分布失灵。
- ❌ 对 log 变换后的 y 算 R²，再与原始 y 的 R² 直接比较 → 变换改变误差尺度，语义不同。
- ❌ 忽略 0 附近绝对误差 vs 相对误差的语义差别——金融/销量类任务往往相对误差更有业务意义。

```python
# -*- coding: utf-8 -*-
"""回归指标三件套示例：MSE / RMSE / MAE / R²，含离群诊断与 MAPE 坑演示"""
import numpy as np
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

# 模拟数据：真实值 y 与模型预测 y_hat（8 个样本，含 1 个大误差样本 #3）
y     = np.array([3.0, -0.5, 2.0, 7.0, 4.2, 1.8, 6.0, 3.9])
y_hat = np.array([2.5,  0.0, 2.1, 9.5, 5.3, 1.4, 5.9, 3.5])  # 样本 #3 偏差 2.5，刻意放大

# 1) 误差量纲族
mse  = mean_squared_error(y, y_hat)                # 平方误差均值：大误差被非线性放大
rmse = np.sqrt(mse)                                # 开方拉回 y 量纲，可和业务口径直接比
mae  = mean_absolute_error(y, y_hat)               # 绝对值均值：对离群样本一视同仁

# 2) 归一化解释族
r2 = r2_score(y, y_hat)                            # 1 - SS_res/SS_tot，解释力占比

print(f"MSE  = {mse:.4f}")
print(f"RMSE = {rmse:.4f}")
print(f"MAE  = {mae:.4f}")
print(f"R²   = {r2:.4f}")

# 3) 诊断：RMSE 明显大于 MAE => 存在少数大误差样本在拉扯平方和（本例即样本 #3）
gap = rmse - mae
print(f"RMSE - MAE = {gap:.4f}  (越大说明离群大误差越明显，应查残差图定位)")

# 4) MAPE 的坑：公式直观，但 y 接近 0 时爆炸、对低估惩罚不对称
def mape(y_true, y_pred):
    return np.mean(np.abs((y_true - y_pred) / y_true)) * 100  # 除 y：y→0 时数值爆炸

print(f"MAPE = {mape(y, y_hat):.2f}%   # 若 y 含 0/近 0 值，请改用 SMAPE 或 WAPE")

# 5) 小样本结论仅供流程演示；正式评估应在同一测试集上报 RMSE + MAE + R² 三件套，
#    并配残差图看模式（漏斗形=异方差、弯月形=漏非线性项），而非只报一个 R²。
```

## 对比选型
| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| 本文方案：MSE/RMSE/MAE/R² 组合 | 量纲误差（RMSE/MAE）+ 解释度（R²）互证，RMSE−MAE 差距作离群诊断 | 同一测试集上的常规回归评估、同任务跨模型比较 |
| MAPE | 相对百分比误差，业务直觉强 | y 远离 0、量纲随规模变化的任务（金额/销量类同比） |
| SMAPE / WAPE | 对称化或按总量加权，规避除零与不对称惩罚 | y 含 0 或近 0 值、需要鲁棒相对误差口径 |
