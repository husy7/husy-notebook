# 模型评估：指标、交叉验证与过拟合

## 一、核心思想

模型评估回答两个问题：**"模型表现如何？"（指标）** 与 **"结果是否可信？"（验证方法）**。评估的核心矛盾在于**过拟合**——模型记下了训练集的噪声而非规律。

**根本原则**：评估必须使用**模型从未见过的数据**（测试集 / 验证集），否则指标严重虚高。

## 二、分类指标

先定义混淆矩阵的四个元素：

| | 预测为正 | 预测为负 |
|----|---------|---------|
| **实际为正** | TP | FN |
| **实际为负** | FP | TN |

| 指标 | 公式/含义 | 适用 |
|------|-----------|------|
| **准确率 Accuracy** | $(TP+TN)/(总)$ | 类别均衡时 |
| **精确率 Precision** | $TP/(TP+FP)$，预测为正的里面有多少对 | 误报代价高（如垃圾邮件） |
| **召回率 Recall** | $TP/(TP+FN)$，真正的正样本找回了多少 | 漏报代价高（如癌症筛查） |
| **F1** | $2 \cdot \frac{P \cdot R}{P + R}$，P 与 R 的调和平均 | 类别不平衡、P/R 都要兼顾 |
| **AUC-ROC** | ROC 曲线下面积，衡量排序/区分能力 | 类别不平衡、阈值无关 |

> 💡 **精确率与召回率是一对矛盾**：把阈值调高 → Precision 升、Recall 降。F1 是折中。

```python
from sklearn.metrics import accuracy_score, precision_recall_fscore_support
from sklearn.metrics import roc_auc_score

y_true = [1, 0, 1, 1, 0, 1]
y_pred = [1, 0, 0, 1, 0, 1]
print(accuracy_score(y_true, y_pred))          # 0.833
p, r, f1, _ = precision_recall_fscore_support(y_true, y_pred, average="binary")
print(p, r, f1)
```

## 三、回归指标

| 指标 | 含义 |
|------|------|
| **MSE / RMSE** | 均方误差及其开方，惩罚大误差，量纲同原值（RMSE） |
| **MAE** | 平均绝对误差，对异常值更鲁棒 |
| **R²（决定系数）** | 模型比"直接平均"改善了百分之多少，≤1，越大越好 |

## 四、交叉验证：让评估可信

单次随机划分易受运气影响。**K 折交叉验证**把数据分成 K 份，轮流用其中 K-1 份训练、1 份验证，结果取平均：

- 常用 K=5 或 10。
- 比单次 `train_test_split` 更稳定、更充分地利用数据。

```python
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression

scores = cross_val_score(LogisticRegression(max_iter=1000), X, y, cv=5)
print(scores.mean(), scores.std())   # 平均分 + 波动
```

## 五、过拟合与偏差-方差

- **偏差（bias）**：模型简化造成的误差，→ 欠拟合。
- **方差（variance）**：模型对训练集波动敏感造成的误差，→ 过拟合。

| 状态 | 表现 | 对策 |
|------|------|------|
| **欠拟合** | 训练集与测试集都差 | 增加模型复杂度、加特征 |
| **过拟合** | 训练集好、测试集差 | 正则化、减少特征、更多数据、早停 |

**判断口诀**：训练误差 ≪ 测试误差 → 过拟合；训练误差本身就高 → 欠拟合。

## 六、测试集治理：避免数据泄漏

- ❌ 在**拟合特征选择器/标准化器之后再做交叉验证** → 验证集信息"泄漏"进训练，指标虚高。✅ 先划分再 fit（sklearn 的 `Pipeline` 可自动保证）。
- ❌ 用测试集反复调参选模型 → 测试集被"用脏"，指标虚高。✅ 拆出独立**验证集**调参，测试集只评估一次。

## 七、边界与坑

- ❌ **类别极度不平衡**时用 accuracy 会"看似很高"（全猜多数类）。✅ 用 Precision/Recall/F1/AUC。
- ❌ **回归数据有噪声**时 RMSE 受异常值影响大。✅ 补充 MAE 对比。
- ❌ 小数据集跑 K 折时训练集过小导致高方差，结果不可靠。✅ 增大 K 或用留一法（LOOCV，K=N）。
- 边界：AUC 反映排序能力而非绝对准确度，商业上还需结合阈值与业务代价。
