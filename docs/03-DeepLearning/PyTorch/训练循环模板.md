# PyTorch 训练循环模板

## 一、核心思想

PyTorch 训练一个模型的标准流程可拆成四步，循环复用：

> 定义**数据（Dataset/Dataloader）** → 定义**模型** → 定义**损失与优化器** → 跑 **train loop + eval loop**。

把流程固定成模板后，任何模型都能"填空式"训练，重点理解每个组件的职责。

## 二、组件逐个看

### 2.1 Dataset：定义"一份样本长什么样"

```python
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self, X, y):
        self.X, self.y = X, y

    def __len__(self):                 # 样本总数
        return len(self.y)

    def __getitem__(self, idx):        # 返回第 idx 个 (输入, 标签)
        return self.X[idx], self.y[idx]
```

### 2.2 Dataloader：批量 + shuffle + 并行取数

```python
from torch.utils.data import DataLoader

loader = DataLoader(MyDataset(X, y),
                    batch_size=64, shuffle=True, num_workers=4)
```

- `shuffle=True` 打乱（训练用），保序则 `False`（验证用）。
- 一次 `for batch in loader` 取出一批 `(inputs, labels)`。

### 2.3 训练循环骨架

```python
import torch.nn as nn
import torch.optim as optim

model   = nn.Sequential(nn.Linear(8, 16), nn.ReLU(), nn.Linear(16, 2))
loss_fn = nn.CrossEntropyLoss()
opt     = optim.Adam(model.parameters(), lr=1e-3)

def train_one_epoch(loader):
    model.train()                       # 启用训练模式（BN/Dropout）
    total, correct = 0, 0
    for inputs, labels in loader:
        opt.zero_grad()                 # ① 清空上次梯度
        out = model(inputs)             # ② 前向
        loss = loss_fn(out, labels)     # ③ 算损失
        loss.backward()                 # ④ 反向
        opt.step()                      # ⑤ 更新参数
        # 统计准确率...
    return avg_loss, accuracy

def evaluate(loader):
    model.eval()                        # 验证模式
    correct, total = 0, 0
    with torch.no_grad():               # 推理不建图，省显存
        for inputs, labels in loader:
            out = model(inputs)
            correct += (out.argmax(1) == labels).sum().item()
            total   += len(labels)

for epoch in range(10):

    va_acc = evaluate(val_loader)
    print(f"epoch {epoch}: train_loss={tr_loss:.3f} train_acc={tr_acc:.3f} val_acc={va_acc:.3f}")
```

## 三、关键约定（为什么这样做）

| 步骤 | 原因 |
|------|------|
| `model.train()` / `model.eval()` | 切换 BatchNorm/Dropout 行为，避免评估错误 |
| `opt.zero_grad()` | Ops 默认梯度累加，不清会叠加错梯度 |
| `loss.mean()` 而非 `.sum()` | 归一化损失，不受 batch 大小影响 |
| `with torch.no_grad()` | 验证不建立计算图，省显存 |

## 四、完整可运行示例（模拟分类）

```python
import torch, torch.nn as nn, torch.optim as optim
from torch.utils.data import Dataset, DataLoader

torch.manual_seed(0)
X = torch.randn(1000, 8)               # 1000 样本，8 特征
y = (X[:, 0] + X[:, 1] > 0).long()     # 构造二分类标签

class DS(Dataset):
    def __init__(self, X, y):
        self.X, self.y = X, y
    def __len__(self):
        return len(self.y)
    def __getitem__(self, i):
        return self.X[i], self.y[i]

train_loader = DataLoader(DS(X[:800], y[:800]), batch_size=64, shuffle=True)
val_loader   = DataLoader(DS(X[800:], y[800:]), batch_size=64)

model = nn.Sequential(nn.Linear(8, 16), nn.ReLU(), nn.Linear(16, 2))
loss_fn = nn.CrossEntropyLoss()
opt = optim.Adam(model.parameters(), lr=1e-2)

for epoch in range(20):
    model.train()
    run_acc, n = 0.0, 0
    for xb, yb in train_loader:
        opt.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward(); opt.step()
        run_acc += (model(xb).argmax(1) == yb).sum().item(); n += len(yb)
    model.eval()
    with torch.no_grad():
        va = (model(val_loader.dataset[:][0]).argmax(1) ==
              val_loader.dataset[:][1]).float().mean()
    print(f"epoch {epoch}: train_acc={run_acc/n:.3f} val_acc={va:.3f}")
```

## 五、常见坑

- ❌ 训练时忘记 `model.train()` → 用了验证模式统计，Loss/精度错乱。✅ 严格区分两模式。
- ❌ 分类标签是 `long()`，模型输出是 logits，却直接和 float 比较。✅ logits 用 `argmax`，标签转 long。
- ❌ 每 epoch `val_loader.dataset[:]` 可直接切，但真实项目建议建独立 val_loader 保持与训练一致的 `transform`。
- ❌ 大批次 + 大学习率直接上不收敛。✅ 学习率大致随 batch 增大而调大（linear scaling rule）。
- 边界：多卡（`DataParallel`/`DistributedDataParallel`）、混合精度（AMP）、断点续训超出本节骨架范围。
