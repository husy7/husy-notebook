# 优化器对比：SGD / Momentum / Adam / AdamW

## 一、核心思想

训练神经网络 = 在前向+反向求得梯度后，用**优化器（optimizer）**更新参数，使损失下降。不同优化器区别在于**如何利用梯度及其历史信息**，决定了收敛速度、稳定性与最终泛化能力。

$$\theta_{t+1} = \theta_t - \eta \cdot \text{update}(\nabla L(\theta_t))$$

## 二、常用优化器一览

| 优化器 | 更新逻辑 | 关键特性 | 适用 |
|--------|----------|----------|------|
| **SGD** | $\theta \gets \theta - \eta g$ | 朴素，沿负梯度 | 基线、理论清晰 |
| **SGD+Momentum** | 累加历史梯度的指数平均 | 加速、抑制震荡 | 需更稳定的收敛 |
| **Adam** | 自适应学习率：梯度一阶矩 + 二阶矩（RMS） | 快、对学习率不敏感，开箱即用 | 一般任务首选 |
| **AdamW** | Adam + 解耦权重衰减 | 正则化更稳，泛化更好 | LLM/Transformer 训练 |

> 💡 简记：Momentum 管"方向平滑"（一阶动量），RMSProp 管"每位特征尺度不同的自适应学习率"（二阶动量），Adam = 两者结合。

## 三、逐个解析

### 3.1 SGD（随机梯度下降）

用单个（或小批量 mini-batch）样本的梯度近似全量梯度。简单但：
- 收敛缓慢。
- 在曲率变化大的损失面上**震荡**（来回摆动）。

```python
import torch.optim as optim
opt = optim.SGD(model.parameters(), lr=0.01)
```

### 3.2 Momentum（动量）

维护梯度方向的指数移动平均 $v$，让更新带上"惯性"：

$$ v = \beta v + \eta g,\quad \theta \gets \theta - v,\quad (\beta\approx0.9) $$

- 平坦方向加速、震荡方向抵消 → 收敛更快更稳。

```python
opt = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
```

### 3.3 Adam

为每个参数维护二阶矩，自适应缩放学习率：

$$ m = \beta_1 m + (1-\beta_1)g $$
$$ v = \beta_2 v + (1-\beta_2)g^2 $$
$$ \hat{m} = \frac{m}{1-\beta_1^t},\ \hat{v} = \frac{v}{1-\beta_2^t}\ (\text{偏差校正}) $$
$$ \theta \gets \theta - \eta \frac{\hat{m}}{\sqrt{\hat{v}}+\epsilon} $$

- 参数更新量按梯度大小归一化 → 对学习率不敏感、稀疏梯度效果好。

```python
opt = optim.Adam(model.parameters(), lr=1e-3)
```

### 3.4 AdamW（W 代表解耦权重衰减）

传统 Adam 实现 L2 正则化时把权重衰减**混入梯度**，与 Adam 的自适应缩放耦合，导致正则效果被破坏。AdamW 将**权重衰减单独解耦**：

```text
普通 Adam+L2:   g_eff = g + λθ   （再走自适应缩放，λ 被缩放失真）
AdamW:         θ = θ - η·(normalized m/√v) - η·λθ   （λ 直接作用于 θ，不缩放）
```

- 已被 PyTorch 设为训练 Transformer/LLM 的默认选择，泛化更好。

```python
opt = optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
```

## 四、选型建议

| 场景 | 推荐 |
|------|------|
| 基础教学/理解 | SGD + Momentum |
| 通用 CV/NLP 模型 | Adam |
| Transformer / LLM / 深度大模型 | AdamW |
| 追求极致泛化、调参成本可接受 | SGD Warmup + Cosine 退火 |

> ⚠️ 深度学习（LLM、ViT 等）主流用 **AdamW + 学习率预热（warmup）+ 余弦退火**的配方。

## 五、边界与坑

- ❌ 深度学习时直接给 Adam 设过大 `lr`（如 0.1）→ 爆炸/不收敛。✅ LLM 训练常用 `lr≈3e-4~1e-3` 配合 warmup。
- ❌ 忘记 `scheduler` / 训练后期学习率恒定 → 收敛不足或在最小值附近震荡。✅ 配合学习率衰减。
- ❌ 对**类别极端不平衡或大学习率**的任务，Adam 的二阶矩偏大导致前期欠够学习。✅ 可用偏置校正、合适 weight_decay。
- ❌ SGD 无自适应，**特征量纲差异大**时收敛慢。✅ 先标准化特征或换 Adam。
- 边界：AdamW 虽通用但**显存开销**比 SGD 大一截（多存 m 和 v），显存受限时考虑 SGD 或 AdaFactor（LLM）。
