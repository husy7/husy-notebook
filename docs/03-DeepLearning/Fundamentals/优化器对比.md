# 优化器对比：SGD / Momentum / Adam / AdamW

## 定义

训练神经网络 = 前向传播求损失 + 反向传播求梯度 ∇L(θ) 后，用**优化器（optimizer）**更新参数 θ，使损失不断下降。优化器解决的核心问题是：**如何利用梯度及其历史信息构造参数更新量**——这直接决定了收敛速度、训练稳定性与最终泛化能力。

不同优化器的本质差异在于 `θ_{t+1} = θ_t − η · update(∇L(θ_t))` 中 `update(...)` 的实现：用不用动量（一阶矩）、用不用二阶矩做逐参数自适应缩放、正则化（weight decay）以何种方式加入。

- 代际演进：**SGD**（只用当前梯度，朴素）→ **Momentum**（一阶动量，平滑方向）→ **RMSProp / Adam**（二阶动量，逐参数自适应学习率）→ **AdamW**（权重衰减与自适应解耦，修复 Adam+L2 的耦合缺陷）。
- 核心特征一览：

| 优化器 | 更新逻辑 | 关键特性 | 适用 |
|--------|----------|----------|------|
| **SGD** | $\theta \gets \theta - \eta g$ | 朴素，沿负梯度 | 基线、理论清晰 |
| **SGD+Momentum** | 累加历史梯度的指数平均 | 加速、抑制震荡 | 需更稳定的收敛 |
| **Adam** | 自适应学习率：梯度一阶矩 + 二阶矩（RMS） | 快、对学习率不敏感，开箱即用 | 一般任务首选 |
| **AdamW** | Adam + 解耦权重衰减 | 正则化更稳，泛化更好 | LLM/Transformer 训练 |

> 💡 简记：Momentum 管"方向平滑"（一阶动量），RMSProp 管"每位特征尺度不同的自适应学习率"（二阶动量），Adam = 两者结合。

适用范围：从教学基线、通用 CV/NLP 模型，到 Transformer / LLM / ViT 等深度大模型——优化器选型是训练配方中最早要定、也最影响结果的一环。

## 原理

优化器的设计动机来自损失面的几何特性：曲率变化大的方向上梯度符号频繁翻转（来回震荡），平坦方向上梯度小、收敛慢。因此演进路径就是"给更新加历史信息 → 按维度自适应缩放 → 修正正则化"：

1. **SGD**：用单个（或小批量 mini-batch）样本的梯度近似全量梯度，$\theta \gets \theta - \eta g$。实现最简、理论清晰，但在曲率变化大的损失面上**震荡**、收敛缓慢，且对特征量纲差异敏感。

2. **SGD + Momentum**：维护梯度方向的指数移动平均 $v$，让更新带上"惯性"。平坦方向持续加速、震荡方向相互抵消，收敛更快更稳：

$$ v = \beta v + \eta g,\quad \theta \gets \theta - v,\quad (\beta\approx0.9) $$

3. **Adam**：为每个参数同时维护一阶矩 $m$（方向）与二阶矩 $v$（尺度），逐参数自适应缩放学习率：

$$ m = \beta_1 m + (1-\beta_1)g $$
$$ v = \beta_2 v + (1-\beta_2)g^2 $$
$$ \hat{m} = \frac{m}{1-\beta_1^t},\ \hat{v} = \frac{v}{1-\beta_2^t}\ (\text{偏差校正}) $$
$$ \theta \gets \theta - \eta \frac{\hat{m}}{\sqrt{\hat{v}}+\epsilon} $$

关键点：$m,v$ 初值为 0 导致早期估计被严重低估，故除以 $1-\beta^t$ 做偏差校正；更新量按梯度大小归一化（除以 $\sqrt{\hat{v}}+\epsilon$），因此对学习率不敏感、对稀疏梯度效果好（典型默认 $\beta_1=0.9,\ \beta_2=0.999,\ \epsilon\approx10^{-8}$）。

4. **AdamW（W 代表解耦权重衰减）**：传统 Adam 实现 L2 正则化时把权重衰减**混入梯度**，与 Adam 的自适应缩放耦合——$\lambda\theta$ 先混入 $g$ 再被 $\sqrt{\hat{v}}$ 缩放，正则强度随梯度尺度失真，正则化被破坏。AdamW 把权重衰减**单独解耦**，直接作用在参数上：

```text
普通 Adam+L2:   g_eff = g + λθ   （再走自适应缩放，λ 被缩放失真）
AdamW:         θ = θ - η·(normalized m/√v) - η·λθ   （λ 直接作用于 θ，不缩放）
```

因为解耦后正则不受自适应缩放干扰，AdamW 泛化更稳定，已被 PyTorch 设为训练 Transformer / LLM 的默认选择。

## 应用

典型选型场景：

| 场景 | 推荐 |
|------|------|
| 基础教学/理解 | SGD + Momentum |
| 通用 CV/NLP 模型 | Adam |
| Transformer / LLM / 深度大模型 | AdamW |
| 追求极致泛化、调参成本可接受 | SGD Warmup + Cosine 退火 |

> ⚠️ 深度学习（LLM、ViT 等）主流用 **AdamW + 学习率预热（warmup）+ 余弦退火**的配方。

快速上手步骤：① 按场景选定优化器并设好 `lr` / `momentum` / `weight_decay`；② 每个 batch 内按 `zero_grad → forward → loss.backward() → step()` 顺序执行（见下方代码骨架）；③ 配 `scheduler` 做 warmup / 余弦退火；④ 监控 loss 曲线，发散就降 lr、不收敛就查学习率是否过小或忘记衰减。

易错点与坑：
- ❌ 深度学习时直接给 Adam 设过大 `lr`（如 0.1）→ 爆炸/不收敛。✅ LLM 训练常用 `lr≈3e-4~1e-3` 配合 warmup。
- ❌ 忘记 `scheduler` / 训练后期学习率恒定 → 收敛不足或在最小值附近震荡。✅ 配合学习率衰减。
- ❌ 对**类别极端不平衡或大学习率**的任务，Adam 的二阶矩偏大导致前期欠学习。✅ 可用偏差校正、合适 weight_decay。
- ❌ SGD 无自适应，**特征量纲差异大**时收敛慢。✅ 先标准化特征或换 Adam。
- 边界：AdamW 虽通用但**显存开销**比 SGD 大一截（多存 m 和 v 两份状态），显存受限时考虑 SGD 或 AdaFactor（LLM）。

```python
# -*- coding: utf-8 -*-
# 案例详解：同一模型下四种优化器的标准配置 + 训练循环骨架（实际任务替换 model / 数据即可）
import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Linear(16, 1)        # 示例网络，实际换成你的模型
criterion = nn.MSELoss()        # 示例损失

# 1) 朴素 SGD：沿负梯度走，作基线对照
opt_sgd = optim.SGD(model.parameters(), lr=0.01)

# 2) SGD + Momentum：momentum=β≈0.9，一阶动量平滑方向、抑制震荡
opt_sgd_m = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# 3) Adam：一阶矩 + 二阶矩 + 偏差校正，开箱即用，通用 CV/NLP 首选
opt_adam = optim.Adam(model.parameters(), lr=1e-3)

# 4) AdamW：权重衰减解耦（weight_decay 直接作用于 θ），Transformer/LLM 默认配方
opt_adamw = optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)

# ---- 训练循环骨架：先清梯度，再前向/算 loss/反向，最后 step ----
for x, y in dataloader:         # dataloader = 你的数据迭代器
    opt.zero_grad()             # 关键！清零上一步累积的梯度，否则梯度会累加
    pred = model(x)             # 前向传播
    loss = criterion(pred, y)   # 计算损失
    loss.backward()             # 反向传播，把梯度填进 param.grad
    opt.step()                  # 优化器按各自规则更新参数
    # 若配了 warmup / 余弦退火，每个 epoch 后还要 scheduler.step()

# 要点回顾：lr 建议——SGD 类 0.01~0.1，Adam 类 1e-3 起步，
# AdamW 常用 1e-4~3e-4 并配 weight_decay=0.01；训练发散优先降 lr。
```

## 对比选型
| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| 本文方案：AdamW | Adam 双矩自适应 + 权重衰减解耦，λ 直接作用于 θ、不被自适应缩放失真 | Transformer / LLM / ViT 等深度大模型 |
| 替代方案：Adam | 一阶矩 + 二阶矩 + 偏差校正，逐参数自适应学习率 | 通用 CV/NLP 模型，开箱即用 |
| 替代方案：SGD + Momentum | 一阶动量指数平均，惯性平滑方向、抑制震荡 | 基础教学；配 warmup + 余弦退火追求极致泛化 |
| 替代方案：SGD | 朴素沿负梯度，无历史信息 | 基线对照、理论清晰 |
| 替代方案：AdaFactor | 低秩近似二阶矩、省显存的自适应方法 | 显存受限的 LLM 训练 |
