# 反向传播与激活函数

## 一、核心思想

深度网络的训练核心是**用梯度下降更新参数**，而梯度需要从损失函数逐层传回每层的参数。**反向传播（Backpropagation）**就是高效计算每个参数梯度的过程，本质是**对损失关于各参数求偏导，并利用链式法则从输出层往输入层逐层回传误差**。

激活函数则是给每个神经元引入**非线性**，否则多层线性叠加仍是线性变换，深层网络就塌缩成一层，失去表达能力。

## 二、反向传播原理

### 2.1 链式法则

设网络第 $l$ 层输出 $z^{(l)}$，损失为 $L$。参数的梯度按链式法则展开：

$$ \frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial z^{(L)}} \cdot \frac{\partial z^{(L)}}{\partial z^{(L-1)}} \cdots \frac{\partial z^{(l+1)}}{\partial z^{(l)}} \cdot \frac{\partial z^{(l)}}{\partial W^{(l)}} $$

反向传播避免重复计算：从输出层往前，每层只需一次求得"对接下来所有层的梯度"，累计到当前层，**前向存中间值、反向复用**，计算量为 $O(\text{参数量})$，与网络深度线性相关（而非指数）。

### 2.2 三层手推示例

```text
输入 x --(W1,b1)--> h = σ(W1 x + b1) --(W2,b2)--> ŷ
损失 L = (ŷ - y)²

∂L/∂W2 = ∂L/∂ŷ · ∂ŷ/∂W2            # 直接用
∂L/∂W1 = ∂L/∂ŷ · ∂ŷ/∂h · ∂h/∂W1    # 复用 ∂L/∂ŷ
```

**关键**：浅层梯度（W1）需要用中间层激活的导数链式相乘 —— 这就是为什么激活函数导数不能过大/过小（见梯度消失/爆炸）。

### 2.3 PyTorch autograd 示例

```python
import torch
import torch.nn.functional as F

x = torch.tensor([[4.0, 2.0]], requires_grad=False)
w = torch.randn(2, 1, requires_grad=True)
b = torch.zeros(1, requires_grad=True)

y = (x @ w + b).squeeze()          # 前向
loss = F.mse_loss(y, torch.tensor(6.0))
loss.backward()                    # 自动反向传播
print(w.grad, b.grad)              # 每个参数的梯度
```

## 三、激活函数对比

| 函数 | 公式 | 取值范围 | 特点 |
|------|------|---------|------|
| **Sigmoid** | $\frac{1}{1+e^{-x}}$ | (0,1) | 二分类输出；两端梯度趋 0（饱和），易梯度消失 |
| **Tanh** | $\frac{e^{x}-e^{-x}}{e^{x}+e^{-x}}$ | (-1,1) | 零中心，优于 Sigmoid，但仍饱和 |
| **ReLU** | $\max(0,x)$ | [0,∞) | 默认主力：计算快；但负区间梯度为 0 → 神经元"死亡" |
| **Leaky ReLU** | $x$ 若 $x>0$；$0.01x$ 否则 | (-∞,∞) | 缓解 ReLU 死亡（负数有微小梯度） |
| **Softmax** | $\frac{e^{z_i}}{\sum_j e^{z_j}}$ | (0,1) 且和为 1 | 多分类概率输出，配合交叉熵 |
| **GeLU** | $x\Phi(x)$ | (-∞,∞) | 平滑，LLM/Transformer 常用，近似 Swish |

```python
import torch.nn.functional as F
x = torch.tensor([-2.0, 0.0, 2.0])
print(F.relu(x))      # tensor([0., 0., 2.])
print(torch.sigmoid(x))  # tensor([0.1192, 0.5, 0.8808])
```

## 四、梯度消失与爆炸

反向传播要连乘多层导数。连乘结果要么趋 0（**梯度消失**），要么爆炸（**梯度爆炸**）。

- 激活函数两端饱和（如 Sigmoid 导数 <0.25）→ 深层梯度趋 0 → 浅层学不动。
- 权重初始化过大 / 网络太深 → 梯度爆炸。

**缓解**：ReLU 族、残差连接（ResNet）、合适的权重初始化（Xavier/He）、BatchNorm、梯度裁剪（gradient clipping）。

## 五、边界与坑

- ❌ 输出层用 **Sigmoid 却配 MSE** 损失 → 收敛极慢（梯度饱和）。✅ 二分类用 `BCEWithLogitsLoss`（Sigmoid+交叉熵合并）。
- ❌ 多分类每个输出单独加 Sigmoid → 概率和不为 1。✅ 用 Softmax + `CrossEntropyLoss`。
- ❌ 隐藏层全用 Sigmoid → 深层梯度消失。✅ 隐藏层优先 ReLU 族。
- ❌ 忘了 `requires_grad=True` 或未 `detach()` → 梯度丢失或累计错误。✅ 先 `zero_grad()` 再做 `backward()`。
- 边界：反向传播要求损失可微、网络是计算图；不可微操作（如采样）需用策略梯度/重参数化技巧。
