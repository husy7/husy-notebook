# 反向传播与激活函数

## 定义

反向传播（Backpropagation）是训练深度网络时用来**高效计算损失函数对每个参数梯度**的核心算法。深层网络参数数量庞大，若对每个参数单独求偏导，计算量将随参数量与网络深度爆炸式增长；反向传播利用微积分中的**链式法则**，让梯度从输出层的损失函数出发逐层向输入层"回传"，每个中间结果只计算一次、被所有浅层参数复用，从而把求梯度成本降到与参数量同阶，是"用梯度下降更新参数"这一训练主线的必要前提。

激活函数（Activation Function）则是附加在每个神经元输出上的**非线性变换**。没有它的多层线性叠加（如 $W_2(W_1 x + b_1) + b_2$）仍然等价于一次线性变换，无论堆多少层都会塌缩成单层效果，网络因此丧失拟合非线性映射的能力——深层结构必须靠激活函数引入非线性才"有意义"。

两者是"深度网络可训练"的一体两面：反向传播解决"每个参数的梯度怎么算得又快又准"，激活函数解决"网络凭什么能叠出深层表达能力"。适用范畴：一切以梯度下降族优化器训练的可微网络（MLP/CNN/RNN/Transformer），以及在可微计算图上的自动微分框架（autograd）。

激活函数家族的核心特征对照：

| 函数 | 公式 | 取值范围 | 特点 |
|------|------|---------|------|
| **Sigmoid** | $\frac{1}{1+e^{-x}}$ | (0,1) | 二分类输出；两端梯度趋 0（饱和），易梯度消失 |
| **Tanh** | $\frac{e^{x}-e^{-x}}{e^{x}+e^{-x}}$ | (-1,1) | 零中心，优于 Sigmoid，但仍饱和 |
| **ReLU** | $\max(0,x)$ | [0,∞) | 默认主力：计算快；但负区间梯度为 0 → 神经元"死亡" |
| **Leaky ReLU** | $x$ 若 $x>0$；$0.01x$ 否则 | (-∞,∞) | 缓解 ReLU 死亡（负数有微小梯度） |
| **Softmax** | $\frac{e^{z_i}}{\sum_j e^{z_j}}$ | (0,1) 且和为 1 | 多分类概率输出，配合交叉熵 |
| **GeLU** | $x\Phi(x)$ | (-∞,∞) | 平滑，LLM/Transformer 常用，近似 Swish |

## 原理

核心机制是链式法则的逐层复用。设网络第 $l$ 层输出为 $z^{(l)}$，损失为 $L$，则第 $l$ 层参数 $W^{(l)}$ 的梯度可展开为整条路径的偏导连乘：

$$ \frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial z^{(L)}} \cdot \frac{\partial z^{(L)}}{\partial z^{(L-1)}} \cdots \frac{\partial z^{(l+1)}}{\partial z^{(l)}} \cdot \frac{\partial z^{(l)}}{\partial W^{(l)}} $$

反向传播与朴素逐参数求导的本质差别在于**避免重复计算**：从输出层往前，每层只需一次求出"对下游所有层的梯度"并累计给当前层，**前向存中间值、反向复用**，整体计算量为 $O(\text{参数量})$，与网络深度呈线性关系（而非指数）。这是它能支撑大规模训练的根本原因。

三层网络手推示例（$h = \sigma(W_1 x + b_1)$，$\hat{y} = W_2 h + b_2$，损失 $L = (\hat{y}-y)^2$）：

```text
输入 x --(W1,b1)--> h = σ(W1 x + b1) --(W2,b2)--> ŷ
损失 L = (ŷ - y)²

∂L/∂W2 = ∂L/∂ŷ · ∂ŷ/∂W2            # 输出层，直接用
∂L/∂W1 = ∂L/∂ŷ · ∂ŷ/∂h · ∂h/∂W1    # 复用 ∂L/∂ŷ，再乘中间层激活导数
```

**关键推论**：浅层梯度（$W_1$）必须连乘中间层激活函数的导数，所以激活函数导数的量级会直接放大或扼杀浅层梯度——这正是梯度消失/爆炸的根源。

梯度消失与爆炸的机理：多层导数连乘时，若各因子都小于 1（如 Sigmoid 导数最大仅 0.25），连乘结果随层数指数级趋 0 → **梯度消失**，深层网络浅层"学不动"；若权重初始化过大或网络过深，连乘结果指数级发散 → **梯度爆炸**。主流缓解手段：ReLU 族激活、残差连接（ResNet）、合适的权重初始化（Xavier/He）、BatchNorm、梯度裁剪（gradient clipping）。边界条件：反向传播要求损失可微、网络构成可微计算图；不可微操作（如离散采样）需改用策略梯度或重参数化技巧。

## 应用

典型场景：用梯度下降族优化器训练一切可微网络——图像分类/回归（CNN + ReLU 族）、NLP/Transformer（隐藏层 GeLU，输出层 Softmax + 交叉熵）、二分类（Sigmoid + BCE）等。快速上手步骤：① 搭好前向计算图（`nn.Module` 或张量运算）；② 可训练参数声明 `requires_grad=True`（或使用 `nn.Parameter`）；③ 前向得到预测并计算标量损失；④ `loss.backward()` 自动反向传播，填充每个参数的 `.grad`；⑤ `optimizer.step()` 用梯度更新参数；⑥ 下一轮前先 `optimizer.zero_grad()` 清空累计梯度。

PyTorch 训练循环的固定套路为 `optimizer.zero_grad()` → `loss.backward()` → `optimizer.step()`，顺序不可乱（先清空、再回传、最后更新）。

常见坑（❌ 错误 / ✅ 正确做法）：

- ❌ 输出层用 **Sigmoid 却配 MSE** 损失 → 处于饱和区时梯度极小，收敛极慢。✅ 二分类用 `BCEWithLogitsLoss`（Sigmoid + 交叉熵合并，数值更稳定）。
- ❌ 多分类对每个输出单独加 Sigmoid → 各输出概率和不为 1。✅ 用 Softmax + `CrossEntropyLoss`。
- ❌ 隐藏层全用 Sigmoid → 导数连乘导致深层梯度消失。✅ 隐藏层优先 ReLU 族（默认 ReLU；出现神经元死亡可换 Leaky ReLU）。
- ❌ 忘了 `requires_grad=True` → 该参数 `.grad` 为 None；未对不需梯度路径 `detach()` → 梯度沿无关路径累计出错。✅ 先 `zero_grad()` 再 `backward()`，需要脱离计算图处显式 `detach()`。
- ❌ 把不可微操作（如 `torch.multinomial` 采样）直接接在需要梯度的路径上 → 反向传播断裂。✅ 用重参数化（reparameterization）或策略梯度绕开。

```python
import torch
import torch.nn.functional as F

# ===== 案例 1：autograd 自动反向传播求梯度（微型线性模型 ŷ = x·w + b）=====
x = torch.tensor([[4.0, 2.0]])              # 输入样本 (1×2)，本身不需要梯度
w = torch.randn(2, 1, requires_grad=True)    # 权重：必须 requires_grad=True 才会被追踪
b = torch.zeros(1, requires_grad=True)       # 偏置：同样声明需要梯度

y = (x @ w + b).squeeze()                     # 前向传播 → 预测值 ŷ（标量）
loss = F.mse_loss(y, torch.tensor(6.0))       # 与目标 6.0 计算 MSE 损失（必须是标量才能 backward）
loss.backward()                               # 反向传播：沿计算图逐层回传，填充 .grad
print(w.grad, b.grad)                         # 查看 ∂loss/∂w 与 ∂loss/∂b

# 训练循环要点：backward 前必须 zero_grad，否则 .grad 会跨 batch 累加
# optimizer.zero_grad();  loss.backward();  optimizer.step()

# ===== 案例 2：激活函数输出验证 =====
x2 = torch.tensor([-2.0, 0.0, 2.0])
print(F.relu(x2))             # ReLU：负数清零 → tensor([0., 0., 2.])
print(torch.sigmoid(x2))      # Sigmoid：压缩到 (0,1) → tensor([0.1192, 0.5, 0.8808])
```

## 对比选型
| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| 本文方案：反向传播 + 非线性激活（ReLU 族） | 链式法则逐层回传梯度，前向存中间值、反向复用，一次 backward 得到全部参数梯度 | 一切可微深度网络（CNN/RNN/Transformer）的常规训练 |
| 替代方案：数值微分（有限差分） | 用 $\frac{f(x+\epsilon)-f(x)}{\epsilon}$ 逐参数近似梯度，实现直观但每参数需一次前向、慢且有步长误差 | PyTorch `torch.autograd.gradcheck` 式梯度正确性校验（仅小规模） |
| 替代方案：不用激活函数的纯线性堆叠 | 每层只做线性变换，计算最简单、无需非线性设计 | 仅线性可分问题；堆任意多层都等价于单层线性，无深层意义 |
