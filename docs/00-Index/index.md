## 使用建议

1. **找笔记**：从本页选板块 → 板块索引 → 目标笔记。
2. **写笔记**：复制 `docs/_template.md` 到对应子目录，遵循模板五段式结构。
3. **维护索引**：每写完一篇笔记，回到本页与对应板块更新链接，保证所有笔记可被索引到。
