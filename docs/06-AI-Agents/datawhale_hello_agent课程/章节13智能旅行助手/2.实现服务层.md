## 🗺️ 二、AmapService（高德地图服务）

### 📂 文件位置
```
app/services/amap_service.py
```

### 🎯 核心作用
封装高德地图 MCP 工具，提供：
- **POI 搜索**：查景点、餐厅、酒店
- **天气查询**：获取目的地天气
- **路线规划**：步行/驾车/公交
- **地理编码**：地址 → 经纬度

### 🔑 关键方法

| 方法名 | 参数 | 返回值 | 用途 |
| :--- | :--- | :--- | :--- |
| `search_poi(keywords, city)` | 关键词、城市 | `List[POIInfo]` | 搜索景点/餐厅 |
| `get_weather(city)` | 城市名 | `List[WeatherInfo]` | 获取天气预报 |
| `plan_route(origin, dest, ...)` | 起点、终点、类型 | `Dict[str, Any]` | 规划出行路线 |
| `geocode(address, city)` | 地址、城市 | `Optional[Location]` | 地址转坐标 |

### 🧠 设计思想（新手必看）

#### 1. 单例模式
```python
_amap_service = None

def get_amap_service() -> AmapService:
    global _amap_service
    if _amap_service is None:
        _amap_service = AmapService()
    return _amap_service
```
**为什么**：全局只创建一个实例，节省资源，避免反复初始化 MCP 工具。

#### 2. MCP 工具封装
```python
self.mcp_tool = get_amap_mcp_tool()
result = self.mcp_tool.run({
    "action": "call_tool",
    "tool_name": "maps_text_search",
    "arguments": {...}
})
```
**为什么**：MCP（模型上下文协议）统一了工具调用方式，后续切换地图服务商（如换成百度地图）只需改底层 MCP 配置，上层代码无需改动。

#### 3. 异常处理
```python
try:
    result = self.mcp_tool.run(...)
    # 解析结果
except Exception as e:
    print(f"❌ POI搜索失败: {str(e)}")
    return []  # 返回空列表，不崩溃
```
**为什么**：外部 API 可能超时、限流、报错。返回空列表保证程序不崩溃，上层（Agent）可以判断 `if not pois: 走降级逻辑`。

## 🤖 三、LLMService（大模型服务）

### 📂 文件位置
```
app/services/llm_service.py
```

### 🎯 核心作用
- 封装 `HelloAgentsLLM` 统一 LLM 接口
- 提供 **真实 AI + Mock 降级** 双模式
- 保证上层代码无论何时都能调用

### 🔑 关键方法

| 方法名 | 参数 | 返回值 | 用途 |
| :--- | :--- | :--- | :--- |
| `get_llm()` | 无 | `HelloAgentsLLM` 或 `_MockLLM` | 获取 LLM 实例（单例） |
| `generate_text(messages)` | 消息列表 | `str` | 生成完整回复（非流式） |
| `reset_llm()` | 无 | `None` | 重置实例（测试用） |

### 🧠 设计思想（新手必看）

#### 1. 双重降级策略（核心亮点）
```python
try:
    _llm_instance = HelloAgentsLLM()
    print("✅ 真实 LLM 模式")
except Exception as e:
    _llm_instance = _MockLLM()
    print("💡 自动切换 Mock 模式")
```
**为什么**：用户可能没配 Key、网络不通、API 额度用完。自动降级保证项目在任何环境下都能运行，这是**生产级代码的必修课**。

#### 2. Mock 类与真实类接口完全对齐
```python
class _MockLLM:
    def think(self, messages, temperature=None) -> Iterator[str]: ...
    def invoke(self, messages, **kwargs) -> str: ...
    def stream_invoke(self, messages, **kwargs) -> Iterator[str]: ...
```
**为什么**：上层（Agent）调用 `llm.think(messages)` 时，无论拿到的是真实 LLM 还是 Mock，调用方式完全一样，实现 **"无感知降级"**。

#### 3. 配置同步到环境变量
```python
if settings.llm_api_key:
    os.environ["OPENAI_API_KEY"] = settings.llm_api_key
```
**为什么**：`HelloAgentsLLM` 内部从环境变量读取配置。这一步确保 `config.py` 是唯一数据源，用户只需配置 `LLM_API_KEY` 即可。

### 🎯 Mock 类能生成什么？
```
输入: [{"role": "user", "content": "请介绍北京"}]
输出: "北京是中国的首都，拥有三千多年建城史..."
```

Mock 类内置了**北京、上海、杭州、成都、广州、西安**等多个城市的模板回复，测试时看起来非常真实。

## 📸 四、UnsplashService（图片服务）

### 📂 文件位置
```
app/services/unsplash_service.py
```

### 🎯 核心作用
- 搜索景点/旅行相关的精美图片
- 为每个景点提供配图 URL

### 🔑 关键方法

| 方法名 | 参数 | 返回值 | 用途 |
| :--- | :--- | :--- | :--- |
| `search_photos(query, per_page)` | 关键词、数量 | `List[dict]` | 批量搜索图片 |
| `get_photo_url(query)` | 关键词 | `Optional[str]` | 获取单张图片 URL |

### 🧠 设计思想（新手必看）

#### 1. 响应数据清洗
```python
photos.append({
    "id": photo.get("id"),
    "url": photo.get("urls", {}).get("regular"),
    "thumb": photo.get("urls", {}).get("thumb"),
    "description": photo.get("description") or photo.get("alt_description"),
    "photographer": photo.get("user", {}).get("name")
})
```
**为什么**：Unsplash API 返回的 JSON 结构复杂，嵌套深。清洗后只保留前端需要的 5 个字段，上层代码更简洁。

#### 2. 单例模式
与 `AmapService` 相同，全局只创建一个实例，避免重复初始化。

### ⚠️ 当前状态（注意事项）
- **没有降级策略**：Key 缺失或网络失败时返回空列表
- **返回的是原始 dict**：没有转换成 Pydantic 模型，上层需要 `photo["url"]` 这样取值
- **建议改进方向**：
  1. 增加 Mock 占位图（如 `picsum.photos`）
  2. 定义 `PhotoInfo` 模型，用 Pydantic 对象代替 dict

## 🔧 五、三个 Service 的协作关系

```
┌─────────────────────────────────────────────────────────┐
│                    TripPlannerAgent                      │
│                  （智能体 - 大脑中枢）                    │
└─────────────────┬───────────────────────────────────────┘
                  │
         ┌────────┴────────┬────────────┐
         ▼                 ▼            ▼
   ┌───────────┐   ┌───────────┐   ┌───────────┐
   │  Amap     │   │   LLM     │   │ Unsplash  │
   │  Service  │   │  Service  │   │  Service  │
   └───────────┘   └───────────┘   └───────────┘
         │                 │            │
         ▼                 ▼            ▼
   查景点/路线/天气    生成文案描述   获取景点配图
```

**调用链示例**：
```python
agent = TripPlannerAgent()
plan = agent.plan_trip(request)

# agent 内部：
# 1. 调用 amap_service.search_poi() 查景点
# 2. 调用 unsplash_service.get_photo_url(景点名) 配图
# 3. 调用 llm_service.generate_text() 生成每日文案
# 4. 组装成 TripPlan 返回
```
