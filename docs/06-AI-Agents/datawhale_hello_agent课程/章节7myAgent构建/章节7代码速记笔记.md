## 1. 核心基础组件

### 1.1 Message 类 (`message.py`)
```python
from typing import Optional, Dict, Any, Literal
from datetime import datetime
from pydantic import BaseModel

MessageRole = Literal["user", "assistant", "system", "tool"]

class Message(BaseModel):
    content: str
    role: MessageRole
    timestamp: datetime = None
    metadata: Optional[Dict[str, Any]] = None

    def __init__(self, content: str, role: MessageRole, **kwargs):
        super().__init__(content=content, role=role,
                         timestamp=kwargs.get('timestamp', datetime.now()),
                         metadata=kwargs.get('metadata', {}))

    def to_dict(self) -> Dict[str, Any]:
        return {"role": self.role, "content": self.content}

    def __str__(self) -> str:
        return f"[{self.role}] {self.content}"
```

### 1.4 HelloAgentsLLM 扩展 (`llm.py` 核心)
- **多提供商支持**：通过继承扩展，如 `MyLLM(HelloAgentsLLM)` 重写 `__init__` 处理 `provider="modelscope"`。
- **自动检测机制**：
  - `_auto_detect_provider()`：优先级①特定环境变量（`MODELSCOPE_API_KEY`等）②解析 `base_url`（域名/端口）③分析 `api_key` 格式。
  - `_resolve_credentials()`：根据 `provider` 补全 `api_key` 和 `base_url`。
- **接入本地模型**：VLLM/Ollama 通过设置 `base_url` 和 `api_key` 即可。

### 2.2 ReActAgent（`MyReActAgent`）
```python
from hello_agents import ReActAgent, ToolRegistry

MY_REACT_PROMPT = """你是一个具备推理和行动能力的AI助手。
可用工具: {tools}
格式:
Thought: ...
Action: 工具名[参数] 或 Finish[最终答案]
Question: {question}
历史: {history}
"""

class MyReActAgent(ReActAgent):
    def __init__(self, name, llm, tool_registry, system_prompt=None,
                 config=None, max_steps=5, custom_prompt=None):
        super().__init__(name, llm, system_prompt, config)
        self.tool_registry = tool_registry
        self.max_steps = max_steps
        self.current_history = []
        self.prompt_template = custom_prompt or MY_REACT_PROMPT

    def run(self, input_text: str, **kwargs) -> str:
        while step < max_steps:
            prompt = self.prompt_template.format(tools=..., question=..., history=...)
            response = self.llm.invoke([{"role":"user","content":prompt}], **kwargs)
            thought, action = self._parse_output(response)
            if action.startswith("Finish"):
                return self._parse_action_input(action)
            tool_name, tool_input = self._parse_action(action)
            observation = self.tool_registry.execute_tool(tool_name, tool_input)
            self.current_history.append(f"Action: {action}\nObservation: {observation}")
        return "超时未完成"
```

### 3.4 异步执行器 (`AsyncToolExecutor`)
```python
import asyncio, concurrent.futures

class AsyncToolExecutor:
    def __init__(self, registry: ToolRegistry, max_workers: int = 4):
        self.registry = registry
        self.executor = concurrent.futures.ThreadPoolExecutor(max_workers)

    async def execute_tool_async(self, tool_name: str, input_data: str) -> str:
        loop = asyncio.get_event_loop()
        return await loop.run_in_executor(self.executor,
                                          self.registry.execute_tool, tool_name, input_data)

    async def execute_tools_parallel(self, tasks: List[Dict[str, str]]) -> List[str]:
        async_tasks = [self.execute_tool_async(t['tool_name'], t['input_data']) for t in tasks]
        return await asyncio.gather(*async_tasks)
```

### 1. `HelloAgentsLLM` —— 统一LLM客户端

**设计目标**：多提供商、自动检测、本地模型支持。

**核心方法**：
- `__init__(model, api_key, base_url, provider="auto")`
- `_auto_detect_provider()` —— 自动检测提供商（优先级：环境变量 → base_url → key格式）
- `_resolve_credentials()` —— 根据provider解析凭证和base_url
- `invoke(messages, **kwargs)` —— 同步调用（完整响应）
- `stream_invoke(messages, **kwargs)` —— 流式调用（生成器）

**自动检测逻辑（伪代码）**：
```python
def _auto_detect_provider(self, api_key, base_url):
    if os.getenv("MODELSCOPE_API_KEY"): return "modelscope"
    if os.getenv("OPENAI_API_KEY"): return "openai"
    # 解析 base_url
    if "api-inference.modelscope.cn" in base_url: return "modelscope"
    if "localhost:11434" in base_url: return "ollama"
    if "localhost:8000" in base_url: return "vllm"
    # 按key格式辅助判断
    if api_key.startswith("ms-"): return "modelscope"
    return "auto"
```

**扩展新提供商**（继承示例）：
```python

        "function": {
            "name": self.name,
            "description": self.description,
            "parameters": {
                "type": "object",
                "properties": { param.name: {"type": param.type, "description": param.description} },
                "required": [p.name for p in self.get_parameters() if p.required]
            }
        }
    }

    def add_step(self, tool_name: str, input_template: str, output_key: str = None)
    def execute(self, registry: ToolRegistry, initial_input: str, context: dict) -> str
```
**支持变量替换**：`"{input}"`, `"{step_1_result}"` 等。

#### (2) `AsyncToolExecutor` —— 异步并行执行

```python
class AsyncToolExecutor:
    async def execute_tool_async(self, tool_name, input_data) -> str
    async def execute_tools_parallel(self, tasks: List[Dict]) -> List[str]
```
内部使用 `ThreadPoolExecutor`，适合I/O密集型工具。
