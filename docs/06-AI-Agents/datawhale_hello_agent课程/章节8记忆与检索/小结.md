# 第八章 记忆与检索 · 小结

> 为 HelloAgents 框架增加记忆系统与 RAG 系统两大核心能力，借鉴认知科学实现类人记忆，借鉴检索增强生成克服 LLM 知识局限。

## 知识体系总览

```
认知科学启发（人类记忆层次）
    ↓
LLM 两大局限
  ├─ 无状态对话遗忘 -> Memory System（四类记忆+生命周期管理）
  └─ 知识静态局限   -> RAG System（五层七步+高级检索）
    ↓
组合实战 -> 智能文档问答助手（PDFLearningAssistant）
```

## Memory vs RAG 速查

| 维度 | MemoryTool | RAGTool |
|------|-----------|---------|
| 解决问题 | 对话遗忘（无状态） | 知识局限（静态） |
| 数据来源 | 交互过程中自动积累 | 用户提供的文档/知识库 |
| 记忆类型 | 4类（工作/情景/语义/感知） | 文档分块（rag_chunk） |
| 存储后端 | SQLite+Qdrant+Neo4j | Qdrant（命名空间隔离） |
| 检索策略 | 向量+图+词法混合（按类型不同） | 向量+MQE+HyDE |
| 生命周期 | add/search/forget/consolidate | add_document/search/ask |
| 典型场景 | "我之前说过..." | "文档里怎么写的..." |

## 四种记忆评分公式速记

| 类型 | 公式 | 记忆口诀 |
|------|------|---------|
| Working | `(TF-IDF×0.7+关键词×0.3) × 时间衰减 × imp权重` | 词法为主，时间淘汰 |
| Episodic | `(向量×0.8+时间近因×0.2) × imp权重` | 语义为主，近因为辅 |
| Semantic | `(向量×0.7+图×0.3) × imp权重` | 语义+关系推理 |
| Perceptual | `(向量×0.8+时间近因×0.2) × imp权重` | 同模态匹配为主 |

> 共性：重要性权重统一 [0.8, 1.2]，避免重要性压制相似度。

## RAG 三阶段演进

| 阶段 | 检索 | 生成 | 特征 |
|------|------|------|------|
| 朴素 | TF-IDF/BM25 | 直接拼接 | 简单但无语义理解 |
| 高级 | 稠密嵌入 | 分块+重排序 | 语义检索成熟 |
| 模块化 | MQE+HyDE+混合 | CoT+反思 | 可插拔、智能化 |

## 高级检索策略对比

| 策略 | 核心思想 | 优势 | 适用场景 | 成本 |
|------|---------|------|---------|------|
| 基础 | 单查询向量 | 快 | 明确查询 | 低 |
| MQE | LLM生成多样化查询 | 召回+30-50% | 模糊/多义查询 | 中（+LLM调用） |
| HyDE | LLM生成假设答案检索 | 桥接语义鸿沟 | 专业领域查询 | 中（+LLM调用） |
| MQE+HyDE | 双策略组合 | 效果最佳 | 高质量要求 | 高 |

## 综合习题

### 习题1：记忆类型评分与组合（详见 memory-system-note.md）

- 情景记忆重时间近因（事件有时间属性），语义记忆重图检索（知识需关系推理）。
- 健康助手：工作记忆（当前对话）+ 情景（每日数据记录）+ 语义（健康画像+知识）+ 感知（食物照片）。
- 自动整合触发：importance≥阈值 + 被检索≥N次 + TTL将过期但高重要性。

### 习题2：分块策略与检索对比（详见 rag-system-note.md）

- 无标题文档：语义边界分块（句子级+滑动窗口+overlap）。
- 基础 vs MQE vs HyDE：明确查询用基础，模糊查询用 MQE，专业领域用 HyDE。
- 嵌入选型：生产用 DashScope，隐私敏感用 Local，兜底用 TFIDF。

### 习题3：遗忘机制（详见 memory-system-note.md）

- 智能遗忘：importance×0.4 + 访问频率×0.3 + 时间近因×0.3 加权评分。
- 记忆归档：冷数据转移冷存储，需时恢复，与四类记忆通过 importance+access_count 阈值集成。
- 敏感信息清除：删数据+重建索引+清事务日志+更新备份，向量库和图库均需彻底处理。

### 习题4：知识图谱与图检索（详见 qa-assistant-note.md）

- 自动提取准确性受文本质量/领域术语/歧义影响，需质量评估机制（置信度+人工抽检）。
- 图检索优势场景：多跳关系推理（如"张三的同事用过的工具"），纯向量无法完成。
- 图检索 vs 纯向量：概念关联推理用图，语义相似匹配用向量，混合最优。

### 习题5：智能路由与多用户（详见 qa-assistant-note.md）

- 智能路由：意图分类 -> 客观知识走 RAG，个人历史走 Memory，混合走双路检索。
- 学习报告扩展：分析提问分布识别盲点，对比文档覆盖度推荐未读章节。
- 多用户隔离：Qdrant（namespace+payload）、Neo4j（user_id属性）、SQLite（user_id列）。
