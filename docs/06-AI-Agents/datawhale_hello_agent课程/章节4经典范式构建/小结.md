### 📒 智能体三大范式 · 速查笔记

| 范式 | **ReAct** | **Plan-and-Solve** | **Reflection** |
| :--- | :--- | :--- | :--- |
| **核心公式** | 思考 ⇄ 行动 ⇄ 观察（循环） | 先全量规划 → 再一次性执行 | 执行（或初版方案）→ 事后审视 → 修正 |
| **一句话人设** | **“边想边干，走一步看一步”** | **“谋定而后动，计划不改”** | **“先干为敬，睡前复盘”** |
| **决策流特征** | **交错式**<br>每一步都依赖上一步的外部真实反馈 | **串行分离式**<br>执行时不再思考，像流水线 | **双阶段式**<br>第一遍产出粗糙结果，第二遍自我批改 |
| **对错误的反应** | **即时止损**（此路不通换条路） | **一错皆错**（第一步失败则全盘崩溃） | **延迟修正**（本轮错，下轮改） |
| **算力/时间成本** | 中等（轮数多，但单步短） | 低（一次生成，批量调用） | 高（相当于做两遍题） |
| **最佳战场** | 开放世界、不确定环境、人机对话 | 固定流程、批量任务、确定性操作 | 数学推理、代码调试、高质量内容生成 |

---


###  三范式组合口诀（背下来）

> **Plan** 拆大任务（粗粒度），  
> **ReAct** 管现场（细粒度），  
> **Reflection** 悟（进化度），  

---

### 记忆锚点
- **ReAct** = **“知行合一”**（知即行，行即知）  
- **Plan-and-Solve** = **“纸上谈兵”**（兵推完美，但战场无常）  
- **Reflection** = **“吾日三省吾身”**（省完再战，战完再省）
