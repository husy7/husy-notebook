# Transformer 架构

> 从"数词对出现次数"的 N-gram，到"顺序记忆"的 RNN，再到"并行全局注意力"的 Transformer 与 Decoder-Only——一条逐步解决稀疏性、长程依赖与并行效率的演进之路，也是现代 LLM 的底层引擎。

## 一、演进脉络

```
N-gram(统计计数) → 神经网络语言模型(词嵌入) → RNN/LSTM(循环记忆)
   ↓ 缺陷:稀疏/泛化差      ↓ 缺陷:固定窗口          ↓ 缺陷:串行、长程遗忘
                              Transformer(注意力并行) → Decoder-Only(只留解码器)
```

## 二、3.1.1 从 N-gram 到 RNN

### 2.1 N-gram：概率连乘 + 马尔可夫假设

语言模型的核心任务：给定词序列 $w_1,\cdots,w_m$，计算它出现的概率 $P(S)$。由链式法则：

$$P(S)=P(w_1)P(w_2|w_1)P(w_3|w_1,w_2)\cdots P(w_m|w_1,\cdots,w_{m-1})$$

问题：条件概率 $P(w_m|w_1,\cdots,w_{m-1})$ 极难从语料估计，长序列可能从未出现过。

**马尔可夫假设**：一个词的出现只与前面有限的 $n-1$ 个词有关（图 3.1），据此建立的模型叫 N-gram：

- Bigram（N=2）：$P(w_i|w_1,\cdots,w_{i-1})\approx P(w_i|w_{i-1})$
- Trigram（N=3）：$P(w_i|w_1,\cdots,w_{i-1})\approx P(w_i|w_{i-2},w_{i-1})$

用**最大似然估计（MLE）**，概率 = 词对计数相除：

$$P(w_i|w_{i-1})=\frac{Count(w_{i-1},w_i)}{Count(w_{i-1})}$$

> 迷你语料 `datawhale agent learns` + `datawhale agent works`（共 6 词），估算 `datawhale agent learns`：
> $P(datawhale)=2/6\approx0.333$，$P(agent|datawhale)=2/2=1$，$P(learns|agent)=1/2=0.5$，连乘 $\approx0.167$。

**两大致命缺陷**：

1. **数据稀疏**：没见过（未登录）的词序列概率为 0，平滑只能缓解、不能根除。
2. **泛化差**：把词当孤立符号，无法理解 `agent` 与 `robot` 语义相近，`robot learns` 组合未出现就归零。

### 2.2 词嵌入：连续向量替代离散符号

前馈神经网络语言模型（Bengio 2003）两步：① 把每个词映射为高维连续向量空间的一个点（**词嵌入**），语义相近则向量相近；② 用网络学习「前 $n-1$ 个词向量 → 下一个词的概率分布」。

用**余弦相似度**量化语义距离：

$$\text{sim}(\vec a,\vec b)=\cos\theta=\frac{\vec a\cdot\vec b}{|\vec a||\vec b|}$$

- 夹角 0°→1（同向），90°→0（正交无关），180°→-1（反向）。

经典类比：`vector(king) - vector(man) + vector(woman) ≈ vector(queen)`，说明向量学到了"性别、皇室"等抽象概念（对齐 queen 相似度可到 1.0）。

> 局限：仍沿用固定上下文窗口，只能看前 $n-1$ 个词——为 RNN 埋下伏笔。

### 2.3 RNN 与 LSTM：加"记忆"，但串行 + 长程遗忘

RNN 引入**隐藏状态**（短期记忆），每步读入当前词 + 上一时刻记忆，循环向后传递信息，可处理任意长序列。但序列越长 = 网络越深，反向传播连乘导致**梯度消失/梯度爆炸（长期依赖问题）**，前文信息被"遗忘"。

LSTM 通过**细胞状态 + 门控机制**缓解：遗忘门（丢什么）、输入门（存什么）、输出门（输出什么），让信息沿独立通路更顺畅传递。但 RNN/LSTM 仍是**串行**计算，第 $t$ 步依赖第 $t-1$ 步，无法大规模并行。

## 三、3.1.2 Transformer 架构解析

Transformer（Vaswani 2017）彻底抛弃循环，只靠**注意力**捕捉依赖，实现真正的并行。

### 3.1 Encoder-Decoder 分工

```
编码器 Encoder：读懂整句 → 每个词元生成一个富含上下文的向量
解码器 Decoder：参考“已生成前文” + “咨询编码器结果” → 逐词生成目标句
```

### 3.2 自注意力：Q/K/V 三角色

动机：读 `The agent learns because it is intelligent.` 时，理解 `it` 会自动把注意力放在 `agent` 上。

每个词元生成三个可学习向量（`Q,K,V` 均由词嵌入 × 权重矩阵 $W^Q,W^K,W^V$ 得到）：

- **Q（查询）**：当前词元"主动提问谁与我相关"；
- **K（键）**：被查询词元的"索引/标签"；
- **V（值）**：词元携带的"内容"。

四步流程（"开卷考试"比喻）：

```
① 每个词都生成 Q,K,V
② 相关性得分 = 当前词 Q · 所有词 K（点积）
③ 除以 √d_k 缩放 → Softmax 归一化为权重（和为1）
④ 权重 × 各词 V 求和 → 融合全局上下文的新表示
```

$$\text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^{T}}{\sqrt{d_k}}\right)V$$

其中 $d_k$ 是 K 的维度，缩放因子 $\sqrt{d_k}$ 避免大维度下点积过大导致梯度消失。

### 3.3 多头注意力：分头、分别看、再合并

单头只能学一种关系；**多头**把 Q/K/V 在维度上切分成 $h$ 份（$d_k=d_{model}//h$），每头独立算一次注意力（相当于 $h$ 个"专家"看不同关系：指代/时态/从属），最后拼接 + 线性变换整合。数据流：

```
(batch, seq_len, d_model)
   → Linear(W_q/W_k/W_v) → split_heads → (batch, h, seq_len, d_k)
   → scaled_dot_product_attention（含 mask，mask 位置填 -1e9 使 softmax≈0）
   → combine_heads → (batch, seq_len, d_model) → Linear(W_o)
```

### 3.4 前馈网络 FFN：先扩再缩

注意力层负责"动态聚合"信息，FFN 负责"逐位置提取高阶特征"。对每个词元独立作用、全位置共享权重：

$$\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2$$

通常 $d_{ff}=4\times d_{model}$：先 ReLU 扩维、再线性收窄回 $d_{model}$。

### 3.5 残差连接 + 层归一化（Add & Norm）

每个子层都被 `Add & Norm` 包裹：

- **Add（残差）**：$\text{Output}=x+\text{Sublayer}(x)$，梯度可绕过子层直传，解决深度网络的梯度消失；
- **Norm（层归一化）**：对单样本所有特征归一化为均值 0、方差 1，缓解内部协变量偏移，加速收敛、稳定训练。

### 3.6 位置编码：给注意力补上"顺序"

自注意力不感知顺序（`agent learns` 与 `learns agent` 对其等价），故给每个词元向量**加上**位置向量（正弦/余弦固定公式，非学习参数）：

$$PE_{(pos,2i)}=\sin\left(\frac{pos}{10000^{2i/d_{model}}}\right),\quad PE_{(pos,2i+1)}=\cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

$pos$ 为位置、$i$ 为维度索引。同一词不同位置，最终向量因位置编码不同而独一无二。

## 四、3.1.3 Decoder-Only 架构

Transformer 是"先理解再生成"（编码器 + 解码器）；GPT 反问：**语言的核心任务不就是预测下一个词吗？** 于是**完全抛弃编码器，只保留解码器**，这就是 Decoder-Only。

**自回归**工作模式（"文字接龙"）：

```
起始文本 "Datawhale Agent is" → 预测 "a" → 接上去 → "Datawhale Agent is a"
   → 预测 "powerful" → … → 直到完整句子或命中停止条件
```

**掩码自注意力（因果掩码）**保证不"偷看"未来：训练时在 Softmax 前把当前位置之后的分数替换为极大负数 → 概率变 0；生成时未来词元本就没生成，天然一致。

**三大优势**：

1. **训练目标统一**：唯一任务"预测下一个词"，适合海量无标注文本预训练；
2. **结构简单易扩展**：组件少 → 容易规模化（GPT-4、Llama 千亿/万亿参数都基于此）；
3. **天然适合生成**：自回归与对话/写作/代码等生成式任务完美契合，是通用智能体的基础。

## 五、易错点

> **把"概率连乘"当成精确计算**：N-gram 只是马尔可夫假设下的近似，连乘会累积误差，且未平滑时 OOV 直接为 0。

> **混淆 Q/K/V 的角色**：Q 是"谁在查"、K 是"被查的标签"、V 是"被取的内容"；自注意力是 QK^T 打分再乘 V，不是 Q·V。

> **忘记缩放因子 $\sqrt{d_k}$**：$d_k$ 很大时点积幅度大，Softmax 进入饱和区梯度变小，必须除以 $\sqrt{d_k}$。

> **忽略位置编码**：注意力本身与顺序无关，去掉/写错位置编码，"agent learns"与"learns agent"将无法区分。

> **混淆训练/生成时的掩码**：Decoder 训练用因果掩码挡住未来 token；推理时逐词自回归，两者必须"只看前文"保持一致。

## 六、练习

- Q1：N-gram 的马尔可夫假设是什么？两大根本局限？  
  A1：词只依赖前 $n-1$ 个词；局限是数据稀疏（未登录序列概率为 0）与泛化差（无法理解语义相似词）。
- Q2：词嵌入如何解决泛化问题？  
  A2：把词映射为连续向量，语义相近则向量相近，可用余弦相似度度量，支持 `king-man+woman≈queen` 式类比。
- Q3：为什么 Transformer 能并行而 RNN 不能？  
  A3：RNN 第 $t$ 步依赖第 $t-1$ 步的隐藏状态必须串行；Transformer 用自注意力一次性计算全序列任意两词关系，可并行。
- Q4：Decoder-Only 为何成为 LLM 主流？  
  A4：训练目标统一（预测下一词）、结构简单易扩展、自回归天然契合生成任务。

## 八、对比与选型

| 模型 | 上下文 | 并行性 | 长程依赖 | 词汇表示 | 主要缺陷 |
|------|--------|--------|----------|----------|----------|
| N-gram | 固定 n-1 | 高 | 弱 | 离散符号 | 数据稀疏、泛化差 |
| 前馈 NN 语言模型 | 固定 n-1 | 高 | 弱 | 词嵌入 | 仍是固定窗口 |
| RNN/LSTM | 理论上任意长 | 低（串行） | 中（LSTM 缓解） | 词嵌入 + 隐藏状态 | 梯度消失/爆炸、无法并行 |
| Transformer | 长（受窗口/位置编码限制） | 高 | 强（全局注意力） | 词嵌入 + 位置编码 | 注意力 $O(n^2)$ 计算开销 |
| Decoder-Only(GPT系) | 长 | 高 | 强 | 词嵌入 + 位置编码 + 因果掩码 | 只能单向看前文 |

**选型速查**：聊"历史与原理"用 N-gram/RNN 理解演进；做"现代生成/对话/智能体"一律 Decoder-Only（GPT/Llama/Qwen）铺底，Encoder-Decoder 更适合翻译等"先理解后生成"的端到端任务。
