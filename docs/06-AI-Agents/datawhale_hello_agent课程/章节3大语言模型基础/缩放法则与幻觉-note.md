# 缩放法则与模型幻觉

> 缩放法则回答"为什么不惜代价把模型做大"——规模带来可预测提升与能力涌现；幻觉则回答"为什么它仍会一本正经胡说"——自回归只预测下一词、并无事实核查，只能靠 RAG/工具/多步验证去缓解。

## 一、3.3.1 缩放法则（Scaling Laws）

### 1.1 核心结论

模型性能（通常用 **Loss** 衡量）与三个要素存在**可预测的幂律关系**：

```
三要素：模型参数量 × 训练数据量 × 计算量
      ↓（在对数-对数坐标系下）
      Loss 随任一要素增大而平滑、可预测地下降（近线性）
```

示意（幂律在 log-log 下为直线，源文未给具体指数）：

```
log(Loss) = -α · log(参数量/数据量/计算量) + 常数   (α>0)
```

启示：持续、按比例地增加三者，性能就会平滑提升，不出现明显瓶颈——这是"用资源换能力"的理论依据。

### 1.2 Chinchilla 定律：纠正"越大越好"

早期只堆参数量；DeepMind 2022 的 **Chinchilla 定律**指出：**给定计算预算下，参数量与数据量存在最优配比**——最优模型应比此前普遍认为的**更小、但用多得多的数据训练**。

> 例：700 亿参数的 Chinchilla，因训练数据比 GPT-3（1750 亿参数）多 **4 倍**，性能反而超越后者。

启示：强调**数据效率**，指导了 Llama 等高效模型的设计；单纯"更大"不是答案，"规模 + 数据配比"才是。

### 1.3 能力的涌现（Emergence）

当模型规模达到某阈值后，会**突然出现**小模型完全缺失或表现糟糕的能力，例如：

- 链式思考（Chain-of-Thought）
- 指令遵循（Instruction Following）
- 多步推理、代码生成

这些能力多在参数量达**数百亿甚至千亿级别**后才显著出现。对智能体开发者：选足够大规模的模型，是实现复杂自主决策与规划的前提。

## 二、3.3.2 模型幻觉（Hallucination）

### 2.1 定义

幻觉 = 大模型生成内容与**客观事实、用户输入或上下文相矛盾**，或编造不存在的事实/实体/事件。本质：生成时过度自信地"编造"，而非准确检索或推理。

### 2.2 类型

| 类型 | 表现 |
|------|------|
| 事实性幻觉 | 与现实世界事实不符 |
| 忠实性幻觉 | 摘要/翻译未忠实反映源文本含义 |
| 内在幻觉 | 生成内容与输入信息直接矛盾 |

### 2.3 成因（三层）

```
① 训练数据层面：数据含错误/矛盾信息
② 生成机制层面：自回归只预测"下一个最可能词元"，无内置事实核查模块
③ 推理层面：复杂推理中逻辑链条出错 → "编造"错误结论
```

典型危害：旅游规划 Agent 推荐**不存在的景点**、预订**航班号错误的机票**。

### 2.4 延伸局限

- **知识时效性不足**：模型知识止于训练数据收集时点，之后的事件/概念/事实无法感知。
- **数据偏见**：训练数据含人类社会的偏见与刻板印象，模型会吸收并反映（Bender 等"随机鹦鹉"之警示，ref[12]）。

### 2.5 缓解手段（三层防线）

| 层面 | 方法 |
|------|------|
| 数据 | 高质量数据清洗、引入事实性知识、RLHF（从源头减少） |
| 模型 | 探索新架构，或让模型表达对生成内容的不确定性 |
| 推理与生成 | ① **RAG**：生成前先从外部知识库检索相关信息作上下文，引导基于事实回答 ② **多步推理与验证**：逐步推理 + 每步自检/外部验证 ③ **引入外部工具**：搜索引擎/计算器/代码解释器获取实时信息、做精确计算 |

> 幻觉短期难以根除，但上述策略可显著降低其频率与影响——这正是后续"记忆检索（第 8 章）"与"评估（第 12 章）"要正面解决的问题。

## 三、易错点

> **把缩放法则理解成"无限堆参数量"**：Chinchilla 表明给定算力下参数量与数据量需配比，数据质量/数量同样关键。

> **把"能力涌现"当成可随便触发**：涌现出现在数百亿~千亿规模的阈值之后，小模型做复杂推理/规划天然受限。

> **以为加了 RLHF 就无幻觉**：RLHF 是数据层面缓解，幻觉根因（自回归无事实核查）未消除，仍需 RAG/工具兜底。

> **把 RAG 当银弹**：RAG 的可靠性依赖检索质量，检索到错/无关内容同样会引导出错误回答。

> **忽略知识时效与偏见**：模型输出"看似流畅"不等于"事实正确"，关键结论需外部核验。

> **把"更大"与"更不幻觉"画等号**：规模带来能力涌现，但幻觉是自回归机制（只预测下一词、无事实核查）的固有缺陷，不会因模型更大而自动消失，仍需外围缓解。

## 四、练习

- Q1：缩放法则的核心结论？  
  A1：Loss 与参数量/数据量/计算量在对数-对数坐标下呈平滑幂律关系，持续按比例扩大三者可预测地提升性能。
- Q2：Chinchilla 修正了什么？  
  A2：给定计算预算下参数与数据存在最优配比，模型应更小但数据更多，纠正"越大越好"。
- Q3：选一种幻觉缓解方法，说明原理与适用场景？  
  A3：RAG——生成前从外部知识库检索相关片段注入上下文，让模型基于事实作答，适合知识密集/要求时效与溯源的可回答任务。
- Q4：幻觉的根本机制原因？  
  A4：训练数据可能含错；自回归只预测下一最可能词元、无内置事实核查；复杂推理逻辑链易出错。

## 六、对比与选型

| 幻觉缓解 | 原理 | 适用场景 | 局限（源文视角） |
|----------|------|----------|------------------|
| RAG | 检索外部知识注入上下文 | 知识密集、要求时效/溯源 | 依赖检索质量 |
| 多步推理与验证 | 逐步推理 + 自检/外部验证 | 多步/复杂推理 | 增加推理开销 |
| 外部工具 | 搜索引擎/计算器/解释器取实时信息 | 实时信息、精确计算 | 依赖工具可用性 |
| 数据清洗 + RLHF | 从训练源头减少事实错误 | 预训练/对齐阶段 | 无法消除生成期幻觉 |

**选型速查**：要"知识时效与溯源"用 RAG；要"精确数值/实时事实"用外部工具；要"复杂推理可审计"用多步推理与验证；三者常组合使用。
