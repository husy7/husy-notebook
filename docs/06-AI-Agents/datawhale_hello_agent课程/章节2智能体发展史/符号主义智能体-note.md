# 符号主义智能体

> 把"智能"定义为对符号的计算与逻辑推理：知识库（IF-THEN 规则）+ 推理机，在专家系统与 SHRDLU 中达到巅峰，也因常识缺失与脆弱性走向瓶颈。

## 核心原理和流程

> 简记：符号表示 → 规则推理 → 预编码知识驱行动。智能完全来自设计者预先编码的知识与规则，而非自主学习。

### 2.1.1 物理符号系统假说（PSSH）

1976 年由艾伦·纽厄尔（Allen Newell）与赫伯特·西蒙（Herbert A. Simon）两位图灵奖得主提出，是符号主义（Symbolicism，逻辑 AI / 传统 AI）的理论基石。包含两条核心论断：

1. **充分性论断**：任何一个物理符号系统，都具备产生通用智能行为的充分手段。
2. **必要性论断**：任何一个能够展现通用智能行为的系统，其本质必然是一个物理符号系统。

物理符号系统 = 一组可区分的**符号** + 一系列对符号的**操作过程**。符号可组合成结构（表达式），过程可创建/修改/复制/销毁符号结构。

核心命题：**智能的本质，就是符号的计算与处理。**

```text
符号 ──组合──> 表达式/结构 ──逻辑推理──> 结论/行动
                 ↑
        过程：创建 / 修改 / 复制 / 销毁
```

影响：把"人类心智"这一哲学问题，转化为可在计算机上工程实现的具体问题，为早期 AI（专家系统、自动规划）注入信心与方向。

### 2.1.2 专家系统：知识库 + 推理机

专家系统是符号主义最重要、最成功的应用，目标是用程序模拟人类专家在特定领域解决问题的能力。其核心特征是**知识与推理相分离**。

```text
         事实(用户输入)
              │
              ▼
     ┌───────────────────┐
     │  推理机 Inference Engine  │──结果──> 用户界面
     │  正向链 / 反向链           │
     └─────────┬─────────┘
               │ 匹配 + 应用规则
               ▼
     ┌───────────────────┐
     │  知识库 Knowledge Base │
     │  IF 条件 THEN 结论  (产生式规则) │
     └───────────────────┘
```

- **知识库（Knowledge Base）**：存放专家知识。常用知识表示方法是**产生式规则（Production Rules）**，即 `IF … THEN …` 条件语句，例如 `IF 发烧 AND 咳嗽 THEN 可能呼吸道感染`。复杂系统可含成百上千条规则，构成知识网络。
- **推理机（Inference Engine）**：通用计算引擎，根据事实在知识库中找规则、推新结论。两种工作方式：
  - **正向链（Forward Chaining）**：数据驱动，从已知事实匹配 IF、触发 THEN、把新结论加入事实库，反复直到得目标或无新规则可匹配。
  - **反向链（Backward Chaining）**：目标驱动，从假设目标（如"是否患肺炎"）出发递归找能推出它的规则，把 IF 当新子目标，直到被事实证明。

**代表系统 MYCIN（斯坦福大学，20 世纪 70 年代）**：辅助诊断细菌性血液感染并推荐抗生素。约 600 条 IF-THEN 规则，主要用**反向链**工作，从"确定致病菌"最高目标反向推导证据并向医生提问。创新点是引入**置信因子（Certainty Factor, CF）**，用 -1 到 1 的数值表示结论可信度，处理医学诊断的不确定性，比布尔逻辑更贴近现实。评估中其表现超过非专业医生、达到人类专家水平，证明了 PSSH 的有效性。

### 2.1.3 SHRDLU：积木世界里的综合智能体

特里·威诺格拉德（Terry Winograd）1968-1970 年开发。在"积木世界"（模拟三维空间，含不同形状/颜色/大小的积木与虚拟机械臂）中，通过自然语言与人类交互，执行指令或回答问题。

```text
自然语言指令 ──解析──> 理解 ──规划──> 动作序列 ──执行──> 世界状态更新
                          ↑                                    │
                          └──────────── 记忆与问答  ◄───────────┘
```

三大能力（首次把多个独立 AI 模块集成在同一系统协同工作）：

- **自然语言理解**：能解析含歧义的复杂句子，含**指代消解**（如 `Find a block which is taller than the one you are holding…` 中 `the one you are holding` 指当前抓取物）与**上下文记忆**（`Grasp the pyramid.` 后问 `What does the box contain?`）。
- **规划与行动**：自主规划动作序列，如"把蓝积木放红积木上"，若红积木上有绿积木，会先移开绿积木再放蓝积木。
- **记忆与问答**：可回答世界状态（`Is there a large block behind a pyramid?`）、行为历史（`Did you touch any pyramid before you put the green one on the little cube?`）、行为动机（`Why did you pick up the red block?` → `BECAUSE YOU ASKED ME TO.`）。

历史地位：① 综合性智能典范——"感知-思考-行动"闭环设计，奠定现代智能体研究基础；② 普及微观世界（micro-world）研究方法；③ 既激发早期 AGI 乐观，又暴露"符号处理 ≠ 真正理解"的深层挑战。

## 易错点 / 局限（2.1.4 根本性挑战）

> **知识获取瓶颈（Knowledge Acquisition Bottleneck）**：专家知识靠人工访谈/提炼/编码，成本高、难规模化；专家的内隐直觉知识很难写成 IF-THEN 规则。
> **常识问题（Common-sense Problem）**：人类靠"水是湿的""绳子可拉不可推"这类庞大常识背景，符号系统除非显式编码否则一无所知；Cyc 项目数十年努力成果仍非常有限。
> **框架问题（Frame Problem）**：动态世界中执行动作后，如何高效判断"哪些状态未变"很困难；为每个动作显式声明所有不变状态在计算上不可行，而人类能毫不费力忽略无关变化。
> **系统脆弱性（Brittleness）**：完全依赖预设规则，遇规则之外的微小变化即可能整体失灵，无法灵活变通。SHRDLU 的成功恰因运行在规则完备的封闭世界里。
> **误把"表演式智能"当理解**：SHRDLU 能力严格局限于积木世界，揭示"会操作符号"与"真正理解"之间的鸿沟。

## 练习

- Q1：PSSH 的充分性论断与必要性论断分别是什么？
  A1：充分性＝任何物理符号系统都有产生通用智能的充分手段；必要性＝任何展现通用智能的系统本质上必然是物理符号系统。
- Q2：正向链与反向链的区别？
  A2：正向链数据驱动，从事实匹配 IF 推 THEN、累积新事实；反向链目标驱动，从假设目标递归找规则、把 IF 当子目标追溯到已知事实。
- Q3：MYCIN 的置信因子（CF）解决什么问题？
  A3：用 -1 到 1 的连续值刻画结论可信度，使系统能表达不确定、模糊的医学知识，而非只能做非真即假的布尔判断。
- Q4：为什么说 SHRDLU 是"综合性智能的典范"，它的局限又是什么？
  A4：它首次把语言理解、规划、行动、记忆集成于统一系统的"感知-思考-行动"闭环；但能力局限于封闭积木世界，离开规则完备环境即失效。

## 对比与选型

| 维度         | 符号主义智能体                 | 现代 LLM 智能体              |
| ------------ | ------------------------------ | ---------------------------- |
| 知识来源     | 人工编码规则库                 | 大规模数据预训练             |
| 表示方式     | 显式符号 / IF-THEN 规则        | 参数化隐式知识               |
| 推理方式     | 逻辑推理（正向链/反向链）      | 神经 + 符号的生成式推理      |
| 不确定性处理 | CF 置信因子                    | 概率分布 / 采样              |
| 可扩展性     | 差（知识获取瓶颈、组合式规则） | 强（涌现能力、零/少样本）    |
| 可解释性     | 高（规则透明）                 | 低（黑盒）                   |
| 代表系统     | MYCIN / SHRDLU / 深蓝          | GPT 系 Agent                 |

**选型速查**：规则封闭清晰、需强可解释与合规 → 符号/规则系统；开放复杂、需泛化 → 现代 LLM Agent。
