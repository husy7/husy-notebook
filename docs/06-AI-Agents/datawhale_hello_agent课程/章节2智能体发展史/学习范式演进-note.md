# 学习范式演进与现代智能体

> 当智能无法被完全设计出来时，就让它被"学"出来——联结主义 → 强化学习 → 大规模预训练 → LLM 智能体，四条线索共同回答了"智能体的能力从哪来"。

## 核心原理和流程

> 简记：符号靠编码，联结靠调权，强化靠试错，预训练靠规模，现代 Agent 靠"预训练世界知识 + 通用推理 + 工具闭环"融合。

### 2.4.1 从符号到联结主义（Connectionism，1980s 复兴）

作为对符号主义局限的直接回应，联结主义是**自下而上**的方法，灵感来自生物大脑神经网络：

1. **知识的分布式表示**：知识不以符号/规则存储，而以**连接权重**形式分布式存在于大量简单处理单元（人工神经元）之间——整个连接模式本身就构成知识。
2. **简单的处理单元**：每个神经元只做简单计算：接收加权输入 → 过激活函数 → 输出给下一神经元。
3. **通过学习调整权重**：智能来自学习而非预写程序，靠反向传播等算法迭代调整权重，使输出逼近目标。

关键转变：符号主义把人类知识**显式编码**给机器；联结主义试图造出**能像人类一样学习知识**的机器。深度学习在 21 世纪的成功，让智能体能直接从图像/声音/文本等原始数据"理解"世界——这是符号主义时代难以想象的。

### 2.4.2 基于强化学习的智能体（RL，行为主义）

联结主义主要解决**感知**（"图里有什么"），强化学习解决**决策**（"我该做什么"），是专注**序贯决策**的学习范式：不靠标注好的静态数据集，而是通过与环境交互、在**试错**中最大化长期收益。

核心要素：

- **智能体（Agent）**：学习/决策者（AlphaGo 的决策程序）
- **环境（Environment）**：与之交互的一切（围棋规则与对手）
- **状态（State, S）**：某时刻对环境的描述（棋盘所有棋子位置）
- **行动（Action, A）**：依状态可采取的操作（合法落子）
- **奖励（Reward, R）**：执行行动后环境的标量反馈（终局赢 +1 / 输 -1）
- **策略（Policy, π）**：从状态到行动的映射，定义智能体的行为方式

工作闭环（感知-行动-学习）：

```text
        t 时刻                                   t+1
 ┌────────────┐   行动 A_t（依策略 π）   ┌──────────────┐
 │  智能体 Agent │ ─────────────────────> │  环境 Environment │
 │  (学习者)     │ <───────────────────── │   (围棋/世界)     │
 └────────────┘  状态 S(t+1) + 奖励 R(t+1) └──────────────┘
       │ 用反馈更新策略 π，优化长期累积奖励（回报 Return）
       └────────────> 需要"远见"：为未来大奖赏牺牲即时奖励（如围棋"弃子"）
```

以 AlphaGo 为例：观察棋盘现状 → 决定落子 → 终局赢/输作为正/负奖励 → 数百万次自我对弈不断调整策略，最终学会在何种棋局选何种行动最可能获胜，全程自主、不依赖人类棋谱直接指导。

### 2.4.3 基于大规模数据的预训练

RL 需海量、任务特定的交互数据，且初始缺乏先验知识。预训练解决"让智能体在学习具体任务前先具备对世界的广泛理解"：

**从特定任务到通用模型**：旧模式为每个任务（情感分析/翻译）在专门标注的中小数据上从零训练 → 知识面窄、难泛化、标注重。新范式两步：

1. **预训练（Pre-training）**：在海量通用文本上做**自监督学习**（最常见目标"预测下一个词"），学语言规律、语法结构、事实知识与上下文逻辑，不针对特定任务。
2. **微调（Fine-tuning）**：用少量下游标注数据让模型适配具体任务。

**LLM 的诞生与涌现能力**：数万亿级文本预训练后，模型权重实际构建了关于世界知识的高度压缩的隐式模型，以全新方式解决符号主义最棘手的**知识获取瓶颈**。当规模（参数量/数据量/计算量）跨过某阈值后，出现未经直接训练的**涌现能力**：

- **上下文学习（In-context Learning）**：不改权重，仅凭输入中的几个示例（Few-shot）甚至零示例（Zero-shot）即可完成新任务。
- **思维链（Chain-of-Thought）推理**：引导模型先输出一步步推理过程，显著提升逻辑/算术/常识推理准确性。

LLM 由此变成兼具"海量知识库 + 通用推理引擎"双重角色的组件。至此拼图齐备：符号主义提供逻辑推理框架，联结主义 + RL 提供学习与决策能力，LLM 提供通过预训练获得的世界知识与通用推理。

### 2.4.4 基于大语言模型的智能体

以 LLM 为核心的智能体是新范式：不仅理解与生成语言，还能与环境交互，自主**感知 → 思考 → 行动**并迭代。

```text
①感知 Perception ──观察──> ②思考 Thought（规划模块 Planning：反思/自我批判 + LLM + 记忆 Memory）
      ▲                                                         │ 工具调用 Tool Call
      │                                                         ▼
④观察 Observation <──工具结果 + 新环境状态── ③行动 Action（执行模块 Execution → 工具箱 Tool Use）
      └──────────── 更新记忆 Memory Update ────────────────────────┘
```

四步拆解：

1. **感知（Perception）**：感知模块经传感器从环境接收原始输入，形成观察（用户指令 / API 返回 / 环境状态变化）。
2. **思考（Thought）**：认知核心。规划模块做高级策略制定，用**反思（Reflection）**与**自我批判（Self-criticism）**把宏观目标分解为可执行步骤；LLM 作为中枢与**记忆模块（Memory）**交互整合历史信息，深度推理后决策出下一步操作，通常表现为**工具调用（Tool Call）**。
3. **行动（Action）**：执行模块解析指令，从**工具箱（Tool Use）**选工具（代码执行器/搜索引擎/API）与环境交互。
4. **观察（Observation）与循环**：工具执行返回**工具结果（Tool Result）**，行动改变环境产生新状态；二者构成新一轮观察，被感知模块再次捕获，LLM 据此**更新记忆（Memory Update）**，启动下一轮循环。

## 易错点 / 局限

> **混淆三种"学习"的数据来源**：监督学习需"输入-正确答案"标注对；强化学习靠环境奖励（无标注、通常延迟）适合序贯决策；预训练靠自监督海量文本。
> **把"涌现能力"当作可训练目标**：In-context Learning、CoT 是规模越过阈值后涌现的，不是被显式设计/训练出来的能力。
> **RL 只盯即时奖励**：目标是最大化**累积奖励（回报）**，有时需牺牲即时奖励换取长远收益（如围棋子"弃子"）。
> **以为 LLM 知识完备**：预训练知识绝大部分来自互联网数据，可能带来偏见、事实过时、幻觉等问题，需要对齐 / 检索增强 / 持续更新缓解。

## 练习

- Q1：联结主义与符号主义在知识表示上的本质区别？
  A1：符号主义把知识显式写成符号/IF-THEN 规则；联结主义把知识以连接权重的形式分布式存于神经元之间，连接模式本身就是知识。
- Q2：为什么强化学习特别适合序贯决策？与监督学习在数据需求上有何区别？
  A2：序贯决策中行动有长期后果，RL 靠环境奖励试错、追求累积回报，无需标注"每一步正确动作"；监督学习需要大量"输入-正确答案"标注，且常是单步独立任务。
- Q3：为什么说预训练解决了符号主义的"知识获取瓶颈"？
  A3：符号主义需人工把知识编码成规则；预训练用自监督从海量文本自动习得世界知识，把它隐式压缩进模型权重，绕开了昂贵的人工符号化。
- Q4：为什么说 LLM 驱动智能体是一次"范式跃迁"？
  A4：它把"预编码知识 + 逻辑规则"升级为"预训练世界知识 + 通用推理 + 工具调用 + 记忆"的神经-符号融合闭环，能自主感知、规划、决策、执行。
- Q5：强化学习在大语言模型训练中起什么关键作用？
  A5：用奖励反馈在试错/迭代中优化策略，用于对齐模型行为（如更符合人类偏好），是行为主义思想在后 LLM 时代的延续（具体机制见后续章节）。

## 对比与选型（四种范式）

| 范式               | 能力来源           | 表示方式       | 学习方式       | 代表系统                    | 主要局限                 |
| ------------------ | ------------------ | -------------- | -------------- | --------------------------- | ------------------------ |
| 符号主义           | 人工编码知识       | 符号 / 规则    | 无（手动编码） | MYCIN / SHRDLU / 深蓝       | 常识、瓶颈、脆弱性       |
| 联结主义           | 数据 + 反向传播    | 连接权重       | 监督/自监督    | DNN / CNN / Transformer     | 需海量数据、黑盒、感知强决策弱 |
| 强化学习（行为主义）| 与环境交互试错     | 策略 π         | 奖励反馈       | TD-Gammon / AlphaGo         | 样本效率低、奖励设计难   |
| LLM 驱动           | 预训练 + 涌现能力  | 参数化隐式知识 | 预训练 + 对齐  | GPT 系 Agent                | 幻觉、偏见、成本         |

**选型速查**：可解释封闭规则 → 符号；感知/模式识别 → 联结；序贯决策环境 → RL；开放复杂通用任务 → LLM Agent。
