## 1. 框架对比速览

| 维度 | AutoGen | AgentScope | CAMEL | LangGraph |
|------|---------|------------|-------|-----------|
| **核心范式** | 对话驱动协作 | 消息驱动架构 | 角色扮演 | 状态图/流程控制 |
| **协作模式** | 群聊/轮询 | 消息中心路由 | 双智能体对话 | 节点-边工作流 |

| **适用场景** | 多角色协作任务 | 大规模/分布式系统 | 深度双智能体协作 | 需精确控制的流程 |
| **架构风格** | 组合式/异步 | 分层模块化 | 轻架构重提示 | 图结构 |

```python
class CustomAgent(AgentBase):
    def __init__(self, name: str, **kwargs):
        super().__init__(name=name, **kwargs)
        # 智能体初始化逻辑
    
    def reply(self, x: Msg) -> Msg:
        # 智能体的核心响应逻辑
        response = self.model(x.content)
        return Msg(name=self.name, content=response, role="assistant")

        # 智能体的观察逻辑（可选）
```

```python
for n in range(chat_turn_limit):
    # step() 驱动一轮完整交互（用户+助理各发言一次）
    assistant_response, user_response = role_play_session.step(input_msg)
    
    if assistant_response.msg is None or user_response.msg is None:
        break
    
    # 处理响应...
    
    # 检测任务完成标志

```

### 4.3 关键概念

- **角色扮演 (Role-Playing)**：AI用户（需求方）+ AI助理（执行方）
- **引导性提示 (Inception Prompting)**：结构化初始指令，包含角色定义、目标、行为约束
- **轻架构重提示**：通过精心设计的初始提示实现高质量协作
- **任务标志**：`<CAMEL_TASK_DONE>` 标识任务完成
- **协作规模**：双智能体为主，已扩展支持多智能体（workforce）

```python
def should_continue(state: AgentState) -> str:
    """条件函数：根据状态决定下一步路由"""
    if len(state["messages"]) < 3:

    else:
```

**构建图**
```python
def create_assistant():
    workflow = StateGraph(SearchState)
    
    # 添加节点
    workflow.add_node("understand", understand_query_node)
    workflow.add_node("search", tavily_search_node)
    workflow.add_node("answer", generate_answer_node)
    
    # 设置入口
    workflow.set_entry_point("understand")
    
    # 线性边
    workflow.add_edge("understand", "search")
    workflow.add_edge("search", "answer")
    workflow.add_edge("answer", END)
    
    # 条件边示例
    workflow.add_conditional_edges(
        "executor",
        should_continue,
        {
            "continue_to_planner": "planner",
            "end_workflow": END
        }
    )
    
    # 编译（支持状态持久化）
    memory = InMemorySaver()
    app = workflow.compile(checkpointer=memory)
    return app

# 运行
app = create_assistant()
inputs = {"current_task": "分析最近的AI行业新闻", "messages": []}
for event in app.stream(inputs):
    print(event)
```

### 5.3 关键概念

- **状态 (State)**：全局共享数据结构（TypedDict）
- **节点 (Node)**：执行具体工作的Python函数
- **边 (Edge)**：定义流程方向（常规边 + 条件边）
- **条件边**：动态路由，实现循环和复杂分支
- **Checkpointer**：状态持久化（`InMemorySaver` / `SqliteSaver`）
- **START/END**：内置入口/出口节点

## 6. 框架设计哲学总结

| 框架 | 设计哲学 | 核心问题 |
|------|---------|---------|
| **AutoGen** | 对话驱动协作 | “谁来说”和“说什么” |
| **AgentScope** | 工程化优先 | 如何稳定、大规模运行 |
| **CAMEL** | 角色扮演涌现 | 如何让AI自主深度协作 |
| **LangGraph** | 显式流程控制 | 如何精确控制每一步 |

### 权衡维度

1. **涌现式协作 vs 显式控制**
   - AutoGen/CAMEL：定义角色和目标，协作行为自然涌现
   - LangGraph：明确定义每一步和跳转条件

2. **工程化维度**
   - AgentScope：面向生产级部署（并发、容错、分布式）
