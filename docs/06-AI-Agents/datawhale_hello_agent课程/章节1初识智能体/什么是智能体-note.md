# 什么是智能体

> 智能体 = 能感知环境、自主决策并执行行动的实体；传统智能体靠工程师显式编程，LLM 智能体靠预训练获得的"通用大脑"自主推理与调用工具。

## 一句话定义

智能体是任何能通过 **传感器（Sensors）** 感知所处 **环境（Environment）**，并 **自主** 地通过 **执行器（Actuators）** 采取 **行动（Action）** 以达成特定目标的实体。定义内含四要素：

| 要素 | 含义 | 例子 |
|------|------|------|
| 环境 Environment | 智能体所处的外部世界 | 道路交通、金融市场 |
| 传感器 Sensors | 感知环境的输入通道 | 摄像头、麦克风、雷达、API 数据流 |
| 执行器 Actuators | 作用于环境的手段 | 机械臂、方向盘、执行代码、调用服务 |
| 自主性 Autonomy | 基于感知+内部状态独立决策 | 不被动响应、不硬编码指令 |

```
        └─────────────────────────────┘
```

## 传统智能体的演进阶梯（1.1.1）

从"被动反应"到"主动学习"的五级递进：

```
简单反射 ──> 基于模型 ──> 基于目标 ──> 基于效用 ──> 学习型
(条件-动作)  (世界模型)   (规划)      (权衡)      (强化学习)
```

| 类型 | 核心问题 | 机制 | 代表例子 | 局限 |
|------|---------|------|---------|------|
| 简单反射 Simple Reflex | 直接映射当前感知 | "条件-动作"规则 | 恒温器（室温>阈值→制冷） | 无记忆、无预测，不能处理上下文 |
| 基于模型 Model-Based Reflex | 世界现在什么样？ | 内部世界模型追踪不可直接感知的状态 | 隧道中自动驾驶维持前车位置估计 | 仍是被动反应、无目标 |
| 基于目标 Goal-Based | 做什么才能达成目标？ | 面向未来状态搜索+规划 | GPS 导航（A* 算法规划最优路径） | 目标单一、不考虑代价权衡 |
| 基于效用 Utility-Based | 哪种行为最满意？ | 给世界状态赋效用值，最大化期望效用 | 时间短+省油+避拥堵的多目标权衡 | 效用函数仍靠人先验设计 |
| 学习型 Learning Agent | 能否不预设、自主学？ | 性能元件+学习元件，观察结果修正策略 | AlphaGo Zero 自我对弈 | 训练成本高、可解释性差 |

关键结论：传统智能体的决策逻辑（规则/模型/效用函数）**始终依赖人类设计师的先验知识**，直到学习型智能体才引入"从环境互动中自主学习"。

## LLM 驱动的新范式（1.1.2）

以 **GPT（Generative Pre-trained Transformer）** 为代表的大语言模型，改变了智能体的构建方法与能力边界。

| 维度 | 传统智能体 | LLM 驱动智能体 |
|------|-----------|---------------|
| 核心引擎 | 人工规则/模型/效用函数 | 预训练大语言模型 |
| 知识来源 | 工程师显式编程与知识构建 | 海量数据预训练（隐式世界模型+涌现能力） |
| 交互方式 | 结构化输入，狭窄领域 | 自然语言，高层级模糊指令 |
| 行为模式 | 确定、有边界 | 灵活、通用、可泛化 |

新范式的三项能力（以"规划一次厦门之旅"为例）：

- **规划与推理**：把高层目标分解为子任务 `[确认出行偏好] → [查询目的地信息] → [制定行程草案] → [预订票务住宿]`。
- **工具使用**：识别信息缺口并主动调用外部工具，如调天气 API，据"预报有雨"偏重室内活动。
- **动态修正**：把用户反馈（"酒店超预算"）当作新约束，调整 `查天气 → 调行程 → 订酒店` 流程。

> 要点：核心从"编写代码"转向"引导一个通用大脑去规划、行动和学习"。

## 智能体的类型（1.1.3）

三个互补分类维度：

**① 按内部决策架构**（源自《Artificial Intelligence: A Modern Approach》）：反应式 → 模型式 → 基于目标 → 基于效用；学习能力是可叠加到所有类型的"元能力"。

**② 按时间与反应性**（核心权衡：反应性 Reactivity vs 规划性 Deliberation）：

| 类型 | 决策方式 | 优势 | 局限 | 适用场景 |
|------|---------|------|------|---------|
| 反应式 Reactive | 感知→行动近乎即时映射，几乎不规划 | 速度快、计算开销低 | 短视、易陷局部最优，难做多步协调 | 安全气囊（毫秒级）、高频交易 |
| 规划式 Deliberative | 行动前探索未来、评估行动序列 | 战略远见、可处理长远任务 | 时间/计算成本高，易错过时机 | 商业计划、长途旅行 |
| 混合式 Hybrid | 分层：底层快速反应+高层规划 | 反应与规划平衡 | 设计复杂度更高 | 智能旅行助手等真实复杂任务 |

> 图 1.3 决策时间与质量关系（原文图片转 ASCII）：随"思考/规划时间"增加，决策质量上升、响应速度下降；反应式在左下（快但短视），规划式在右上（优但慢），混合式取平衡点。

LLM 智能体是一种更灵活的混合模式，在"思考-行动-观察"循环里融合两态：

- **规划（Reasoning）**：思考阶段分析现状、规划下一步 —— 审议过程。
- **反应（Acting & Observing）**：行动+观察阶段与工具/环境交互、立即反馈 —— 反应过程。

宏大任务被分解为一系列"规划-反应"微循环，既灵活应对即时变化，又通过连贯步骤完成长期目标。

**③ 按知识表示**：

| 范式 | 知识形态 | 类比 | 优势 | 局限 |
|------|---------|------|------|------|
| 符号主义 Symbolic | 显式符号+逻辑规则 | 图书管理员/规则库/知识图谱 | 透明、可解释、可追溯 | 脆弱、知识获取瓶颈 |
| 亚符号主义 Sub-symbolic | 神经网络中的统计模式 | 看上万张猫图学会"猫"的孩童 | 模式识别强、抗噪声、处理非结构化数据 | 黑箱、逻辑推理弱、易幻觉 |
| 神经符号主义 Neuro-Symbolic | 神经网络+符号推理融合 | 卡尼曼双系统（系统1直觉/系统2理性） | 既学又推，感知+认知融合 | 仍在演进中 |

LLM 智能体是神经符号主义的极佳实践：内核是神经网络（模式识别/生成），工作时却产出 Thought/Action/API 调用这类显式结构化符号，实现直觉与理性的初步融合。

## 易错点

> **误把"有智能的程序"都叫智能体**：无传感器/执行器、无自主性的纯计算程序或纯规则脚本不算智能体。判断标准看四要素是否齐备。

> **把反应式当"低级"、规划式当"高级"**：二者是"速度 vs 最优解"的取舍，不是优劣分级；安全气囊恰恰必须用反应式。

> **把 LLM 智能体的"涌现能力"理解成无所不能**：它仍是概率模型，逻辑推理弱、易产生幻觉、是黑箱，需靠外部工具和校验兜底。

## 练习

- Q1：智能体定义的四个基本要素是？  
  A1：环境、传感器（感知）、执行器（行动）、自主性。
- Q2：传统智能体与 LLM 智能体最本质的区别？  
  A2：能力来源不同——前者靠工程师显式编程（确定、有边界），后者靠海量数据预训练获得隐式世界模型与涌现能力（灵活、通用）。
- Q3：反应式/规划式/混合式各适合什么场景？  
  A3：反应式适合毫秒级即时决策（安全气囊、高频交易）；规划式适合需长远眼光的任务（商业计划、长途旅行）；混合式（含 LLM 智能体）适合既要即时应变又要长期规划的真实复杂任务。
- Q4：三种知识表示范式如何一句话区分？  
  A4：符号主义靠显式规则可解释但脆弱；亚符号主义靠神经网络学模式但黑箱；神经符号主义融合二者，LLM 智能体是其实践范例。

## 对比与选型

| 需求 | 选择 |
|------|------|
| 毫秒级快速反应、不可延迟 | 反应式智能体 |
| 长远规划、多步最优路径 | 规划式（基于目标/效用）智能体 |
| 真实复杂任务、既要快又要远 | 混合式 / LLM 智能体 |
| 高风险、必须可解释可审计 | 符号主义（规则库）方向 |
| 图像/语音等非结构化感知 | 亚符号主义（神经网络）方向 |
| 既要学习又要逻辑推理 | 神经符号主义 / LLM + 工具 |
