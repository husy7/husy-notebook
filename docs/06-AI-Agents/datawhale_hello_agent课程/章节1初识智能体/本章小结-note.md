## 关键概念串讲（1.1~1.4 一句话回顾）

- **1.1 定义与类型**：智能体 = 感知→决策→行动的自主实体；传统靠"显式编程+先验知识"，LLM 靠"预训练涌现能力"；可按决策架构、反应性（反应式/规划式/混合式）、知识表示（符号/亚符号/神经符号）三轴分类。
- **1.2 原理**：PEAS 四元组形式化环境；Agent Loop = 感知→思考（规划+工具选择）→行动→观察的闭环；交互协议把输出结构化成 Thought + Action，环境反馈封装成 Observation。
- **1.3 实战**：用系统提示词约定工具与输出格式、工具字典做路由、OpenAI 兼容客户端连任何 LLM、`for i in range(5)` 主循环驱动，三轮完成"查天气→推荐景点"。
- **1.4 协作**：工具型增强人类（Copilot/Cursor/Claude Code/Trae）；协作者型独立交付（单智能体循环 / 多智能体 / 高级控制流）；Workflow 按部就班 vs Agent 自主决策。

## 习题精选（答案为简明组织版）

- **Q1**：判断四个 case 的主体是否属于智能体及类型？  
  **A**：A 超级计算机——仅算力，无感知/目标/自主，**否**；B 特斯拉遇障毫秒级刹车——反应式智能体；C AlphaGo 评估局面规划数十步——规划式（基于目标/效用+学习型）；D ChatGPT 智能客服查订单、分析、安抚——LLM 智能体（混合式，规划+工具调用）。

- **Q2**：用 PEAS 描述"智能健身教练"，并分析环境特性？  
  **A**：P=训练达标率、用户健康与满意度；E=可穿戴设备数据流+运动场景；A=语音播报、计划下发、动作纠正提示；S=心率/强度传感器、用户输入。特性：**部分可观察**（无法精确感知用户真实疲劳/关节状态）、**随机性**（生理状态波动）、**动态性**（运动中实时变化）、**序贯**（当前训练影响后续调整）。

- **Q3**：电商退款场景下 Workflow 与 Agent 的优缺点，如何选？  
  **A**：Workflow——可预测、可解释、无幻觉、合规可审计，但规则僵硬、难覆盖新情况；Agent——灵活、能处理模糊个案，但结果不稳定、存在幻觉与不可控。规则清晰量大 → Workflow；个案复杂多变需综合判断 → Agent。方案 C：**Workflow 主流程收口确定性规则（金额/天数/特殊商品），灰色区间（如高价争议单）嵌入 Agent 辅助研判后人工/规则兜底**。

- **Q4**：为旅行助手加"记忆/备选/反思"怎么改循环？  
  **A**：记忆——在 prompt_history 外增加用户偏好字段（喜历史、预算等），工具返回时一并写入下轮 Prompt；备选——get_attraction 售罄/为空时触发二次搜索或换参数；反思——维护"被拒次数"计数，连续 3 次被拒时让 LLM 显式反思偏好并调整推荐策略。

- **Q5**：为某场景（如医疗诊断助手）划分系统 1 / 系统 2？  
  **A**：系统 1（快速直觉）处理模式识别类——影像初筛、异常信号、常规问答速答；系统 2（慢速逻辑）处理需推理的——鉴别诊断、用药禁忌核对、方案解释。协同：系统 1 先快速候选，系统 2 对高风险/冲突项复核，最终输出附带依据。

- **Q6**：LLM 智能体为何幻觉、为何限最大步数、如何评估智能？  
  **A**：幻觉源于 LLM 是概率模型，会生成看似合理但事实错误的内容；不限步数会在未收敛时反复调用工具陷入死循环；评估不能只看准确率，还需任务完成率、工具调用合理性、可解释性、鲁棒性与成本等综合指标。
