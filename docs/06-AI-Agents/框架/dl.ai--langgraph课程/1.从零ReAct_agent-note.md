# 课程笔记：从零搭建ReAct代理

## 1. 核心概念：ReAct 模式
- **ReAct** = **Reasoning**（推理）+ **Acting**（行动）。
- 工作流程循环：
  1. LLM **思考**（Thought）当前该做什么。
  2. LLM 决定并输出一个**行动**（Action）。
  3. 在外部环境执行该行动，获得**观察**（Observation）。
  4. 将观察结果反馈给LLM，重复上述步骤，直到LLM输出**最终答案**（Final Answer）。

## 2. 代理的基础架构
- **LLM** 负责推理和生成行动指令。
- **代码（运行环境）** 负责解析行动、执行函数、收集观察结果，并管理对话历史。
- 这种分离使得代理灵活且可控。

## 3. 实现步骤（Python + OpenAI）

### 3.1 初始化LLM
```python
from openai import OpenAI
client = OpenAI()
# 测试调用
response = client.chat.completions.create(model="gpt-4", messages=[{"role": "user", "content": "Hello"}])
```

### 3.2 代理类（Agent）
- 参数：系统消息（system prompt）。
- 属性：消息列表（`messages`），用于累积对话历史。
- 方法：
  - `__call__(user_message)`：添加用户消息 → 调用执行方法 → 将LLM回复（助理消息）加入历史。
  - `execute()`：调用OpenAI API，使用当前消息列表，返回模型回复内容。

### 3.3 系统提示设计（关键）
- 提示需明确告诉LLM：
  - 输出格式：`Thought: ...`，`Action: ...`，`Pause`（表示等待观察），最终输出`Answer: ...`。
  - 可用工具列表（函数名及用途）。
  - 提供一个具体示例（one-shot）帮助LLM理解格式。

**示例提示片段**：
```
You run in a loop of Thought, Action, Pause, Observation.
...
Available actions:
- calculate: e.g. calculate("2+2") returns 4
- average_dog_weight: e.g. average_dog_weight("Border Collie") returns weight
...
Example:
Question: ...
Thought: ...
Action: ...
Pause
Observation: ...
Answer: ...
```

### 3.4 实现工具函数
- `calculate(expression)`：计算数学表达式。
- `average_dog_weight(breed)`：返回预设品种体重（玩具示例）。
- 维护一个字典：`{"calculate": calculate, "average_dog_weight": average_dog_weight}`。

### 3.5 手动循环过程
1. 使用初始问题调用代理，获得LLM响应。
2. 解析响应中的`Action: <函数名> <参数>`。
3. 执行对应函数，得到观察结果。
4. 将观察结果格式化为`Observation: ...`，与之前消息一起再次调用代理。
5. 重复直到LLM输出`Answer: ...`。

## 4. 自动化循环（Query函数）

### 4.1 正则解析
```python
import re
action_re = re.compile(r'^Action: (\w+): (.*)$')   # 匹配 "Action: func: input"
```
- 用于从LLM响应中提取动作名称和输入。

### 4.2 查询函数逻辑
- 参数：`question`, `max_turns`（最大迭代次数）。
- 流程：
  1. 初始化新代理（清空历史）并设置计数器。
  2. `next_prompt = question`
  3. `while counter < max_turns`：
     - 调用代理，获取结果。
     - 用正则解析结果：
       - 若匹配到行动 → 执行对应工具函数 → 得到观察 → 构造 `"Observation: " + observation` 作为下一轮提示。
       - 若没有行动（即输出Answer） → 返回最终答案，结束循环。
  4. 打印调试信息（Thought, Action, Observation）。

### 4.3 示例运行
- 问题1：`"How much does a Toy Poodle weigh?"` → 代理正确调用工具，最终返回 `"7 pounds"`。
- 问题2：`"I have a Border Collie and a Scottish Terrier, what is their combined weight?"` → 代理分三步：查边境牧羊犬体重、查苏格兰梗体重、计算和，最终返回 `"57 pounds"`。

## 5. 关键设计要点
- **确定性问题**：设置`temperature=0`使输出更确定，便于解析。
- **历史管理**：每个代理实例维护独立消息列表，每次新问题需重新初始化。
- **错误处理**：若解析出未知动作，抛出异常。
- **工具函数可扩展**：实际应用可替换为数据库查询、API调用、文件操作等。
