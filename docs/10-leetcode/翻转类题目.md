# 翻转类题目 · 解题方法论

翻转类题目有一个**统一的解题框架**，掌握后可以应对绝大多数变体。

---

## 核心思想：三步翻转法

> **任何需要"分段重排"数组的问题，都可以用翻转来解决**

### 通用模板

```python
def solve_by_reverse(nums, left, right):
    """三步翻转法的通用模板"""
    n = len(nums)
    
    def reverse(start, end):
        while start < end:
            nums[start], nums[end] = nums[end], nums[start]
            start += 1
            end -= 1
    
    # 根据具体问题，设计三个翻转步骤
    reverse(0, n - 1)      # 步骤1
    reverse(0, k - 1)      # 步骤2
    reverse(k, n - 1)      # 步骤3
```

## 题型分类与解法

### 类型一：轮转/旋转数组

**特征**：将数组整体移动 k 步（左移或右移）

| 方向 | 操作 | 三步翻转 |
|------|------|----------|
| **右移 k 位** | 后 k 个移到前面 | ① 整体翻转 ② 前 k 翻转 ③ 后 n-k 翻转 |
| **左移 k 位** | 前 k 个移到后面 | ① 整体翻转 ② 前 n-k 翻转 ③ 后 k 翻转 |

```python
# 右移 k 位
def rotate_right(nums, k):
    n, k = len(nums), k % n
    reverse(0, n-1)
    reverse(0, k-1)
    reverse(k, n-1)

# 左移 k 位
def rotate_left(nums, k):
    n, k = len(nums), k % n
    reverse(0, n-1)
    reverse(0, n-k-1)
    reverse(n-k, n-1)
```

**记忆口诀**：
```
右移：全翻 → 前k翻 → 后n-k翻
左移：全翻 → 前n-k翻 → 后k翻
```

---

### 类型二：反转字符串/数组

**特征**：将数组/字符串整体或部分反转

```python
# 344. 反转字符串
def reverseString(s):
    left, right = 0, len(s) - 1
    while left < right:
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1

# 541. 反转字符串 II（每 2k 个字符反转前 k 个）
def reverseStr(s, k):
    s = list(s)
    for i in range(0, len(s), 2*k):
        s[i:i+k] = reversed(s[i:i+k])
    return ''.join(s)

# 151. 反转字符串中的单词
def reverseWords(s):
    # 先整体翻转，再翻转每个单词
    s = s.strip().split()
    s.reverse()
    return ' '.join(s)
```

### 类型三：旋转矩阵

**特征**：二维矩阵顺时针/逆时针旋转

```python
# 48. 旋转图像（顺时针旋转 90°）
def rotate(matrix):
    n = len(matrix)
    # 方法1：先转置，再每行反转
    for i in range(n):
        for j in range(i, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()
    
    # 方法2：四角旋转（更复杂但更高效）
```

| 旋转方向 | 操作 |
|---------|------|
| 顺时针 90° | 转置 + 每行反转 |
| 逆时针 90° | 转置 + 每列反转 |
| 旋转 180° | 行反转 + 列反转 |

---

### 类型四：局部反转

**特征**：反转数组的特定区间

```python
# 按 k 个一组反转链表/数组
def reverseKGroup(arr, k):
    n = len(arr)
    for i in range(0, n, k):
        if i + k <= n:
            reverse(i, i + k - 1)
```

## 核心规律：翻转的本质

### 翻转操作对应的数学变换

```
原数组: [a₁, a₂, ..., aₙ]
翻转后: [aₙ, ..., a₂, a₁]
```

### 组合翻转的规律

```
右移 k 位 = 翻转 + 分段翻转
数学表达: ROTATE_RIGHT(A, k) = (A^R 的前 k 个翻转)(A^R 的后 n-k 个翻转)
```

## 解题三步法

### Step 1：确定操作类型

```
问自己几个问题：
□ 是整体移动还是部分移动？
□ 移动方向是左还是右？
□ 是否需要分段？
□ 有没有边界条件（k 可能大于 n）？
```

### Step 2：设计翻转步骤

```
画出数组，标注分段点
例: [1,2,3,4,5,6,7], k=3

目标: [5,6,7,1,2,3,4]
       ↑   ↑ ↑     ↑
       分界点: k=3

操作序列:
① 整体翻转: [7,6,5,4,3,2,1]
② 前 k 个翻转: [5,6,7,4,3,2,1]
③ 后 n-k 个翻转: [5,6,7,1,2,3,4]
```

### Step 3：处理边界

```python
# 必须处理的情况
k %= n  # k 可能大于 n
if k == 0: return  # k 为 0 或 n 的倍数
```

## 示例题详解

### 例题1：左移 k 位

```python
# 输入: [1,2,3,4,5,6,7], k=3
# 输出: [4,5,6,7,1,2,3]  (前3个移到后面)

def rotate_left(nums, k):
    n = len(nums)
    k %= n
    
    def reverse(l, r):
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
    
    # 关键三步
    reverse(0, n - 1)       # [7,6,5,4,3,2,1]
    reverse(0, n - k - 1)   # [4,5,6,7,3,2,1]
    reverse(n - k, n - 1)   # [4,5,6,7,1,2,3]
```

### 例题2：交换前后两部分

```python
# 输入: [1,2,3,4,5,6], 分成 [1,2,3] 和 [4,5,6]
# 输出: [4,5,6,1,2,3]  (交换前后两部分)

def swap_parts(nums, split):
    # 等价于左移 split 位
    rotate_left(nums, split)
```

### 例题3：数组局部反转

```python
# 输入: [1,2,3,4,5,6,7], 反转索引 2 到 5
# 输出: [1,2,6,5,4,3,7]

def reverse_range(nums, left, right):
    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1
```

## 通用解题模板（可直接套用）

```python
class ReverseTemplate:
    def solve(self, nums, params):
        n = len(nums)
        
        # 定义反转函数
        def reverse(start, end):
            while start < end:
                nums[start], nums[end] = nums[end], nums[start]
                start += 1
                end -= 1
        
        # 1. 参数处理
        k = params % n  # 取模
        
        # 2. 根据题目类型设计步骤
        # 类型A: 整体反转
        reverse(0, n - 1)
        
        # 类型B: 分段反转
        reverse(0, k - 1)
        reverse(k, n - 1)
        
        # 类型C: 按组反转
        for i in range(0, n, k):
            if i + k <= n:
                reverse(i, i + k - 1)
```

## 面试技巧

### 回答步骤

1. **画图说明**：在纸上画出数组，标注关键位置
2. **推导公式**：展示从目标反推翻转步骤
3. **代码实现**：先写 reverse 辅助函数，再组合
4. **边界测试**：k=0, k=n, n=1 等特殊情况

### 常见错误

| 错误 | 正确做法 |
|------|----------|
| ❌ 忘记 `k %= n` | ✅ 必须取模，否则 k 可能大于 n |
| ❌ 翻转区间计算错误 | ✅ 画图确认 left 和 right |
| ❌ 改变了原数组 | ✅ 题目要求 in-place 时注意 |
| ❌ 混淆左右移动 | ✅ 右移：前 k 翻；左移：后 k 翻 |

## 一句话总结

> **翻转类题目的核心是：确定分界点 → 分段翻转 → 处理边界。记住"右移：全翻前k后n-k；左移：全翻前n-k后k"这个口诀，三步翻转法通杀所有数组轮转问题！** 🔄
