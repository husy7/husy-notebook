## 2. 题目理解
*   **输入**：一个字符串 `s`。
*   **输出**：布尔值 `true` 或 `false`。
*   **核心规则**：
    *   只考虑字母和数字字符（字母数字字符）。
    *   忽略字母的大小写。
    *   判断处理后的字符串是否正着读和反着读都一样（即回文串）。
*   **示例分析**：
    *   `"A man, a plan, a canal: Panama"` -> `true`：移除空格和标点后得到 `"amanaplanacanalpanama"`，正反读相同。
    *   `"race a car"` -> `false`：处理后得到 `"raceacar"`，正反读不同。
    *   `" "` -> `true`：移除所有非字母数字字符后得到空字符串 `""`，空字符串视为回文串。

## 3. 解题思路与策略
*   **思路方向**：
    *   *方向 A (字符串预处理 + 反转比较)*：先过滤原字符串，只保留字母数字并转为小写，然后比较该字符串与其反转是否相等。时间复杂度 `O(n)`，空间复杂度 `O(n)`。
    *   *方向 B (双指针原地判断)*：**<-- 选择此方向**。直接在原字符串上使用左右两个指针，跳过非字母数字字符，边移动边比较（忽略大小写）。时间复杂度 `O(n)`，空间复杂度 `O(1)`。
*   **双指针直觉**：
    *   核心思想：从字符串两端向中间移动两个指针，每次跳过无效字符后比较对应字符是否相等。
    *   关键变量：`left` 指向左端有效字符，`right` 指向右端有效字符。
    *   关键判断：当 `left < right` 时，先移动 `left` 和 `right` 跳过非字母数字，再比较 `s[left].lower()` 与 `s[right].lower()`。
    *   终止条件：若发现不相等直接返回 `False`；若两指针相遇或交叉则说明全部匹配，返回 `True`。

## 4. 算法步骤
1.  初始化左指针 `left = 0`，右指针 `right = len(s) - 1`。
2.  进入循环，当 `left < right` 时：
    *   子步骤 2.1：向右移动 `left`，直到 `s[left]` 是字母数字字符（注意保持 `left < right`）。
    *   子步骤 2.2：向左移动 `right`，直到 `s[right]` 是字母数字字符（注意保持 `left < right`）。
    *   子步骤 2.3：比较 `s[left].lower()` 和 `s[right].lower()`，若不相等则返回 `False`。
    *   子步骤 2.4：`left += 1`，`right -= 1`。
3.  循环结束后返回 `True`。

## 5. 复杂度分析
*   **时间复杂度**：`O(n)`，其中 `n` 是字符串长度。每个字符最多被访问两次（一次由左指针，一次由右指针）。
*   **空间复杂度**：`O(1)`，只使用了常数额外空间。

## 6. 代码实现
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        
        while left < right:
            # 跳过左侧非字母数字字符
            while left < right and not s[left].isalnum():
                left += 1
            # 跳过右侧非字母数字字符
            while left < right and not s[right].isalnum():
                right -= 1
            
            # 比较字符（忽略大小写）
            if s[left].lower() != s[right].lower():
                return False
            
            left += 1
            right -= 1
        
        return True
```

## 7. 边界情况与易错点
*   **边界 1**：空字符串或全是非字母数字字符（如 `" "`、`".,!"`） → 预期返回 `true`。代码中 `left = 0, right = len(s)-1`，若 `right < 0` 则循环不进入，直接返回 `True`；若有字符但全是无效字符，内层跳过循环会使得 `left` 和 `right` 相遇或交叉，外层循环结束，返回 `True`。
*   **边界 2**：只有一个有效字符（如 `"a"`、`"1"`） → 预期返回 `true`。循环开始时 `left = 0, right = 0`，不满足 `left < right`，直接返回 `True`。
*   **易错点**：
    - 在跳过非字母数字字符时忘记加 `left < right` 条件，可能导致越界。
    - 比较时没有统一大小写，导致 `"A"` 和 `"a"` 被认为不同。
*   **反例思考**：
    - `s = ".,"`，`left=0, right=1`，内层第一个 `while` 跳过 `'.'` 后 `left` 变为 1，此时 `left == right`，内层第二个 `while` 条件 `left < right` 为假，不执行；比较时 `s[1]` 是 `','`，但此时 `left=1, right=1`，已经不满足外层 `while left < right` 条件，直接退出循环返回 `True`。代码正确。

## 8. 做题思路总结
*   **回文串类题目常用双指针法**：从两端向中间遍历，逐步比较对应字符。
*   **处理字符限制**：当题目要求忽略某些字符或忽略大小写时，指针移动时跳过无效字符，比较前统一格式（如转为小写）。
*   **循环条件**：始终保证 `left < right`，避免越界和重复比较。
*   **举一反三**：类似题目如“验证回文串 II”（允许删除一个字符）、“最长回文子串”等都可基于双指针或中心扩展法解决。
