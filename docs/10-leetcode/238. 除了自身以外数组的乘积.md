## 1. 基本信息
*   **题目编号/标题**：[238. 除了自身以外数组的乘积]
*   **难度**：[中等]
*   **标签**：[数组、前缀积、后缀积]
*   **题目链接**：[LeetCode 238](https://leetcode.com/problems/product-of-array-except-self/)

## 2. 题目理解
*   **输入**：一个整数数组 `nums`，长度为 `n`。
*   **输出**：一个整数数组 `answer`，其中 `answer[i]` 等于 `nums` 中除了 `nums[i]` 之外其余所有元素的乘积。
*   **核心规则**：
    *   不能使用除法。
    *   时间复杂度必须为 `O(n)`。
    *   题目保证任意元素的前缀乘积和后缀乘积都在 32 位整数范围内（即不会溢出）。
    *   目标：计算每个位置除自身外的乘积。
*   **示例分析**：
    *   `[1,2,3,4]` -> `[24,12,8,6]`：
        - `answer[0] = 2*3*4 = 24`
        - `answer[1] = 1*3*4 = 12`
        - `answer[2] = 1*2*4 = 8`
        - `answer[3] = 1*2*3 = 6`
    *   `[-1,1,0,-3,3]` -> `[0,0,9,0,0]`：
        - `answer[2] = (-1)*1*(-3)*3 = 9`，其余位置因包含 `0` 而乘积为 `0`。

## 3. 解题思路与策略
*   **思路方向**：
    *   *方向 A (暴力法)*：对每个位置，遍历其他所有元素求乘积。时间复杂度 `O(n²)`，不满足要求。
    *   *方向 B (除法)*：先求所有元素总乘积，再对每个位置除以 `nums[i]`。但题目禁止使用除法，且若存在 `0` 会失败。
    *   *方向 C (前缀积 + 后缀积)*：**<-- 选择此方向**。对于每个位置 `i`，其结果 = `nums[0..i-1]` 的乘积 × `nums[i+1..n-1]` 的乘积。可通过两次遍历分别计算前缀积和后缀积，时间复杂度 `O(n)`，空间复杂度可优化为 `O(1)`（不考虑输出数组）。
*   **前缀积 + 后缀积直觉**：
    *   核心思想：将每个位置的结果拆分为"左侧所有元素的乘积"和"右侧所有元素的乘积"两部分，分别计算后相乘。
    *   关键变量：`prefix` 记录从左到右的累积乘积；`suffix` 记录从右到左的累积乘积；`answer` 数组存储最终结果。
    *   第一次遍历：从左到右，将 `prefix` 存入 `answer[i]`，然后更新 `prefix *= nums[i]`。此时 `answer[i]` 存储的是 `nums[0..i-1]` 的乘积（左侧乘积）。
    *   第二次遍历：从右到左，将 `answer[i]` 乘上 `suffix`（右侧乘积），然后更新 `suffix *= nums[i]`。最终 `answer[i] = 左侧乘积 × 右侧乘积`。
    *   终止条件：两次遍历完整数组。

## 4. 算法步骤
1.  初始化：`n = len(nums)`，`answer = [1] * n`，`prefix = 1`。
2.  第一次遍历（计算左侧乘积）：
    *   对于 `i` 从 `0` 到 `n-1`：
        *   `answer[i] = prefix`
        *   `prefix *= nums[i]`
3.  初始化 `suffix = 1`。
4.  第二次遍历（计算右侧乘积并合并）：
    *   对于 `i` 从 `n-1` 到 `0`：
        *   `answer[i] *= suffix`
        *   `suffix *= nums[i]`
5.  返回 `answer`。

## 5. 复杂度分析
*   **时间复杂度**：`O(n)`。两次线性遍历，每次 `O(n)`。
*   **空间复杂度**：`O(1)`（不考虑输出数组 `answer`）。仅使用了常数级别的额外变量 `prefix` 和 `suffix`。

## 6. 代码实现
```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        answer = [1] * n
        
        # 第一次遍历：计算左侧乘积
        prefix = 1
        for i in range(n):
            answer[i] = prefix
            prefix *= nums[i]
        
        # 第二次遍历：乘以右侧乘积
        suffix = 1
        for i in range(n - 1, -1, -1):
            answer[i] *= suffix
            suffix *= nums[i]
        
        return answer
```

## 7. 边界情况与易错点
*   **边界 1**：数组长度为 1（`nums = [x]`）。
    - 预期结果：`[1]`（除自身外没有其他元素，乘积为 1）。
    - 代码处理：第一次遍历 `answer[0] = 1`；第二次遍历 `answer[0] *= 1`，结果正确。
*   **边界 2**：数组包含 0。
    - 例如 `nums = [0, 1]`，预期 `[1, 0]`。
    - 代码处理：左侧乘积：`answer[0]=1`，`answer[1]=0`；右侧乘积：`i=1` 时 `suffix=1`（`nums[1]` 右侧无元素），`answer[1]=0`，`suffix=1`；`i=0` 时 `answer[0] = 1 * 1 = 1`，`suffix = 0`。结果正确。
*   **易错点**：
    - 第二次遍历时忘记更新 `suffix`，导致所有位置乘以同一个右侧值。
    - 误用除法（题目禁止）。
    - 混淆前缀和后缀的边界：`prefix` 在赋值给 `answer[i]` 后才乘 `nums[i]`，确保 `answer[i]` 不包含 `nums[i]` 本身。
*   **反例思考**：
    - `nums = [2, 3, 4]`，若先乘后赋值：`prefix = 2`，`answer[0] = 2`（错误，应不含 `nums[0]`）。正确做法：先赋值再更新 `prefix`，得到 `answer[0] = 1`。

## 8. 做题思路总结

对于“除自身以外数组的乘积”这类需要利用前缀/后缀信息的数组题目，可以总结出以下通用解题思路：

1. **识别模式**：题目要求计算每个位置与左右两侧元素相关的结果（如乘积、和、最大最小值等），且限制不能使用某些操作（如除法）或要求 O(n) 复杂度。
2. **拆分问题**：将每个位置的结果拆分为“左侧部分”和“右侧部分”的组合。通常左侧部分可以通过一次正向遍历累积计算，右侧部分通过一次反向遍历累积计算。
3. **空间优化**：如果只需要最终结果数组，可以先利用结果数组存储左侧信息，再在反向遍历时乘以右侧信息，从而实现 O(1) 额外空间（不计输出）。
4. **处理边界**：注意数组首尾元素的“空积”或“空和”默认值（乘积为1，和为0），确保循环边界正确。
5. **注意顺序**：在遍历中先使用当前累积值更新结果，再更新累积值（将当前元素纳入累积），从而排除自身。
6. **举一反三**：类似题目如接雨水（左右最大高度）、分发糖果（左右规则）、除自身以外数组的乘积等，都可以用两次遍历或前缀/后缀数组解决。
