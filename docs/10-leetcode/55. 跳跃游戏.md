## 1. 基本信息
*   **题目编号/标题**：55. 跳跃游戏
*   **难度**：中等
*   **标签**：贪心、数组、动态规划
*   **题目链接**：[LeetCode 55](https://leetcode.com/problems/jump-game/)
## 2. 题目理解
*   **输入**：非负整数数组 `nums`，初始位置在 `index 0`。
*   **输出**：布尔值，能否到达最后一个下标。
*   **核心规则**：
    *   数组元素 `nums[i]` 代表在位置 `i` **最大**能跳的长度。
    *   可以选择跳比该值小的步数。
    *   目标：从下标 0 跳到下标 `n-1`。
*   **示例分析**：
    *   `[2,3,1,1,4]` -> `true`：0->1 (跳1步) -> 4 (跳3步)。或者 0->2->3->4。
    *   `[3,2,1,0,4]` -> `false`：虽然能跳到下标 3，但下标 3 值为 0，卡住了，无法到达 4。
## 3. 解题思路与策略
*   **思路方向**：
    *   *方向 A (回溯/DFS)*：尝试所有跳法，时间复杂度指数级，不可行。
    *   *方向 B (动态规划)*：定义 `dp[i]` 为能否到达位置 `i`。`O(n^2)`，可行但非最优。
    *   *方向 C (贪心算法)*：**<-- 选择此方向**。不需要关心每一步具体跳几步，只需要关心“目前能到达的最远边界在哪里”。
*   **贪心直觉**：
    *   我们遍历数组，维护一个变量 `max_reach`（当前能到达的最远下标）。
    *   只要当前遍历到的下标 `i` 没有超过 `max_reach`，说明我们是可以到达 `i` 的。
    *   在到达 `i` 的基础上，我们尝试更新 `max_reach` 为 `max(max_reach, i + nums[i])`。
    *   如果在遍历过程中，`max_reach` 已经大于等于最后一个下标，直接返回 `true`。
    *   如果遍历结束还没到达，或者某一步 `i > max_reach`，说明卡住了，返回 `false`。
## 4. 算法步骤
1.  初始化 `max_reach = 0`。
2.  遍历数组 `nums`，下标 `i` 从 0 到 `len(nums) - 1`：
    *   **判断能否继续**：如果 `i > max_reach`，说明当前所在的位置之前根本跳不过来，直接返回 `false`。
    *   **更新最远距离**：`max_reach = max(max_reach, i + nums[i])`。
    *   **提前终止**：如果 `max_reach >= len(nums) - 1`，说明已经可以覆盖终点，返回 `true`。
3.  遍历结束，返回 `true`（隐含了能走完的情况）。
## 5. 复杂度分析
*   **时间复杂度**：`O(n)`。只需要遍历一次数组。
*   **空间复杂度**：`O(1)`。只使用了常数个额外变量（`max_reach`, `i`）。
## 6. 代码实现
```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        max_reach = 0
        n = len(nums)
        
        # 只需要遍历到 n-1，因为如果到了 n-1 前一个位置能跳过去即可
        # 但为了逻辑统一，遍历整个数组也没问题
        for i in range(n):
            # 如果当前下标超过了目前能跳到的最远距离，说明卡住了
            if i > max_reach:
                return False
            
            # 更新能跳到的最远距离
            max_reach = max(max_reach, i + nums[i])
            
            # 如果最远距离已经覆盖了最后一个下标，提前结束
            if max_reach >= n - 1:
                return True
                
        return True
```
## 7. 边界情况与易错点
*   **边界 1**：数组长度为 1。此时本来就在终点，应直接返回 `true`。（代码逻辑中 `max_reach` 初始为 0，`n-1` 为 0，`max_reach >= n-1` 成立，正确）。
*   **边界 2**：数组包含 0。如 `[2, 0, 0]`。`max_reach` 会被更新为 2，`i=1` 时 `1 < 2` 通过，`i=2` 时 `2 < 2` 不通过（等于可以通过），返回 `true`。
*   **易错点**：题目说的是“最大长度”，不是“必须跳这么长”。贪心算法正是利用了这一点，取最大覆盖范围。
*   **反例思考**：如果是 `[0, 2, 3]`。`i=0` 时 `max_reach=0`。`i=1` 时，`i > max_reach` (1 > 0)，直接返回 `false`。正确。
