# 买卖股票的最佳时机（一次交易）

> **一句话总结**：  
> 遍历时记录历史最低价，每天尝试以当天价格卖出并更新最大利润。

## 核心原理 / 流程

**核心思想**：要获得最大利润，就是在历史最低点买入，在之后的某个高点卖出。一次遍历即可完成。

**贪心流程口诀**：`边走边记最低价，每天算算赚多少，更新答案取最大。`

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float('inf')
        max_profit = 0
        
        for price in prices:
            # 1. 更新历史最低价（潜在买入点）
            if price < min_price:
                min_price = price
            # 2. 计算如果今天卖出能赚多少
            profit = price - min_price
            # 3. 更新最大利润
            if profit > max_profit:
                max_profit = profit
                
        return max_profit
```

**状态转移图（DP视角）**：

```
第i天有两个状态：
- 持有股票：dp_hold = max(dp_hold, -price[i])  # 之前持有 或 今天买入
- 不持有股票：dp_not_hold = max(dp_not_hold, dp_hold + price[i])  # 之前不持有 或 今天卖出
```

## 易错点 / 坑

- ❌ 错误现象：初始化 `min_price = 0`，导致价格全为正时，min_price 永远为 0，算不出利润。  
  ✅ 正确做法：初始化 `min_price = float('inf')`（正无穷），让第一个价格成为新的最小值。

- ❌ 错误现象：先计算 profit 再更新 min_price，顺序反了。  
  ✅ 正确做法：先更新最低价，再计算利润（保证“先买后卖”的顺序）。

- ❌ 错误现象：认为需要找“全局最低”和“全局最高”且最高在最低之后，尝试先找最低再找最高。  
  ✅ 正确做法：一次遍历即可，不需要事后找。因为遍历顺序天然保证“卖出日在买入日之后”。

## 提取练习

- Q1：如果价格一直下跌，如 `[7,6,4,3,1]`，算法会返回什么？为什么？  
  A1：返回 0。因为 `min_price` 一直在更新为更低价格，每次 `profit = price - min_price = 0`，所以 `max_profit` 保持为 0，表示不交易。

- Q2：能否用两层循环暴力求解？复杂度是多少？  
  A2：可以，`for i in range(n): for j in range(i+1, n): max(prices[j]-prices[i])`，时间复杂度 O(n²)，空间 O(1)。本题数据范围大时超时，需要用 O(n) 的贪心/DP。

- Q3：如果允许“同一天买入并卖出”会怎样？  
  A3：利润为 0，不影响结果，因为题目要求利润为正才交易，0 表示不交易。

## 对比

| 方案 | 核心思想 | 时间复杂度 | 空间复杂度 | 最佳场景 |
|------|---------|-----------|-----------|----------|
| 暴力枚举 | 所有买入卖出对 | O(n²) | O(1) | n ≤ 10³ |
| 贪心（单次遍历） | 记录历史最低 | O(n) | O(1) | **通用最优** |
| DP（状态机） | 持有/不持有两状态 | O(n) | O(1) | 便于扩展到多次交易 |

**选型速查**：要 **最高效、最简洁** 选贪心；要 **统一框架（方便扩展到K次）** 选 DP。

## 深度源码/原理（可选）

**DP 状态机推导**（更通用，可用于系列题目）：

定义：
- `dp[i][0]`：第 i 天结束后，**不持有**股票的最大利润
- `dp[i][1]`：第 i 天结束后，**持有**股票的最大利润

状态转移：
```
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
dp[i][1] = max(dp[i-1][1], -prices[i])
```
因为只能交易一次，所以买入时利润直接为 `-prices[i]`，而不是 `dp[i-1][0] - prices[i]`（后者是无限次交易的写法）。

化简为变量：
```python
not_hold = 0
hold = -float('inf')
for p in prices:
    not_hold = max(not_hold, hold + p)
    hold = max(hold, -p)
return not_hold
```
