## 1. 基本信息
*   **题目编号/标题**：[380. O(1) 时间插入、删除和获取随机元素]
*   **难度**：[中等]
*   **标签**：[数组, 哈希表, 数学, 设计, 随机化]
*   **题目链接**：[LeetCode 380. Insert Delete GetRandom O(1)](https://leetcode.com/problems/insert-delete-getrandom-o(1)/)
## 2. 题目理解
*   **输入**：一系列对 `RandomizedSet` 类的方法调用，参数为整数 `val`。
*   **输出**：`insert` 和 `remove` 返回布尔值表示成功与否，`getRandom` 返回集合中的一个随机整数。
*   **核心规则**：
    *   **规则1**：集合中元素唯一。
    *   **规则2**：时间复杂度限制非常严格，`insert`、`remove`、`getRandom` 的平均时间复杂度都必须是 $O(1)$。
    *   **规则3**：`getRandom` 必须保证等概率返回集合中的任意元素。
*   **示例分析**：
    *   `insert(1)` -> `true`：集合为空，插入成功。
    *   `remove(2)` -> `false`：集合中没有 2，删除失败。
    *   `insert(2)` -> `true`：集合变为 `[1, 2]`。
    *   `getRandom()` -> `1` 或 `2`：随机选择一个。
## 3. 解题思路与策略
*   **思路方向**：
    *   *方向 A (仅使用哈希表)*：哈希表的插入、删除和查找都是 $O(1)$。但是，哈希表不支持“随机获取一个键”，因为键的存储不是连续的，无法通过索引直接访问，只能先获取所有键（$O(N)$），然后随机选一个，不满足要求。
    *   *方向 B (仅使用数组)*：数组支持通过索引 $O(1)$ 访问，因此 `getRandom` 很容易实现（生成随机索引）。但是，数组的 `insert` 判断是否存在需要遍历（$O(N)$），且 `remove` 操作为了保证内存连续性，需要移动后续元素（$O(N)$），不满足要求。
    *   *方向 C (哈希表 + 数组)*：**<-- 选择此方向**。
        *   **数组**：存储具体的数值。利用 `append` 实现 $O(1)$ 插入；利用索引访问实现 $O(1)$ 随机获取。
        *   **哈希表**：存储 `数值 -> 数组索引` 的映射。利用它实现 $O(1)$ 查找元素是否存在，以及 $O(1)$ 定位元素在数组中的位置。
        *   **难点解决**：为了实现数组的 $O(1)$ 删除，我们采用“交换末尾元素”的策略。
*   **[变长数组 + 哈希表]直觉**：
    *   [核心思想]：用数组存值以便随机访问，用哈希表存下标以便快速定位。删除元素时，将待删元素与数组最后一个元素交换位置，然后删除最后一个元素。
    *   [关键变量/数据结构的作用]：
        *   `nums`：List[int]，存储元素值。
        *   `val_to_index`：Dict[int, int]，存储元素值到 `nums` 索引的映射。
    *   [遍历或递推过程中的关键判断条件]：
        *   删除时：先查哈希表判断存不存在。如果存在，拿到它的索引 `i` 和数组最后一个元素 `last`。把 `last` 挪到 `i` 的位置，更新哈希表中 `last` 的索引为 `i`，然后 `pop` 数组末尾，删除哈希表中原元素。
    *   [终止条件或提前返回的时机]：
        *   插入/删除时，如果元素已存在/不存在，直接返回 false，不执行后续操作。
## 4. 算法步骤
1.  **初始化**：创建一个空列表 `nums` 和一个空字典 `val_to_index`。
2.  **insert(val)**：
    *   如果 `val` 在 `val_to_index` 中，返回 `false`。
    *   将 `val` 追加到 `nums` 末尾。
    *   在 `val_to_index` 中记录 `val` 的索引为 `len(nums) - 1`。
    *   返回 `true`。
3.  **remove(val)**：
    *   如果 `val` 不在 `val_to_index` 中，返回 `false`。
    *   获取 `val` 的索引 `idx`。
    *   获取数组最后一个元素 `last_elem = nums[-1]`。
    *   将 `nums[idx]` 更新为 `last_elem`（覆盖待删除元素）。
    *   更新 `val_to_index[last_elem] = idx`（更新被挪动元素的索引）。
    *   弹出 `nums` 的最后一个元素（`nums.pop()`）。
    *   从 `val_to_index` 中删除 `val`。
    *   返回 `true`。
4.  **getRandom()**：
    *   生成一个范围在 `[0, len(nums) - 1]` 的随机整数 `r`。
    *   返回 `nums[r]`。
## 5. 复杂度分析
*   **时间复杂度**：`O(1)`。
    *   `insert`：字典判断 $O(1)$，数组追加 $O(1)$，字典插入 $O(1)$。
    *   `remove`：字典查询 $O(1)$，数组末尾元素访问 $O(1)$，数组元素修改 $O(1)$，字典修改 $O(1)$，数组弹出 $O(1)$。
    *   `getRandom`：生成随机数 $O(1)$，数组索引访问 $O(1)$。
*   **空间复杂度**：`O(N)`。其中 N 为元素个数，需要额外的数组和字典来存储所有元素。
## 6. 代码实现
```python
import random
class RandomizedSet:
    def __init__(self):
        # 初始化数组和字典
        self.nums = []           # 存储数值
        self.val_to_index = {}   # 存储数值到索引的映射
    def insert(self, val: int) -> bool:
        # 如果 val 已存在，返回 False
        if val in self.val_to_index:
            return False
        
        # 添加到数组末尾
        self.nums.append(val)
        # 记录 val 的索引
        self.val_to_index[val] = len(self.nums) - 1
        return True
    def remove(self, val: int) -> bool:
        # 如果 val 不存在，返回 False
        if val not in self.val_to_index:
            return False
        
        # 获取 val 的索引
        idx = self.val_to_index[val]
        # 获取数组最后一个元素
        last_elem = self.nums[-1]
        
        # 将最后一个元素移动到 idx 的位置
        self.nums[idx] = last_elem
        # 更新哈希表中最后一个元素的索引
        self.val_to_index[last_elem] = idx
        
        # 移除数组最后一个元素
        self.nums.pop()
        # 移除哈希表中的 val
        del self.val_to_index[val]
        
        return True
    def getRandom(self) -> int:
        # 随机选择一个索引返回
        return random.choice(self.nums)
# Your RandomizedSet object will be instantiated and called as such:
# obj = RandomizedSet()
# param_1 = obj.insert(val)
# param_2 = obj.remove(val)
# param_3 = obj.getRandom()
```
## 7. 边界情况与易错点
*   **边界 1**：删除集合中唯一的元素。
    *   此时 `idx` 为 0，`last_elem` 也是它自己。代码逻辑 `self.nums[0] = self.nums[-1]` 依然成立（自己赋值给自己），`pop` 后数组变空，字典变空，逻辑正确。
*   **边界 2**：删除最后一个元素。
    *   如果要删除的元素正好在数组末尾，逻辑同样是将其与自己交换，然后弹出，处理一致，无需特殊判断。
*   **易错点**：在 `remove` 操作中，容易忘记更新“被交换过来的末尾元素”在哈希表中的索引。
    *   如果不做 `self.val_to_index[last_elem] = idx`，那么哈希表中记录的还是 `last_elem` 的旧索引（即末尾位置），当再次删除 `last_elem` 或查询它时就会出错。
*   **易错点**：`insert` 时忘记检查元素是否存在。虽然哈希表 `insert` 会覆盖，但题目要求元素唯一，若已存在需返回 `false`。
