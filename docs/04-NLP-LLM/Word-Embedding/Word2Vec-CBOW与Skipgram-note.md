# Word2Vec：CBOW 与 Skip-gram 的结构、负采样与训练细节

## 定义

Word2Vec 是 2013 年 Mikolov 等人提出的**静态词向量（word embedding）训练方法**。它把"预测共现"伪装成监督任务，训练时顺带学出一张词向量表：**语义相近的词（上下文分布相似）会被拉到向量空间相邻位置**。它解决的问题是：如何不靠人工标注，仅从大规模无标注语料中自动获得稠密、可参与计算、自带语义相似度的词向量，替代 one-hot / 词袋这种高维稀疏且无语义可比性的表示。

核心特征有三：一是**自监督**——语料里天然存在的 (中心词, 上下文词) 共现对就是标签，不需要人工标注，根基是分布假说 *You shall know a word by the company it keeps*（语义相近 → 上下文相似）；二是**预测式训练**——让模型完成"填词"任务（用上下文猜中心词，或用中心词猜上下文），词向量只是训练副产物；三是**静态**——每个词最终只有一个向量，学到的 是"分布相似"而不是"语义等价"（反义词如 good/bad 上下文相似，余弦可能很高），因此适合做特征、基线、检索映射，多义词场景要让位给上下文嵌入（BERT / LLM 内部表示）。

CBOW 与 Skip-gram 是同一思想的"预测方向"互逆的两个版本：CBOW 聚合上下文预测中心词，Skip-gram 用中心词分别预测每个上下文词。适用范畴：词级输入的 NLP 任务前置表示层；中文需先分词；无监督、无标注、无需训练标签；与 GloVe / 上下文嵌入的结论性对比见同目录《词嵌入与Word2Vec》。

## 原理

整体流程：语料 → 以窗口取 (中心词, 上下文词) 共现对 →（可选）词频子采样与动态窗口 → 初始化词向量表 → 对每个样本做一次判别式更新 → 收敛后取向量表。为什么这样设计：直接建模整个词表上的共现概率分布不可行（分母遍历 V 太大），于是把密度估计换成判别式二分类任务，训练信号只来自局部窗口内的共现关系。

**两种结构（预测方向互逆）**：CBOW 用上下文词的向量（求和或平均）预测中心词——适合小语料、高频词；一次更新利用整个上下文，收敛快，直觉是 `[the, ___, runs in the park]` → 填 `dog`，需要"融合"上下文。Skip-gram 用中心词分别预测**每一个**上下文词——每个 (中心, 上下文) 对都是独立训练样本，数据量大、训练慢 2~3 倍；但对**稀有词更友好**：稀有词的每一条出现都被充分利用，词向量在高频词上略逊 CBOW，整体语义更细。小语料 / 罕见词多时优先 Skip-gram。

| 维度 | CBOW | Skip-gram |
|------|------|-----------|
| 预测方向 | 上下文 → 中心 | 中心 → 上下文 |
| 每步梯度 | 一次（上下文聚合后） | 每个上下文词一次 |
| 速度 | 快 | 慢 2~3 倍（样本多） |
| 罕见词表示 | 较弱 | 较好 |
| gensim 参数 | `sg=0`（默认） | `sg=1` |

**输出层为什么必须做近似（softmax 太贵）**：朴素做法在中心词处要算 `softmax(W·h)`，分母遍历**整个词表 V（几十万）**，每步更新全表，代价不可接受。两个经典近似：
1. **层级 Softmax（hierarchical softmax）**：用 Huffman 树把 V 个类别路径编码成 O(log V) 次二分类（每个内部节点一个逻辑回归），树上"高频词路径短"；
2. **负采样（Negative Sampling, NEG）**——Word2Vec 事实标准：把问题从"V 分类"改成 **k+1 个二分类**。对每个正样本 (w, c)，随机抽 k 个**负样本** (w, c')（k 通常 2~15，小语料取 5~20），目标函数为 `maximize log σ(v_w·v_c) + Σ_{c'~P_n} log σ(-v_w·v_c')`，其中 σ 为 sigmoid。只更新正样本 + k 个负样本的向量 → 每步代价 O(k)。

**为什么负采样能成立**：词表里绝大多数词与当前上下文无关，全部按"负类"处理即可——这是"让正样本共现概率高、随机负对概率低"的判别式训练，等价于只让模型学会"区分真共现与随机共现"。数学上可证明：学到的向量隐式地在做 PMI 矩阵的低秩分解，与"点互信息矩阵分解"视角相通。

**负采样分布的小心机 ^0.75**：负样本按词频采样，但不是线性词频，而是 `P(w) ∝ count(w)^0.75`（分子取 0.75 次幂再归一化）。作用是**抬高中低频词的被采样概率**，避免负样本清一色是 the/of/and，否则模型只会学到"这些词不该共现"而缺乏判别力。

**数据侧的两个正则技巧**：① **词频子采样（subsampling）**——高频词（the、的）按概率 `P(drop) = 1 - sqrt(t / f(w))` 随机丢弃（t 约 1e-3~1e-5）。高频词重复出现提供的信息边际递减，丢弃后训练更快、罕见词相对权重更高；② **动态窗口**——每个样本实际窗口在 1~window 间随机，近邻词权重更大。

## 应用

典型使用场景：把词变成稠密向量作为下游任务（文本分类、聚类、检索召回、序列模型 embedding 初始化）的特征或基线；相似词 / 词间相似度查询；与上下文嵌入对照作为静态基线。快速上手三步：① 中文必须先分词（jieba 等）或用字级输入，否则"字"之间没有天然窗口；② 按语料规模选结构与参数（sg、negative、sample、window、vector_size，见下方代码与"对比选型"）；③ 用 `model.wv` 查询相似度，发布只存向量文件。

常见坑与注意事项：
- ❌ 把"训练好的完整模型"与 `wv`（KeyedVectors，只含向量）混用：部署 / 发布只存 `model.wv.save_word2vec_format` 即可（不带训练器）。
- ❌ 不同语料 / 参数训练的向量直接比较余弦 → 无语义可比性；接下游任务要统一重训或做空间对齐。
- ❌ OOV 词直接 KeyError：先建 `wv` 的未见词回退（子词 / fastText 可解决）。
- ❌ 语料太小还开大窗口 / 大维数 → 过拟合到"共现噪声"，相似度全是无意义的高分。
- ❌ 类比 `king - man + woman ≈ queen` 只是近似性质，需要足够大语料才稳定，小语料上经常不成立——别拿玩具语料测类比然后怀疑代码写错。
- ❌ 词向量是**静态的**：`bank`（银行 / 河岸）只有一个向量 → 多义词场景改用上下文嵌入（BERT / LLM 内部表示），静态向量适合做特征 / 基线 / 检索映射。
- 相似度一律用**余弦**（向量长度无关紧要，方向才有语义）。

```python
# gensim 4.x 训练 Word2Vec：CBOW/Skip-gram 选择 + 负采样 + 相似度查询
from gensim.models import Word2Vec

# sentences：可迭代的句子（每个句子 = 分词列表）
model = Word2Vec(sentences,
                 vector_size=100,    # 4.x 起叫 vector_size，旧版叫 size
                 window=5,           # 上下文窗口（实际窗口会动态缩小）
                 sg=1,               # 1=Skip-gram, 0=CBOW（默认）
                 negative=5,         # 负样本数 k；0=层级 softmax
                 sample=1e-4,        # 子采样阈值 t（P(drop)=1-sqrt(t/f(w))）
                 min_count=2,        # 过滤低频词
                 epochs=5,           # 旧版叫 iter
                 workers=4, seed=1)  # 固定 seed 保证可复现
model.wv.most_similar("king")        # 查询相似词（余弦）
model.wv.similarity("king", "queen") # 两词余弦相似度

# 案例详解：
# 1) sg=0（默认）即 CBOW：聚合上下文词向量预测中心词，小语料/高频词场景收敛快；
#    改为 sg=1 即 Skip-gram：每个 (中心,上下文) 对独立成样本，稀有词表示更好，但慢 2~3 倍。
# 2) negative=5：每步只更新正样本 + 5 个按 count(w)^0.75 采样的负样本，代价 O(k)；
#    若 negative=0 则退回层级 softmax（Huffman 树路径，O(log V) 次二分类）。
# 3) 训练后部署只保留向量：model.wv.save_word2vec_format("vec.bin", binary=True)，
#    下游用 KeyedVectors.load_word2vec_format 加载，避免携带训练器/与 wv 混用。
# 4) 词频子采样阈值 sample=1e-4 会按 P(drop)=1-sqrt(t/f(w)) 丢弃 the/的 等高频词，
#    语料小时可调小甚至关掉（sample=0），防止过度丢弃。
```

## 对比选型
| 方案 | 核心思想 | 最佳场景 |
|------|---------|----------|
| Word2Vec CBOW（本文方案） | 上下文词向量聚合后预测中心词，负采样二分类训练 | 小语料、高频词多；追求收敛速度 |
| Word2Vec Skip-gram（本文方案） | 中心词分别预测每个上下文词，逐样本更新 | 大语料、稀有词/罕见词多，语义更细 |
| 层级 Softmax（输出层替代） | Huffman 树路径编码成 O(log V) 次二分类 | 词表极大且需要精确概率、不想引入负采样噪声 |
| GloVe（替代方案） | 全局共现计数 + 加权最小二乘矩阵分解 | 中等语料、想利用全局统计、可并行快速训练 |
| 上下文嵌入 BERT/ELMo（替代方案） | 按上下文动态编码词义 | 多义词、需要语境化语义的下游任务（成本更高） |
