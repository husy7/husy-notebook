## 核心目标
用更少的算力、更少的内存，压榨出更多的智能。
- **本质**：涵盖硬件、架构、训练、推理、IO 的全栈系统工程问题。
- **约束**：算力上限、显存带宽、延迟要求、成本预算。
- **产出**：任务成功率、复杂推理能力、长程一致性。
---
## 第一轮：应用层优化（引导智能与提升效率）
### 1. 模型智能优化
聚焦于挖掘模型自身潜力，提升复杂问题解决能力。
- **层次化推理机制**
  - **策略**：将一次硬想拆解为多层级规划与子问题求解。
  - **案例**：ReasonFlux 通过思想模板库与层级规划，提升复杂问题分解能力。
  - **收益**：推理路径更可控、可解释，适合测试时扩展。
- **智能体决策框架**
  - **核心闭环**：规划、执行、观察、反思。
  - **能力**：赋予模型工具使用、多智能体协作与环境交互能力。
  - **工程意义**：从问答系统升级为任务执行系统。
### 2. 模型速度优化
聚焦于降低运行成本，提升部署效率。
- **模型压缩技术**
  - **量化**：降低参数精度（如 4-bit），减少显存占用与带宽压力。
  - **剪枝**：去除冗余注意力头或层，降低计算量。
  - **蒸馏**：大模型教导小模型，实现轻量化部署。
- **自动化部署调优**
  - **手段**：针对特定硬件自动搜索最优 Kernel、并行策略与批大小。
  - **收益**：最大化实际部署的吞吐量与利用率。
---
## 第二轮：基础层优化（架构突破与资源瓶颈）
### 1. 底层架构革新
挑战传统组件，探索新的扩展维度。
- **优化器改进**
  - **痛点**：AdamW 显存占用大，需存储动量与方差。
  - **方案**：Sophia 引入二阶信息加速收敛；APOLLO 通过低秩投影压缩显存。
  - **收益**：训练更快、显存占用更低。
- **架构范式迁移**
  - **方向**：探索线性复杂度架构（如 Mamba/SSM），替代 Transformer 的二次复杂度。
  - **收益**：从根本上解决长序列计算爆炸问题。
### 2. 记忆瓶颈优化
解决推理过程中的核心资源瓶颈。
- **核心痛点**：KV Cache 显存占用
  - **问题**：显存随生成长度线性增长，长上下文易导致显存溢出。
- **关键优化手段**
  - **PagedAttention (vLLM)**：像操作系统管理内存一样管理 Cache，消除碎片，提升并发。
  - **淘汰与压缩**：动态丢弃不重要 Token 的 Cache，或进行量化压缩。
  - **多 Token 预测**：减少自回归步数，变相降低 Cache 累积时长。
### 3. 分布式训练工程
在高并发集群上最大化算力利用率。
- **重点**：负载均衡、通信与计算重叠、稀疏化训练。
---
## 第三轮：接口层优化（通信效率与结果质量）
### 1. 输入端通信优化
降低输入成本，提升预处理效率。
- **提示词压缩技术**
  - **工具**：LLMLingua 等。
  - **方法**：剔除冗余 Token，保留关键语义。
  - **收益**：直接降低输入成本与首包延迟，减少预填充显存压力。
- **协议化输入规范**
  - **方法**：使用紧凑的结构化协议（DSL/JSON）替代自然语言描述。
### 2. 输出端质量优化
确保结果规范性，降低后续处理成本。
- **结构化输出约束**
  - **方式**：强制模型以 JSON/YAML/表格格式输出。
  - **收益**：降低解析失败率，便于下游系统自动化处理，减少人工干预。
### 3. 系统协同优化
- **组合策略**：KV Cache 优化（显存）结合动态稀疏计算（算力）。
- **应用场景**：长文本处理、高并发推理场景下的整体效率提升。
---
## 核心洞察总结
LLM 的优化不再是单一算法的较量，而是系统工程能力的竞争。
1. **分层解耦**：从硬件到应用，每一层都有独立的优化目标，但需全局协同。
2. **杠杆效应**：找准瓶颈点（如 KV Cache、Optimizer States、Prompt Length），往往能以小博大。
3. **资源约束**：所有优化的终点，都是在算力、显存、成本的刚性约束下，寻找智能的最大化解。
